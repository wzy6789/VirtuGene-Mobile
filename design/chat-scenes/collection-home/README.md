# 家庭场景：暖灯卧室与晨光客厅

原创离线 Blender 几何与程序材质；沿用本项目自己的基础建模函数。卧室包含低床、枕头、真实起伏的被褥、床尾织物、床头柜和暖灯；客厅包含宽长沙发、抱枕、双侧窗帘、绿植、收纳柜、藤编篮、茶几和热茶。两者采用不同家具与光照，不是咖啡厅换色。没有外部模型、照片、生成服务或场景音频。

复现：本目录 `build-scenes.py -- --scene home-bedroom --preview` 由 Blender 后台执行；将 ID 改为 `home-living` 可看客厅。`render-all.py` 串行导出两景的分层、真实几何遮挡 mask 与原生2160×4800源稿。`export-runtime.py` 只裁切、缩小和编码实际渲染图，生成1080/1440档和360×800缩略图。`verify-assets.py` 实际解码并核对文件哈希、构图、源稿、遮挡、内存估算与中性位重构。

手机使用固定相机 DOM 2.5D。窗框、织物和家具重叠处保持静止，局部窗雨、日光微尘、床头灯暖光与真实茶杯蒸汽走已有统一暂停策略。卧室没有热茶，不添加蒸汽。素材选择仅为本机外观，不修改世界地点、人物事实或记忆。每个图层使用真实场景可见性遮罩；运行完整poster不重复叠放家具。

高分原稿和 `.blend` 保留本目录，运行时只有 `src/assets/chat-scenes/home-*` 的裁切资源。RGBA估算不是手机GPU或进程内存实测。编码模型、推理强度未确认；在线生成调用0。
