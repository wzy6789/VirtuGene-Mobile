# 数字灵魂启动动画 · 2026-10-03

启动视觉改为深空紫青色双螺旋核心：17 段基因连接、细线轨道、星点、淡坐标网格和品牌字标。轨道先转动对齐，再缓慢运行；核心和字标分别浮现，底部光迹表示正在启动，不显示伪造的进度百分比。保留「让数字灵魂拥有时间」品牌文案。

背景与光晕静态绘制，不使用 Canvas、动态图像下载或动态模糊。运行中的动画仅改变 transform/opacity，轨道和光迹不产生逐帧 React 提交。首次短呈现 640ms（含实际初始化等待），退出 320ms；如果初始化本来更慢，不再追加一段完整呈现等待。应用/系统减少动态效果时呈现静态图案，准备完成即进入页面。后台暂停装饰动画，退出计时和偏好订阅随组件卸载清理。

原实现先淡出启动页、400ms 后才挂载主页面，淡出期间会露出空背景。现在初始化就绪后先准备登录页或已登录主页，再透过启动页淡出显露。被覆盖页面设置 inert/aria-hidden，退出后恢复；更新说明、新手引导与使用提醒等到启动页退场再显示。

Android 最早的系统启动页原本引用白底 Capacitor 默认图。主题改为 #0F0F1A 深色、品牌双螺旋矢量标志；系统启动结束后的主题明确使用 AppTheme.NoActionBar。保留旧 PNG 资源，不影响其他引用。无需额外图片或启动插件。
