# 助理入口收起与展开

消息首页和角色页的助理工作台默认收起，头部内容高度 84px，含边框共 86px，与普通会话行相近。保留 48px 头像、名字、助理标记和状态，有待处理请求时显示数量。

点击整行展开，显示原有办事概览、进入对话、助理管理及记录提示；再次点击整行收起。未聘用时展开后显示聘用入口。桌面复用此组件的入口采用相同交互。

展开与收起使用 340ms 的 CSS grid 高度过渡，配合箭头旋转与内容淡入，连续点击能够直接反向过渡。系统减少动态效果时关闭动画。收起内容通过 inert 和 aria-hidden 停用，触发按钮提供 aria-expanded 和 aria-controls，支持键盘操作。切换账号重置展开状态；保持既有工作台读取、订阅与助理操作逻辑。

验证：

- TypeScript 检查、Vite 生产构建通过。
- 助理完整回归：258 项数据检查、71 项 UI 检查通过，包括普通会话高度对齐、键盘展开、快速反向点击、减少动态效果、展开后的真实对话入口和账号切换。
- mobile-soul、character-ui、character-scroll 三个套件通过。
- Chrome 触屏预览检查浅色/深色、320px/390px、展开/收起、角色目录入口，无横向溢出和运行时错误。
