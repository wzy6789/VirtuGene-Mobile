# UI 流畅度与触控收尾

本轮继续使用深色星域主题和既有字体、色彩、设置层级，不添加新业务功能。参考 design-md-reference 的小屏控制与安静层次原则，把调整集中在实际操作路径。

## 会话侧滑

`SwipeActionItem` 改用 Pointer Events 和合帧 DOM 位移，拖动不再逐帧更新 React 状态。位置直接跟随手指；松手综合距离与速度判断是否显示操作，动画使用与主界面一致的阻尼收束曲线。左右边界有最多 18px 的弹性阻力，落点在松手前以细光轨预示。

重新抓住回弹中的行会从当前实际位置接续。保留纵向滚动、滑后不进入聊天、只展开一行、点击主体收起、明确点击操作才执行的行为。修正真实触摸中子按钮失去隐式捕获冒泡导致侧滑取消的问题。新的按下会撤掉上一轮点击抑制，不用等待才能继续操作。

键盘可用左方向键显示操作、右方向键或 Escape 收起；关闭的操作层 inert，不参与焦点与点击。收起时将操作按钮的焦点还给主体。

## 聊天滚动

自动跟随最新与显式返回最新分开处理。查看历史时，新消息和视口变化保留阅读位置；按下、滚轮和键盘滚动会取消尚未执行的补滚。虚拟列表测量与输入区尺寸变化不会被误认为用户选择离开底部。

观察滚动容器及其直接布局子节点，处理晚到图片、内容测量与工具区高度变化。会话切换重新绑定并恢复底部跟随。聊天页增加“回到最新”入口，放在输入区上方右侧。修正了通用触控选择器覆盖定位的 CSS 优先级，出现时仅淡入与小幅位移，始终保持 48px 高度。

## 触控一致性

原有的触点柔光、滑出取消与滑回继续扩展到导航、聊天按钮和会话入口；不移动文字与主按钮热区。语音手势和独立按压卡片保留各自的控制方式。补上聊天长按的 touchcancel、失焦、隐藏和卸载清理，防止延迟弹菜单。修正减少动态效果模式下按压卡片残留的点击抑制。
