## 二、改了什么

### 2.1 结构：12 段压缩到 5 段

删掉：四大理念矩阵（TIME / MEMORY / RELATIONSHIP / WORLD）、六项能力列表、使用场景列表、
十二图界面画廊、关系等级长时间线、三屏高的产品轮播、独立的“产品”章节。
需要的信息融进相遇 / 记忆与关系 / 世界 / 下载四段，不另起功能区。

- 导航：品牌 · 体验 · 世界 · 下载（移动端只留品牌 + 下载按钮）。
- 首屏：左侧 47% 文字、右侧 53% 人物；取消“系统初始化”等待画面、轨道圈、粒子前景、
  人物编号、舱体标题；标题为偏白实色，仅第二行用浅紫强调；下方露出下一段内容。
- 相遇：真实聊天截图作主视觉，极薄设备边缘；不再叠加第二个人物、不做漂浮字幕、
  不伪造“消息逐条到达”。
- 记忆与关系：三步因果示意（提到 → 留下记忆 → 之后被想起）+ 真实记忆界面；
  取消泛化星图、漂浮残影与“第七天熟悉、第三十一天信任”的固定成长时间线。
- 世界：一个宽幅展示区，三个原生按钮切换（世界星图 / 剧情现场 / 留下的经历），
  默认星图、点击切换、不自动轮播；手机端截图保持竖版比例，不拉宽成横屏。
- 下载：Android 与 Windows 分开核对版本与系统要求，说明首次需要配置模型服务 API Key，
  保留隐私说明与使用条款入口。不自动触发下载，不写“下载即完全免费使用”，
  不编造用户数、评分、合作方或推荐语。

### 2.2 视觉

- 深紫黑底（`#08050f` / `#05030b`）+ 偏白正文（`#efeaf9`）+ 柔和紫强调（`#8b7bf0` / `#a99bff`），
  主按钮沿用品牌紫 `#6c5ce7`；品牌青 `#00cec9` 只用在“体验示意”一个圆点上。
- 正文字号 17px（手机 16px）、行高 1.75；标题行高 1.16–1.2。
  中文标题字距 0.04em，正文 0.01em。正文对背景对比度 ≥ 9:1（灰字 `--faint` 也有 5.4:1）。
- 内容最大宽度 1200px；桌面左右边距 40–64px，手机 20px；章节间距桌面 128px / 手机 64px，
  **只在顶部留一次**，相邻章节不叠加双倍空白。
- 每个可视区域只有一个主角；每个章节一个大标题 + 一段短说明。
- 全页唯一一处装饰：世界展示区上方一条很淡的弧光，与首屏紫色光线呼应。

### 2.3 动效：只保留 6 类

| 动效 | 用途 | 限制 |
| --- | --- | --- |
| 首屏光晕 | 紫色空间氛围 | 低幅度慢速（11s），仅首屏可见且标签页可见时运行 |
| 区域进入 | 引导阅读 | 淡入 + 12px 位移，一次 |
| 记忆连接线 | 表达经历延续 | 进入视口点亮一次，不循环闪烁 |
| 世界切换 | 表示内容改变 | 220ms 淡入淡出，容器高度不变 |
| 按钮反馈 | 明确可操作 | 150ms 颜色/边框变化，不移动点击目标 |
| 图片查看 | 查看真实细节 | 180ms 淡入，无旋转飞入 |

删除：全页鼠标追光、自定义光标、磁吸按钮、全局星空 Canvas、滚动速度光效、全页 3D 镜头、
大面积动态模糊、多层持续粒子、自动轮播、滚动锁定。

“内容默认透明、靠脚本解锁”的做法被反过来：由 **JS 先把元素武装（`.is-armed`）再播放**。
脚本没加载或被拦掉时不会武装，内容一开始就是可见的；另外还有滚动兜底，
观察器失灵时也会按位置补一次，内容不会永远藏着。

### 2.4 工程

- 重写 `index.html` / `styles.css` / **新增 `main.js`**，不再在旧 CSS 末尾追加覆盖。
  旧 `styles.css` 是 113 KB 的压缩样式 + 多次追加覆盖，现在按
  基础变量 / 布局 / 组件 / 章节 / 响应式 / 减少动态 / 文档页 七段组织。
- 交互全部集中到 `main.js`，6 个模块各自 `try/catch` 初始化，互不影响。
- 世界切换用原生 `button` + `role="tab"` / `aria-selected` / `tabpanel`，支持方向键、Home、End。
- 图片查看：关闭按钮、Esc、焦点回到触发按钮、滚动位置恢复，并用 token 防止
  快速切换时旧定时器覆盖新图片。
- 图片写明 `width`/`height`，首屏主图优先加载，非首屏图片懒加载，
  隐藏面板的两张截图在接近视口时预热一次，切换时不出现空白等待。
- 没有引入任何框架或动画库；隐私页、使用条款页继续复用 `styles.css` 的 `.document` 段落，已实测未被带坏。

### 视觉检查（人工看截图，不是只看断言）

已逐屏看过并据此修掉的问题：

1. 首屏标题在 1440px 下被挤成 4 行（“让数字灵 / 魂 / 拥有时 / 间。”）→ 调整列宽比例与字号上限。

3. 相遇整段只有半屏内容、右半边全空 → 把标题移进两栏，左侧文字右侧截图。
4. 记忆段三步与截图挤在同一格 → 拆成左右两栏，纵向居中。
5. 世界展示区说明文字过长导致切换时容器高度变化 27px → 固定说明区高度并把说明移到截图左侧。
6. 相邻章节上下 padding 叠加成 256px 黑场 → 章节只在顶部留间距，页面总高度减少约 1000px。
