# 行动舱第一阶段 · 正式应用接入

2026-10-04。正式应用现在提供“今日”和“收集箱”；项目中心、风险独立页面、周复盘仍留在设计原型，不显示未完成入口。没有修改版本号或宣称 6.0.0 已达到发布标准。

## 可以使用的功能

- 消息首页常显行动舱入口，与生活助理卡片分开；桌面侧栏也可直达。生活助理聊天头部的小球可以进入行动舱；返回会恢复原导航上下文。
- 今日展示真实的今日待完成、今日完成、逾期、需要跟进四个数字，以及按契约排序的三件优先行动。今日与逾期的并集按发生实例 id 去重。
- 搜索与筛选覆盖今日、全部行动、逾期、等待、跟进、过期重点和今日完成。未处理的旧重点不设历史隐藏窗口，可单独接续或清除并撤销。
- 收集箱就是当前账号的未排期待办。手工新增默认私密，排上日期后进入日程。没有自动理解原话、助理确认卡片或未经确认的写入。
- 整行完成、重新打开、编辑名称/备注/截止时间/优先级/重复规则/步骤/工作状态/知情范围、设置今日重点、等待与阻塞说明。列表每次显示 40 行，继续加载不会改变统计总数。
- 编辑器从原待办页抽成一个共享组件。重复任务默认只改当前实例的截止日期；后续安排需明确选择范围。已存在实例的身份与历史保留。
- “补记已跟进”保存实际日期、方式、反馈；“其他”方式需要说明。安排变更与实际联系分别保存；补记不会改变下次安排，软件不会代发消息。
- 完成、重点变更、跟进记录均提供撤销。撤销检查版本，不覆盖后续修改；纠错作废原事件，保留原文与发生日。

## 数据、迁移与同步

生产 Dexie 版本由 31 升到 32，一次迁移包含 Todo 工作字段、实例覆盖字段、行动事件表及按账号查询的索引。旧完成记录只迁为 `legacy-completion`，使用已有完成时间；不虚构联系。修复旧未排期任务在不同入口创建多个完成实例的问题。

`readTodoInstances` 和 `readActionDay` 是共享只读服务，首页助理概览、主动建议、每日整理、行动舱和原待办页使用同一套实例读取逻辑。重复实例按原计划日期保持 `todo-occ:{todoId}:{scheduledDate}`，实际截止日可以调整。每日整理仍保留现有授权、来源版本和资料量上限。

查询先按账号读取，再取角色知情范围交集；空角色集合不意味着公开。无日缓存，前台恢复、窗口获得焦点、每分钟和午夜都会刷新。账号切换会立即卸载两种待办页面的私有局部状态。

事务中的页面通知延迟到最外层提交成功后发出，并脱离原事务上下文。读取页面不再创建发生实例；只有确需安排的系统提醒才持久化对应实例。提醒使用实例实际截止时间，失败或平台不支持不会标成已安排。

同步与正式加密备份都包含事件。事件按稳定 id 去重，原始事实不可改写，只能追加作废标识；未知事件类型或改写已有事实会拒绝整个事务。工作字段带独立版本，旧数据包缺字段不清除新字段，显式 `null` 的清空不会在旧客户端回传后复活。已测试 v31→v32 的实际 IndexedDB 升级和旧格式数据包回传；没有把这些结果称为旧 Android 二进制的整机兼容验证。

## 小球接入

正式入口已经引入 `soul-orb.css`。小球出现在行动舱入口、助理聊天头部、行动舱标题和空态：聊天请求中显示思考，行动执行中显示忙碌，操作失败显示遇到困难，行动清空显示完成。表情说明不代表监听或情绪识别。

SVG 接力只快照受控的球体子树，冻结当前外观并重命名渐变 id，不克隆聊天正文或任意页面。聊天/首页→行动舱路径已经实测；减少动态效果时直接进入，键盘操作仍可用。入口采用原生按钮与至少 44px 热区，拖动超过 10px 不触发打开。

## 验证和实际边界

运行命令：

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build
node scripts/verify/build-action-cabin.mjs
node scripts/verify/run-action-cabin.cjs
node scripts/verify/build-secretary.mjs
node scripts/verify/run-secretary.cjs
node scripts/verify/build-soul-orb.mjs
node scripts/verify/run-soul-orb.cjs
```

行动舱 54 项数据检查、18 项界面检查通过，另有一项大历史量计数检查。覆盖真实迁移、回滚、撤销冲突、重复任务旧逾期、未排期身份、权限交集、事实/安排区分、旧数据回传、同步重放、备份恢复、行动舱与助理改期衔接、失败保留输入、320/390/430px、深浅色、实际 SVG 接力、键盘减少动效和账号切换。小球原有 70 项检查通过，原助理回归 1,228 项数据 + 157 项界面通过且无浏览器运行错误。截图为 `scripts/verify/action-cabin-dark.png` 和 `action-cabin-light.png`；运行结果写在同目录 `.last-result-action-cabin*`。助理回归可通过 `VG_VERIFY_SCREENSHOTS` 指定独立截图目录，避免并行工作争用图片。

120 个任务模板展开为 11,070 个真实/虚拟发生实例，最新 12 次 Chrome 查询测得中位 13.7ms、P95 16.6ms。改用线性选择前三项，避免每次对全部历史排序。该结果是这台电脑上浏览器的查询墙钟时间，不是帧耗时或 Android WebView 性能保证。当前服务仍需读取当前账号的模板与持久实例；极长历史或更大规模数据需要继续做真机和内存测试。

ADB 检查没有连接设备。中端安卓的滑动、键盘、后台恢复、小球常驻帧率与实际通知到达尚未验收。用户随后明确“不需要真机”，这些实测项不再阻塞发布，仍保留未验证说明，见 [冻结与发布记录](RELEASE-6.0.0-GATE.md)。自动解析收集箱、项目实体、周复盘及其小球驱动不在本次开放范围。
