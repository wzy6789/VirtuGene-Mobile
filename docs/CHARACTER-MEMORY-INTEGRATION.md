# 跨场景角色记忆

统一入口：`src/lib/character-memory.ts`。按当前账号、角色、听众、查询和预算读取原始数据，返回正文与来源标识。零额外模型调用，不迁移或复制私密正文，不把模型的推测写成事实。

## 已接入

- 私聊：保留原有长期记忆、日记、世界与动态召回；新增群消息、角色动态和评论/点赞记录。已有动态正文不重复注入，近期使用过的跨场景记忆降低重复出现机会；用户明确追问可重新召回。
- 星域：新旧生成路径都接入。单角色可携带自己的长期记忆与最近私聊；多人新增上下文只使用全体听众都允许知晓的内容。“只带此刻状态”不加载新增记忆。
- 群聊：接入世界共同记忆、已结算经历、进行中片段、朋友圈互动；撤去原来的成员私聊原文拼接，避免一份多人模型请求包含不该公开的私聊。
- 朋友圈：评论与发动态均读取听众权限过滤后的世界与社交记忆；评论回复读取最近十二条真实评论，保留发言人和回复对象。
- 私聊记忆依据：保存真正完整注入的跨场景来源标识；区块被截断或丢弃时不记录。界面显示来源计数，不复制已删除正文。

## 权限与生命周期

1. 账号必须拥有角色与所有听众角色，来源也必须属于当前账号。
2. 群消息在写入事务中记录 `witnessedBy`。新成员不继承旧消息的在场资格。旧消息没有快照，不在新增召回层推断知情。
3. 世界记忆继续使用原有可见性和认知校验。多人新增上下文取各人的可召回内容交集，进行中经历明确标注尚未结算。
4. 朋友圈屏蔽、私密、删除、听众名单每轮重新读取；撤回的评论不召回，配图未解析时明确内容未知。
5. 长期记忆过滤已撤回/被纠正的旧事实。优先用户钉住事项与当前话题，整条装入预算，文本去重。
6. 召回读取失败时跳过可选记忆，不阻断发送，也不扩大权限重试。

## 验证

`node scripts/verify/character-memory.mjs` 使用独立临时 Edge 配置与独立 localhost 源，在真实 IndexedDB 上执行 29 项断言。生成路径的网络调用被禁止；唯一网络为测试结果上报到本机验证服务。覆盖账号隔离、群消息快照、晚加入、旧消息、失败消息、删除、朋友圈撤回/屏蔽/私密、世界认知与可见性交集、真实世界角色上下文、不带记忆模式、预算与溯源。

## 边界

这是一层有界召回，不承诺任意久远原文永远命中。群消息按近期会话与消息窗口读取；旧的长期记忆/摘要机制继续承担长程保存。没有给旧群消息伪造听众，也没有清理用户原始历史。多人模型已有的其他上下文规则仍需遵守角色边界；新增召回层对可能公开的信息采用保守交集。已发出的历史回复不会因为随后撤权自动消失，撤权作用于后续召回。

本次验证不调用真实付费模型，也未替代 Android 真机长对话体验测试。
