# VirtuGene 5.3：有性格、能办事、能交接的生活助理

主打体验：用户亲自聘用一位有鲜明性格的生活助理，在一次对话中完成生活记录和事项安排，并能随时解雇、重新聘用，保留自己的记录。

## 5.3.0 已实现的主线

- 口语声明整改：办事回应采用完整情绪短句允许列表，不透传“记好了、发好了、搞妥了”。混合句仅保留前面的安全情绪短句；用途不明的“给我记一笔”补问待办或日记。默认气泡移除重复标题与时间，详细回应偏好仍保留。跨会话任务焦点与历史分页尚未完成。

- 聘用：用户取名，比较五种性格的办事、疲惫与失败反应，选择对应的二次元男性／女性形象，补充称呼和文风偏好。
- 办事：14类真实操作，包含私密日记保存/追加/检索、应用内朋友圈草稿/发布/检索、待办创建/查询/改期/完成/恢复/修改/取消/步骤管理，以及8个软件页面的直达卡片。
- 内部能力开放：修改待办名称、备注（含清空）、优先级、整个系列的日期时间与重复规则；每天/工作日/每周/每月/间隔天数、最多3个提前提醒，支持关闭提醒、同步取消旧通知和撤销修改。未指定的设置保留，历史完成记录保留。
- 历史检索：按日期或关键词查个人日记与自己发布的朋友圈，只读查询并展示最多30条真实结果；点击打开原记录。锁定日记立即隐藏摘要，原记录修改/删除后不展示旧摘要。
- 办事习惯：专属设置选择日记格式、朋友圈文风、回应长度、新待办默认优先级和提前提醒分钟数；跟随用户保留，换助理不丢失。当前指令优先，只有明确要求提醒才采用提醒习惯，缺日期时间仍补问。每次请求保存习惯快照，修改设置不会改变已经开始的任务。
- 连续修改：刚创建或办理完单个待办后，直接说“改为紧急”“改名为…”“备注改成…”“改成提前十分钟提醒”“关闭提醒”“改到后天晚上八点”，无需重复标题。版本变化或多个候选不擅自选择；修改记录独立保留，可撤销。
- 待办步骤：新建时拆成清单，或为已有单次待办追加步骤；保留原步骤、完成状态和标识，去除重复新增。按名称或序号完成/恢复，接着说“第一步完成了”“恢复第二步”；父待办和步骤分别选择，重名不擅自处理。聊天卡片实时显示进度并跟随待办页修改，写入可撤销，备份保留清单。全部步骤完成不自动完成父待办；重复系列暂在待办页管理，新建时可明确改为单次并保留步骤。
- 反馈：真实结果卡片，编辑、补充、单项重试、查看目标、撤销及连续对话指代。
- 体验优先整改：支持“帮我记上”“别让我忘了”和单项收据后“那个挪到后天”；新建显示已添加、日记已保存、调整已修改，单独读取真实待办状态。办事回应保留模型的一句体谅与真实添加结果，不增加调用；过滤未经验证的成功声明与定时提醒承诺。接下来依次完善任务焦点与分批历史读取、界面减负、用户自选的主动帮助，暂缓扩大工具数量。
- 真实性收尾：不再整体保留问号结尾的模型回复，补问由实际缺少字段和候选项生成；支持“记上明天的会议”“记得叫我一声”，缺提醒日期、时间或事项时具体补问。情绪句中的“已经”可保留，执行声明仍过滤；不增加模型调用，真实模型语义质量仍需验证。
- 管理：同一时间一位在职助理，在职资料修改、保留记录的解雇与重新聘用。
- 独立工作台：首页聊天列表保留助理专属卡片，点击直接对话，实时展示今日及逾期待办、待处理请求及待发布草稿；角色搜索不隐藏助理入口，空缺时仍可回看保留记录。
- 体系分离：助理不列入普通角色搜索、基因库发布、好感度与情绪图谱、群聊选人、星域参与者和朋友圈自动互动；专属菜单处理办事、整理、聘用和生活记录，旧角色编辑入口转到助理管理。
- 交接：未完成待办与草稿概览，历任聘用记录，旧草稿和待补充事项手动接续。
- 收件箱：跨会话查看待处理、朋友圈草稿、未办成和最近完成，直接使用原结果卡片编辑、补充、发布、查看或撤销；理解失败的请求可以放回输入框重新描述。
- 每日整理：选择日期、资料范围和需要的建议类型，按勾选生成日记、朋友圈草稿或次日待办建议，逐项采用后才实际写入。生成前可展开真实办事进展，分开查看当日完成、仍待办理与次日已有安排；按日期和优先级排序，查看当前步骤及下一步，点击回到原待办。预览实时刷新，历史日期不引用当前步骤，步骤勾选不当作当日经历。
- 形象：五种性格各一男一女，共十款原创 AI 拟人头像。在职可以更换男女形象，保留名字、性格、任期和全部记录；旧默认图标升级到对应头像，自定义头像保留。
- 连续性：保留同一账号工作区、聊天和生活记录，拦截旧任期的迟到请求；备份恢复不自动执行。

首页聊天列表和手机角色页持续展示独立助理工作台；普通角色列表不重复展示助理。聊天内提供日记、朋友圈、待办、今天安排、查记录、改待办和每日整理入口；更多菜单增加六组已开放能力说明及示例。默认使用账号内办事能力，保留账号归属、日记锁和当前明确请求校验，不开放任意代码、账号密钥或外部应用控制。开发版本为 5.3.0，Android versionCode 37；尚未制作安装包或发布更新。

## 后续 5.3.x 优先顺序（规划，尚未实现）

1. 扩展办事习惯：已实现日记格式、朋友圈文风、回应长度、优先级和提醒偏好；后续完善清单分类与用户模板，不从任意角色聊天推断现实事实。
2. 主动协助：明确启用后提供真实调度、通知和任务状态；平台未运行调度时不能承诺定时办事。
3. 多设备聘用与任务锁：服务端统一账号聘用版本与执行幂等；覆盖离线冲突和同时操作。

## 发布前验收

用真实模型体验五种性格及中文连续任务；在 Android 真机验证权限、提醒、语音输入、键盘和长表单；核对升级后的旧角色、会话、日记、动态、待办、草稿和撤销状态。固定 HTTP 模型替身验证执行一致性，不能证明真实模型表达质量。
