# 2026-09-26 记忆整改结果

对应 MEMORY-AUDIT-2026-09-26.md 的九类缺陷，生产代码已修复，并新增隔离回归。

## 行为变化

- 星域正文优先使用 witnessedBy 快照；旧正文使用在场区间。携带本人记忆不会授权入场前别人说的话。
- 离场记录保留在 pastParticipants；重入可读自己的亲历，不补齐离场期间的内容。结算给离场者 partial 知情，仅允许回查亲历原文，不授予最终完整摘要。
- 私聊接入统一服务召回的世界原话与角色动态，按来源 id 去重。溯源只记录实际分配给该区块的引用。
- worldId 与 scene.worldId 统一；旧授权日记的检索与知情索引使用同一世界标识。
- 长星域的普通相关追问也执行本地历史检索，不依赖“还记得”关键词，不新增模型请求。
- 历史事件与共同记忆的查询要求角色知情，world 可见性本身不再等于已知。
- 更正、显式遗忘、事实替代撤回该角色旧 claim 的知情边，并保留原文抑制记录。私聊原文、统一引用与后台提炼执行抑制；原始聊天记录不删除。
- 私聊和群聊摘要写入核对消息版本与先前摘要。私聊另检查本次保护的置顶记忆是否仍有效。摘要写入拒绝后不会继续生成派生摘要记忆；派生写入也检查当前会话摘要。
- 逐条提炼支持 content + sourceIds 格式，拒绝批次外 id。旧模型的字符串数组按整批依赖处理，来源变化时保守失效。明确独立证据可以保留幸存来源。重复提炼合并证据；无效任务的部分消息不混进其他有效任务。
- 群聊历史按消息的真实见证者筛选，退出群聊不抹去已经见过的历史。

## 边界

1. 已经被老版本物理删除的历史参与记录不能凭空恢复；没有见证快照的旧记录只能按现存成员与时间资料兼容。新离场记录不会再丢失。
2. 旧提炼没有逐条证据时采用保守失效，可能需要重新提炼。明确遗忘的原文抑制目前以消息为粒度，一条消息内其他细节也可能暂时不参与回忆；记录本身仍保留。
3. 本轮证明本地权限、来源失效和提示词传递；模型是否自然使用记忆仍需真机真实模型验证，不能保证每次措辞都正确。
4. 没有清理用户数据库、没有生成 APK、没有发布。版本号沿用工作区现状。
