# 生活助理质量收尾验收

日期：2026-10-02。范围：生活助理连续办理、结果展示、原生提醒异步收尾与主动协助频率。未出APK、未提交或发布；验收使用隔离数据，不操作用户实际聊天和记忆。

## 修复与最终行为

1. **取消不会被保存成标题。** “不用记了”“算了吧”等结束未执行事项；“暂停一下”等保留待补信息并停止办理。礼貌尾句和语气词不影响独立控制指令。已保存的生活记录不会因取消补问被删除。
2. **暂停后能继续。** 支持直接说“继续”、点“继续处理”，也可跨聊天说“继续，下午三点”。恢复后仍校验原话版本、账号、任期、源消息及目标版本；撤回或改写的来源不能执行。
3. **选择答案能接上。** 时间冲突按钮注明序号；“选第二个”“后一个”等与数字采用同一规则。无效序号继续补问，不调用模型、不写生活记录。
4. **应答与标题分开。** “好的”“收到”“没想好”不会成为标题，也不耗尽来源链。否定短句存在歧义时保留补问；完整新工作指令走正常规划和否定保护。字段输入明确传递“标题：/正文：”，所以确实叫“不要熬夜”的事项可以保存。
5. **手机结果更紧凑。** 简单成功卡片以实际事项为标题，时间和当前状态同排，查看与详情在同一操作排。来源、执行详情和撤销按需展开；12px以上辅助字号和触控目标保留，长标题允许自然增长。390px简单卡片高度断言不超过155px，不裁字压高度。
6. **办事回复短而真实。** 中性成功回执省去重复确认话，五种性格仍有受控短句差异；情绪回应保留，失败、草稿、补问不冒充完成。私聊继续采用非流式回复。
7. **迟到提醒能收尾。** 调度已经获授权但返回时账号已切换，补偿取消该次通知；只修改对应原生回执，不修改生活记录或另一账号。取消失败保存`cancel-pending`，返回原账号后可恢复，不冒充已取消。
8. **主动协助不反复打扰。** 默认关闭。候选查询不消耗展示次数，实际可见后记录；普通一天最多一次新展示，未变化的事项在重开软件后不再重复。明确选择“一小时后再看”可以再次展示；延后到期后不会每次重开都出现。忽略和关闭不改待办。

node scripts/verify/build-secretary.mjs --with-regressions
node scripts/verify/run-secretary.cjs
node scripts/verify/run-secretary-ui-polish.cjs
