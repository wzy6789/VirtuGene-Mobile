# 角色创建改进

后续按用户反馈调整：移除旧记忆选择及创建/试聊时的导入，保留已有角色的记忆；“相遇预览”统一简化为“相遇”。身份示例改用普通身份，步骤去掉数字并保持单行，长标签缩短。下面的初次实现记录包含此前的记忆选择设计，当前界面不再提供该项。

## 用户流程

1. TA 是谁：名字、头像、一句话身份。支持单字名字。
2. 与你相处：用户身份、双方关系、初次相识或已经认识、共同过去；其他角色关系与旧记忆选择折叠呈现。
3. 如何表达：快速描述或精细刻画，参考文件折叠；可调用模型塑造，也可直接使用自己的设定。
4. 相遇预览：大卡片展示候选签名和开场白；选定后可试聊、深入编辑或直接创建。

分步切换保留填写内容并将弹窗滚动返回顶部。原有编辑入口保留单表单，不重新创建人物，不改用户历史记录。

## 关系与记忆

用户身份和关系同时参与生成与最终人物上下文，生成开场白不再强制按陌生人处理。初次相识不携带隐藏的共同过去。

旧记忆默认不选，最多手选十二条，展示内容及来源角色；明确属于用户转述，不能冒充新角色亲历。保存时重新核验账号、active 状态和目标角色归属。重复保存不重复导入同一来源。试聊同样重新读取所选有效记忆。

试聊使用当前配置模型，非流式、仅显式点击调用，不创建 session/message/memory。修改设定后旧预览失效。生成期间改变草稿，不接受旧设定的迟到结果。

## 稳定性与可读性

保存失败保留草稿；辅助写入失败后的重试复用已创建的 id，并更新当前草稿，不重复创建角色。编辑时避免重复追加互动边界。修复不可读的问号错误文案，候选由三窄列改为单列卡片，说明文字最低十二像素。
