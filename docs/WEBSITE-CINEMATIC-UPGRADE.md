# 官网升级记录：电影级沉浸版（动态视觉系统）

这一版是在 `docs/WEBSITE-5.0.5-REBUILD.md`（五段式克制版）之后，按新的要求做的**第二次重度升级**。
信息结构没有被推翻，是在原有导航 / 首屏 / 相遇 / 记忆与关系 / 世界 / 下载之上，
补了「理念」过渡区与「界面」画廊，并把整页从“静态官网 + 一点特效”改成一套**分层的动态视觉系统**。

> 注意：第一版曾按当时的方案**刻意禁掉**全页鼠标追光、全局粒子 canvas、磁吸按钮与 3D 倾斜。
> 这一版按新要求把这些全部做回来了，但都加了强度上限与性能分级，避免变成炫技 demo。

---

## 一、设计思路

主题仍然是「时间留下痕迹，角色因此变得不同。」所有效果都为这句话服务，而不是反过来。

1. **环境是连续的，内容才分区。** 背景由 5 层组成：底雾渐变 → 4 组大型环境光 → 星尘粒子 →
   鼠标光场/核心 → 颗粒。章节之间用柔光雾过渡，纵向不裁切，所以滚动时不会出现黑块断层。
2. **一个世界，不是一个页面。** 页面安静时高级（低密度粒子、缓慢光呼吸），
   一旦鼠标进入就像被“唤醒”（光场跟随、粒子避让变亮、卡片倾斜、边缘高光偏移）。
3. **克制是设计的一部分。** 粒子 85 颗而不是 800 颗；连线只在枢纽粒子近距离时出现；
   卡片倾斜 ≤5°；按钮磁吸位移个位数像素；拖尾只在快速移动时产生。
4. **不是所有东西都动。** 人物位移最大、光晕次之、文字最小；装饰层永远在内容之下。

## 二、动态系统（11 个模块，全在 `main.js`）

| 模块 | 实现要点 |
| --- | --- |
| `Performance` | 先定级 high / medium / low + `reduced-motion`，写入 `<html class="tier-*">`，CSS 与后续模块据此降级 |
| `Ticker` | 全站唯一 rAF 主循环；每个订阅者单独 try/catch，一个出错不拖垮整条循环 |
| `PointerEngine` | 全站唯一 `pointermove` 监听；输出原始位置、慢跟随（0.055 惯性）、快跟随（0.22）、速度、归一化坐标 |
| `ParticleEngine` | canvas 星尘；三种色调 sprite（预渲染径向渐变，避免逐帧建渐变）；枢纽粒子才连线、且要足够近；指针 180px 内微弱排斥 + 亮度提升；速度 > 16px/帧 且冷却结束时才吐短拖尾，上限 34 条 |
| `DepthSystem` | `data-depth` 分层位移；用独立的 `translate` 属性避让入场动画的 `transform`；`.hero-stage` 做 rotateY/rotateX；边缘高光用**人物图自身的 alpha 做遮罩**，所以光只落在轮廓上 |
| `TiltSystem` | 缓存 rect（滚动/缩放时刷新），逐帧计算卡片内相对位置；幅度 ≤5°，离开时用插值回正；反光位置写进 `--sx/--sy` |
| `MagneticSystem` | `data-magnetic` 位移 + `data-spotlight` 光斑；只在指针进入影响半径时生效 |
| `ScrollSystem` | 进度线（transform，不触发布局）、导航毛玻璃、进入动画（先武装再播放 + 滚动兜底）、记忆连接线点亮一次、当前章节高亮 |
| `Tabs` | 原生按钮 + ARIA tab；切换时 `hidden → is-entering → 移除`（强制一次样式读取，保证从 display:none 出来也走过渡）；`data-world` 驱动宇宙层色相 |
| `Lightbox` | 打开/关闭都有过渡（340ms）；Esc / 关闭按钮 / 焦点回到触发元素 / 滚动锁恢复；token 防止旧定时器清掉新图片 |
| `AmbientSync` | 首屏背光对准人物；`visibilitychange` 时给 `<html>` 加 `.is-paused`，所有持续动画停下 |

## 三、性能与降级

| 等级 | 条件 | 表现 |
| --- | --- | --- |
| `tier-high` | 桌面 + 精细指针 + 核心数够 | 85 颗粒子、连线最多 52 条、卡片倾斜 5°、玻璃反光、颗粒、全部环境光 |
| `tier-medium` | 手机 / 触屏 / 核心较少 | 52 颗粒子、连线 26 条、不做 tilt（触屏没有 hover）、颗粒更淡、第二三环不转 |
| `tier-low` | 双核 / 内存很小 / 无精细指针 / `prefers-reduced-motion` | 不启用粒子 canvas、不做指针光场与磁吸、关 blur 与颗粒、关星环旋转、关边缘光 |

另外：canvas DPR 上限 1.5（medium 1.25）；标签页不可见时暂停所有 CSS 持续动画；
所有逐帧效果只写 `transform` / `opacity` / CSS 变量，不碰触发布局的属性（环境背光对齐是 rAF 节流的）。

## 四、验收

`70 项 / 70 通过`（真实 Edge + CDP；脚本 `.tmp-preview/site-verify.mjs`，结果 `.tmp-preview/site/result.txt`）。
在**线上地址再跑一遍同样 70 项**，同样 `ALL PASS`。

其中与"效果真的在动"相关的实测（不是只看 DOM 有没有那个元素）：

| 检查 | 手段 | 结果 |
| --- | --- | --- |
| 鼠标光场被唤醒 | 真实 `Input.dispatchMouseEvent` 后读 `--fx/--fy` 与 `is-on` | ✅ 跟随且有惯性 |
| 粒子系统真的在画 | `getImageData` 统计 canvas 上 alpha>4 的像素 | ✅ 有发光像素 |

| 按钮磁吸 | 读 `.nav-cta` 的 `translate`，要求非零且 <14px | ✅ |
| 进度线 / 导航毛玻璃 | 滚到 50% 读 `scaleX` 与 `is-scrolled` | ✅ |
| 世界切换变色相 | 切到「剧情现场」读 `--cosmos-hue` | ✅ 258 → 232 |
| 六个视口 + 200% 缩放 + 手机横屏 | 横向溢出 / 文本裁切 / 图片比例 / 点击目标 | ✅ 全部通过 |

| 减少动态 | 无隐藏内容、光晕不持续播放、连接线直接点亮 | ✅ |

### 这一轮靠"真的去看"才发现并修掉的问题

1. 首屏标题在 1440px 被挤成 4 行 → 调整列宽比例与字号上限。
2. 人物图带着一块纯黑矩形 → 把纯黑背景抠成**真透明通道**（WebP 带 alpha，401 KB）。
3. 世界面板图片与 `auto` 轨道互为依赖，懒加载完成前宽度解析成 0，**整页会突然下跳 731px** →
   中间列改成固定宽度，CLS 归零。
4. 章节环境光雾被 `overflow: hidden` 裁出一条**横向硬边**，页面出现断层 → 改为只裁横向
   （`overflow-x: clip`），并让光雾渐变自带尺寸、到边缘前就收成透明。
5. 手机端首屏环境光撑出 3~4px 横向滚动 → 收掉移动端的 `overflow: visible`。
6. 验收脚本自身的两个坑：CDP 截图在非零滚动位置用 `clip` 会**全黑**（几张“截图证据”其实是黑图），
   以及平滑滚动导致取坐标时页面还在动 → 都已修正，并保留修正前后的对照说明。
