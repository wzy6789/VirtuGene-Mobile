# 助理文字质感调整 · 2026-10-02

本轮改善中文字形、字重和阅读节奏。旧界面在本机实际上使用微软雅黑，部分加粗标题跳到粗体，辅助文字偏小。此前网页虽然引用联网字体，但字体栈中的中文仍优先匹配系统字体。

## 实现

- 内置 Noto Sans SC 可变字体，使用真实 400、450、500、550 等字重。统一基础 UI 字体栈，助理和设置窗口使用相同字体；场景中显式指定的文学字体保持其原有用途。
- 移除 `index.html` 的外部字体 stylesheet 和预连接，预加载本地常用字形文件。其他支持的字形分片随实际文本加载，完整来源与许可证保存在 `src/assets/fonts/README.md`。
- 弹窗标题 18px / 550；说明卡标题 16px / 550；入口标题 15–15.5px / 500；说明正文 14px；入口辅助文字 13px；时间、状态等元信息约 11.5–12.5px。中文追踪间距归于自然，长说明使用更宽松的行距。
- 数字使用等宽数字、24px / 500，按钮采用适度的中等字重。聊天正文继续使用用户保存的字号，避免字体调整覆盖阅读偏好。
- 验收样式同步本地字体文件，防止截图悄悄回退到系统字体。新增浏览器实际字形检查和离线后的实际按钮字形检查。
