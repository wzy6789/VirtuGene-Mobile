# 私聊流式输出（2026-10-03）

普通角色私聊现在在收到正文时立即显示气泡，并随 SSE 增量更新；发图、语音转文字后的回复复用同一发送流程。支持现有 OpenAI 兼容、Claude、Gemini 协议和 AI 网关。首次仍保留输入提示，首段正文到达后替换成实时回复。

## 呈现与流畅度

- 单独的 `StreamingReply` 订阅 `ChatReplyStream`，历史虚拟列表与 Zustand 消息数组不参与逐片段更新。首段即时显示，后续片段按 32ms 合并，没有人工逐字延迟。
- 使用已有滚动跟随机制与 ResizeObserver：停在底部时跟随增长，用户向上阅读时保持位置，点击回到最新后恢复跟随。
- 模型明确的 `---` 分条保留，并缓冲跨片段分隔符、短动作括号及 JSON 消息封装。已经显示的回复不再被隐藏的质量重试替换，也不在结束时按总长度重新拆分气泡。
- 完成后使用稳定消息 id 保存正式记录，不逐 token 写 IndexedDB。语音模式在后台合成时保留已经显示的文字。

## 中断与隔离

- 输入区提供停止生成按钮。停止和网络中断都保留已收到的正文，并显示相应状态；第一段正文前停止不会伪造回复或把用户消息标成发送失败。
- 同一会话在保存用户消息之前就获得同步锁，避免双击或连续回车产生重复记录。真正失败的请求保留手动重试，复用原用户消息，并保留图片附件。
- 各会话分别维护请求；旧会话结束不会解锁当前会话，返回尚在生成的会话可以恢复预览。账号改变清除旧预览，并拒绝迟到回复写入。
- 页面卸载中断网络，并保存该账号已经收到的正文。网关客户端的停止信号传递到请求；服务端发现客户端断开时也关闭供应商连接。
- 供应商返回普通 JSON 时按同一次请求处理。旧网关缺少流式端点时，在没有任何正文的前提下回退原 JSON 接口。鉴权、额度、限流错误不会因此自动重发。

## 范围

本次改的是普通私聊文字回复。生活助理办事依赖完整结构化计划、实际执行结果和权限校验，回执保持校验后显示；群聊和手账引导沿用各自流程。已有星域流式输出继续使用共享解析器。

不调整版本号、不打 APK、不部署网关。浏览器检查使用隔离来源与模型测试响应；没有调用真实供应商或测量 Android 真机性能。
