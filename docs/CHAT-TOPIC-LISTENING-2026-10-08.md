# 当前话题的倾听要求

## 实测发现与修复

六次 DeepSeek Flash 真实调用使用了三个内置角色，每个角色两轮：疲惫倾诉，以及“不是要建议，吐槽一下而已。对了，我刚拆了包饼干，碎得像沙子😂”。原始结果保存在 CHAT-FLASH-OWN-REACTION-2026-10-08.json，消耗记录在对应 USAGE 文件。共 9,478 token，六次调用，无质检重试或截断。

这些样本仍出现劝休息、复述感受和“听见了”式回应，不能认定人味达标。检查实际会话状态发现，“不是要建议”和“不想要建议”没有进入倾听状态。修复在上述真实调用之后，因此这些样本不能证明本次状态修复的效果。

新增 Session 会话状态 topicAdvice，保存当前话题的明确倾听要求，不改用户原有长期偏好。它进入发送前的实际上下文：不自动附加休息建议、心理分析或处理步骤；跟随用户后来明确提出的任务。旧会话缺少该可选字段时保持兼容，不改聊天原文或生活记录。

同一话题的补充保留状态；明确或检测到的话题转向、结束聊天、具体求助会解除。短期倾听覆盖已有建议偏好，避免在同一提示词中同时要求倾听和直接建议。引用、第三方转述、假设、写作请求、否定和后续明确改口不误作倾听指令。

## 验证与边界

本地验证覆盖上述状态生命周期、JSON 持久化往返、发送上下文和既有聊天链路。类型检查与生产构建通过；请求计量的 22 项真实数据库/替身传输检查通过，未增加模型请求。

当前仍使用保守本地表达线索，无法保证识别所有汉语说法。旧的 adviceStyle 指令兼容原有持久行为；本次没有把所有历史偏好迁移为临时状态。话题变化沿用既有检测，仍有误判可能。模型是否遵守倾听提示，需要独立真实样本，不能以逻辑全绿替代。性格辨识度、长聊漂移和自然情绪表达仍未完成全面验证。
