# 小星 · 原创表情小球预览

2026-10-04。此文记录可复用组件和可交互预览，预览表情由按钮驱动。后续正式 App 已接入助理聊天和行动舱业务状态，详见 [第一阶段接入记录](ACTION-CABIN-IMPLEMENTATION-2026-10-04.md)。这份独立预览不代表语音监听、情绪识别或任务完成。

## GitHub 参考与取舍

- [Rive Web](https://github.com/rive-app/rive-wasm)：参考交互状态驱动和视觉动画分离的组织方式。
- [Motion](https://github.com/motiondivision/motion)：参考连续目标、弹簧动效及手势控制的组织方式；官方维护 React/JS 动画库并采用 MIT 许可。
- [Emotion Ball / aora-bot](https://github.com/sam70361/aora-bot)：其展示说明包含 32 种表情及静态缩略图、视口外停帧的策略。其 [授权说明](https://github.com/sam70361/aora-bot#许可) 对球形形象限制商业使用，引擎也需要相应商业授权，因此本项目只将其作为产品行为参考。

球体轮廓、五官、配色、表情参数和动画实现均由本次独立编写，使用现有原生动效底座；未引入上述项目的源码或角色素材。设计借助本地 `design-md-reference` 的深色层次参考，沿用 VirtuGene 紫青色，而非改变主题品牌。

## 实现

- `src/components/ui/SoulOrb.tsx`：12 种表情，目光跟随、眨眼、呼吸、轻触回应和状态切换；`SoulOrbButton` 提供原生按钮语义和点击取消。
- `src/lib/soul-orb-motion.ts`：共享帧时钟与临界阻尼积分，保留当前姿态和速度接近新目标，帧内不更新 React 状态。
- `src/styles/soul-orb.css`：原创 SVG 的色彩和容器样式，已从 `src/main.tsx` 导入。
- `docs/prototypes/soul-orb.tsx`：演示宿主、主题、减少动效、键盘和表情选择。
- `docs/prototypes/soul-orb.html`：独立 HTML，包含演示代码、CSS 和项目已有的中文字体，可离线查看。

表情包含待机、好奇、倾听、思考、忙碌、开心、惊讶、害羞、困倦、低落、遇到困难、完成。业务状态切换优先于短暂的轻触回应；缩略图使用静态渲染，小尺寸五官单独放大保证可读。

背景、失焦、离开视口、系统及应用减少动效会释放动画时钟；静态模式仍显示当前表情。背景观察器也不能重新启动失焦实例。卸载释放观察器、事件订阅与帧回调。

SVG 五官形变涉及小面积矢量重绘，不能声称整段均由 GPU 合成或保证所有设备 60fps。正式接入前仍需手机上的帧时间与耗电实测。

## 本轮评审整改

- ORB-1：指针事件中读取当前视口矩形，滚动、键盘引起的页面移动、父容器位移不再沿用旧位置；动画帧中不测量布局。
- ORB-2：互动实例监听窗口内的主指针，球体附近的鼠标及触控都可驱动目光；超出附近范围按距离平方衰减，远处不吸引目光。减少动效、失焦、后台及视口外仍停止互动动画。
- 缩略图：倾听增加侧边声波，思考增加头顶气泡和大轨道节点，忙碌使用眯线眼，低落下沉并增加泪滴，惊讶使用深色张嘴；困倦和完成分别增加睡眠标记及星光。特征透明度、嘴型、眉眼和轨道节点继续走同一套阻尼插值。
- ORB-3：正式样式入口已导入小球 CSS。SVG 内容限制在 256×256 视图框，容器使用布局与绘制隔离，避免外溢重绘。
- ORB-4：核心小球保留装饰语义，Props 注释写明宿主契约；新增原生 `SoulOrbButton`，提供明确名称、焦点指示、至少 44px 触控目标及 Enter/Space 激活。
- 误触取消：滑动超过 10px、按钮外松开、取消触控或失焦均取消宿主点击和轻触表情；移出后再移回不会恢复点击。业务状态切换仍优先于临时轻触回应。
- 参数改为具名姿态字段；预览增加实际 40px 缩略图模式和双球同屏模式，仍不增加帧内 React 提交。

### 接入用法

```tsx
<SoulOrbButton
  emotion="listening"
  size={48}
  label="打开助理"
  onActivate={openAssistant}
/>
```

纯展示使用 `<SoulOrb emotion="thinking" size={40} animated={false} />`，宿主另外提供可读的业务状态。核心组件不承担独立按钮语义，不向读屏重复朗读装饰表情。

产品内引导仅介绍五个核心状态：待机、思考、忙碌、完成、遇到困难（`SOUL_ORB_CORE_STATES`）。保留 12 种表情，其余作为可选互动表现；不将小尺寸特征补偿解释成“12 种都能稳定辨认”。聘用引导已同步，正式业务结果仍以事项状态和办事记录为准。

正式助理聊天、行动舱入口、标题和空态已经接入小球；`soul-handoff` 已补充受控 SVG 快照、渐变 id 重命名与减少动效降级。接入验证见第一阶段记录；本篇下方 70 项仍是小球组件自身的检查。

Chrome 浏览器 70 项检查通过：包含原有 12 种表情、动画帧零 React 提交、静态缩略图、320/390/430px、后台/失焦/视口外停帧、两种减少动效、快速切换和离线零外部请求；新增滚动及父容器移位后的目光定位、球体外附近指针与原生触控跟随、远距离衰减、Enter/Space 与可见焦点、拖动后移回/短距离滑出后移回/取消触控后的点击拦截、原生触控轻触和纵向滚动、40px 互动球的 44px 触控目标、双球共享时钟和零帧内 React 提交，以及小尺寸特征和浅色文字对比度。TypeScript 和 renderer 生产构建通过。

人工查看了 40px 深浅色表情矩阵、390px 窄屏和双球同屏截图，确认特征没有被视图框裁剪。脚本输出双球同屏的桌面浏览器 rAF 间隔，数值受浏览器和运行环境影响，不等同于 Android WebView 的 CPU/GPU 帧耗时。真机应分别测量聊天头部单球与头部 + 空态双球，包含连续输入、键盘弹起、快速滚动及后台恢复。
