## 设计令牌

统一入口为 `src/styles/theme-tokens.css`，组件呈现层为 `src/styles/ui-v2.css`。深色使用低亮度极光表面与顶部高光，浅色单独设置纸感表面和阴影。

| 组 | 令牌 | 用途 |
| --- | --- | --- |
| 表面 | `--vg-elev-0/1/2/3` | 页面、卡片、重点卡、弹层 |
| 描边与阴影 | `--vg-elev-edge`、`--vg-elev-highlight`、`--vg-elev-shadow-1/2/3` | 深浅色独立调校 |
| 间距 | `--vg-space-1/2/3/4/6/8/12` | 4/8/12/16/24/32/48px |
| 圆角 | `--vg-radius-1/2/3/4/5/pill` | 8/12/16/20/28px、全圆 |
| 时长 | `--vg-motion-fast/medium/slow` | 120/200/320ms |
| 曲线 | `--vg-motion-standard/spring/decelerate` | 标准、回弹、减速 |
| 字阶 | `--vg-type-title/body/caption/micro` | 22/14/12/12px，配套行高 |
| 展示数字 | `.vg-display-number`、统计区 strong | 34px、600 字重、等宽数字 |

## 本轮落地

- 助理今日重点卡增加 3px 状态能量条：逾期红、今日紫、等待青。行动事项、待办、收件箱、通用弹层与反馈通知消费高度令牌。
- 四个统计数字放大至 34px，保留真实计数；渐变分隔线仅作装饰，不伪装成进度百分比。今日及逾期计数采用胶囊说明。
- 页头在滚动超过 32px 时进入紧凑态，小球与名称持续可见。保留页头高度，避免滚动内容跳动；头像和副标题用 opacity/transform 淡出。Web 使用玻璃表面，native 使用不透明表面降级。
- 行动页、收件箱、消息列表新增共享骨架屏；行动页和收件箱采用“小球、主文案、说明、主按钮”空态。
- 新增 40 个语义 SVG 的 `Icon`，24px 网格、1.5px 描边。`SecretaryIcon` 作为兼容导出保留。助理、行动页及选定世界/角色/设置入口改用统一图标。
- 主、次、幽灵、危险按钮统一层次与按下反馈；重点卡的小操作按钮与状态标签统一圆角节奏。
- 完成事项只在保存成功后触发行内勾选回响、页头 success 表情及已有成功触觉。短暂装饰不等待、不阻塞撤销，不克隆任务正文。
- 今日清空时沿用真实计数更新，空态小球可接收页头小球的接力；讨论事项时横幅从任务位置作有界位移展开，小球切换 thinking。返回消息列表补齐反向小球接力。
- 失败通知仅脉冲一次。有限装饰动画最大 320ms，可响应运行中的减少动效切换与页面隐藏。
- 聊天气泡采用自己侧不对称圆角与长短文内边距；流式标记替换为微缩小球。装饰小球不注入消息 textContent，也不改变保存前后的气泡布局。发送按钮增加短暂 happy 回应。

对话隐藏不卸载、讨论源版本核对、请求分类及任务保存契约保持现有行为。本轮未增加运行时依赖，未修改数据库与业务查询规则。

## 后续迁移边界

令牌与公共组件已经建立，本轮不是全站旧 CSS 的一次性重写。全站剩余文字符号、间距魔法数、其他空态和世界/角色卡片仍需按组件继续迁移。页头尚未改变实际高度，底部导航未新增结构；统计数字没有人为延迟归零。重渲染关系星图与场景画布保持现有实现。

### 记忆碎片与换一批

按最新设计要求，预览改为三张切角碎片，以紫/青/暖色微染色、随机横向错落及轻微倾斜呈现，正文最多六行，全文仍在完整档案。选择改为从当前账号/角色全部有效记忆中随机抽取最多三条，同批不重复；存在未展示记录时，“换一批”保证换入不同记录，否则打乱现有记录顺序。只有一条时禁用换批，不编造补足。

换批使用公共 animateVisual 的 200ms transform/opacity 过渡，快速换批取消上一次动画；系统/应用减少动效下直接更新，并去掉卡片倾斜。角色/账号隔离、撤回记录过滤、档案关闭后的重新读取保持。TypeScript、生产构建（3.82s）、17 项集成检查和 CSS 预算通过，检查确认四条候选随机展示三条、唯一性与换入不同内容。深浅色截图已刷新；CSS gzip 总量 75,874 B，较基线增长 6.63%。
