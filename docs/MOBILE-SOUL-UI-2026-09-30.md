# 手机版主题与聊天精修 · 2026-09-30

本轮在 5.2.8 工作区的现有 UI 改动上继续精修。目标是强化紫青色数字生命主题、聊天材质和导航连续性。

## 实现

- `src/styles/mobile-soul.css` 是最终手机样式层，在 globals、mobile-refinement、mobile-aurora、physical-interactions 后加载。统一深空与浅色主题的底色、文字、面板、边缘光和触摸目标；修复浅色「此刻」标题对比度。安卓状态栏仍用品牌深色，以匹配原生固定白色图标。
- `SoulAtmosphere` 提供固定紫青氛围光、轨道和六个信号点。背景不随列表滚动，只在 transform 和 opacity 上做缓慢动画；装饰不接收指针、不进入无障碍树。
- 聊天气泡增加渐变面板、微光边缘和柔和阴影；时段背景与细点阵共存。聊天标题展示现有关系状态，生成回复时展示动态信号。输入区域增加聚焦光轨，返回与发送按钮至少 44px。
- `useMobilePageMotion` 根据一级导航顺序与页面深度确定入场方向，使用单一 260ms 原生浏览器动画。快速导航、视口变化、切后台、减少动态设置变化及卸载会取消旧动画。既有手势层继续负责跟手和退场。
- 底部导航使用连续移动的光感胶囊；未读数、覆盖页与键盘隐藏行为沿用原逻辑。
- 取消历史消息和每条气泡内容的重复入场，只为原逻辑标记的新消息保留 220ms 入场；世界入口不再叠加延迟入场。录音与取消状态保持可辨识。
- 系统减少动态设置关闭装饰、导航和页面动画；页面隐藏时暂停装饰动画。

## DESIGN.md 参考后的选择性精修

采用本地 `design-md-reference` skill 的参考原则，保留 VirtuGene 的紫青主题、光轨、数字生命装饰和既有手势。

- 参考 Linear 的面板层次：区分页面底色、内容面板、凹入搜索/输入区和凸起导航/聊天工具栏，降低普通卡片的阴影与渐变强度。
- 参考 Stripe 的色彩分工：环境光与操作色分开。新增角色和发送使用明确的品牌紫，普通卡片主要使用中性色，世界入口保留局部色光与各自图标色。
- 参考 Apple 的手机阅读顺序：世界页拆为 `LIVING WORLD` 小标签与「世界」主标题；角色快捷入口增加线性图标，个人卡片减少无效高度。
- 参考 ElevenLabs 的安静阅读面板：聊天点阵降低对比，角色消息使用微光中性面板；输入框增加独立边界与聚焦反馈，空草稿发送状态采用中性色。
- 保留原有多选标签、按压光感、字号标尺和录音变形；录音展开时移除输入区间距，避免隐藏控件挤占空间。
- 版本信息加载前使用占位符，避免短暂显示旧版本。

验收新增主操作文字与发送图标对比度、输入框聚焦反馈、个人页宽度与身份信息、世界/角色/设置触摸目标检查。深浅主题的五个页面截图位于 `.tmp-preview/design-reference-20260930/after/`，优化前截图留存在同级 `before/`。截图使用本地测试角色，无真实账户或模型请求。

本次类型检查和正式构建通过；六个 UI 回归套件通过。mobile-soul 普通模式 216 项、减少动态模式 210 项通过，physical-ui 23 项通过。截图覆盖深浅两套主题，无横向溢出或浏览器异常。浅色个人页的青色标注另外调整为主题可读色。
