# 手机端即时交互改造

## 实际入口

| 交互 | 位置与行为 |
| --- | --- |
| 多选筛选 | 角色页「性格筛选」。同组标签按任一匹配筛选，叠加搜索/我的角色条件；勾选撑开、填色，计数跳动，筛选按钮清空选择。 |
| 删除标签 | 角色创建/编辑的性格标签、日记标签。先缩成点，再删除；相邻标签及输入框高度补位。异步删除读取最新值，连续添加不会被旧快照覆盖。 |
| 输入联想 | 上述标签框。以光标位置为锚，输入实时匹配；支持方向键/确认/关闭，中文输入法确认不会误插入。浮层避开视口和键盘。 |
| 字号刻度 | 私聊/群聊输入区聚焦时出现，12–22px；拖动即时改变气泡与输入文字，松手吸附。默认14px，选择保存到设置，草稿保留。 |
| 按压卡片 | 世界的朋友圈/日记/待办/星域四个入口。按触点轻微倾斜、收拢光斑；松手复原，拖动超过10px撤销按压及点击。 |
| 录音变形 | 手机聊天输入区的加号与麦克风。长按300ms启动，实际录音电平驱动波形；松手转写发送，上滑64px取消。也支持点击开始/停止及加号取消。 |

## 交互约束

- 横向标签、联想、字号刻度、录音入口标记为不触发页面切换/返回手势；卡片继续允许纵向滚动。
- 特效主要使用 transform、opacity、轻量背景及局部布局动画；不增加循环模糊滤镜。系统减少动态设置生效。
- 字号仅在整数刻度变化时保存，避免每个像素的拖动都写本地存储。
- 录音异步操作有代次和原生占用锁：释放手指后返回的权限/启动结果不能继续录音或发送，切页后不能让两个输入区同时占用麦克风。
- 恢复按钮组后，转写进度显示在麦克风中；文字草稿不被录音覆盖。识别无有效文字时不发送伪造语音文本。
- 本次没有修改消息、记忆数据表或模型聊天请求方式。
