# 七种手势交互落地 · 2026-10-02

根据用户提供的七种交互说明，选择已有操作场景接入，保持深色主题、真实业务状态与可撤回的手势。

| 技巧 | 落地位置与行为 |
| --- | --- |
| 跟手返回 | `SwipeBackView` 的移动浏览器页面允许从左边缘开始，位移直接跟随手指。判断当前距离、最近释放速度与方向；达到距离后反向撤回也会取消。Android 原生系统边缘保持由系统管理，避免重复触发返回。 |
| 按钮滑出取消 | App 内普通按钮通过捕获阶段记录按压，滑出后显示取消状态；外部松手取消点击，回到按钮内松手仍可点击。键盘和程序触发不受影响，录音等专用手势按钮保留自己的处理。 |
| 文字局部过渡 | 角色页的角色数量、筛选计数只动画变化的数字；“位”“筛选”等静态文字及控件不动。相同值不触发动画。 |
| 手势方向锁定 | 朋友圈真实大图预览。明确横向后仅翻图，后续斜向移动不会触发关闭；明确纵向后仅下拉，后续横移不切图。模糊方向先等待意图。 |
| 动画中途接管 | 页面回弹、图片翻页/边界回弹和大图下拉关闭，可在动画期间从当前显示姿态重新抓取。关闭动画完成前重新按住可取消关闭。 |
| 落点预览 | 聊天字号刻度拖动时标出最近刻度并显示“松手选 N px”；松手吸附该刻度，字号继续即时保存和预览。 |
| 边界阻尼 | 字号刻度 12–22px、图片首尾和页面边界，越界越难拉动，松手回弹。没有把阻尼强加到虚拟聊天历史等滚动容器。 |

新公共组件：`src/components/ui/useSlideOutCancel.ts`、`AnimatedValue.tsx`、`ImagePreview.tsx`。原有 `PhysicalInteractions.tsx` 和 `usePageSwipe.ts` 承接字号及返回逻辑，角色页和朋友圈使用真实入口。大图保留键盘左右键、Escape、关闭及翻图按钮，切换账号立即移除原账号预览。
