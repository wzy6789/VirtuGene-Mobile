# 手机版过渡动效 · 2026-10-01

本轮解决旧页面立即消失、侧滑归零后重新入场、弹窗关闭没有收尾，以及一级页面首次加载打断切换的问题。

## 实现

- `mobile-motion.ts` 提供临界阻尼的采样关键帧：起步柔和、连续减速、无位置过冲。页面、手势回弹和底部面板共享响应方式，使用不同距离和时长。
- 页面入场 360ms，旧画面退场 240ms；导航内容变化与旧画面交接同时开始。一级页小幅横向切换，详情页位移稍大，返回方向相反。
- 退场保留一个 DOM 视觉副本，实际旧页面仍正常卸载，不保留请求、订阅或录音生命周期。副本 inert、aria-hidden，删除控件语义，不接收事件，不播放装饰动画。
- 快速切页会取消旧动画并清理旧副本，每次最多保留一个页面退场画面。结束、窗口尺寸变化、切后台和减少动态偏好变化都清理画面与临时 will-change。
- 侧滑使用连续阻力而非硬限幅；松手后的 220ms 动作保留当前位置，页面副本接住祖先手势层的实际位移；取消手势使用 260ms 阻尼回弹。
- 底部操作面板入场 360ms、背景渐入 160ms；关闭使用 180ms 画面退场，即使调用方直接卸载 Modal 也有收尾。退场副本不占有实际弹窗焦点或返回栈。
- 全高表单保持位置固定，入场只改变透明度。滚动偏移在画面副本插入后恢复，避免关闭时内容跳回顶部。
- 底部导航胶囊与图标分别使用柔和移动和轻微回弹。关闭画面最多保留一层，重新打开、尺寸变化、后台和动态偏好变化会清理它。
- 「角色」和「我的」作为一级页直接加载，避免首次切换时 Suspense 替换整个切换层。相应代码进入主包，换取第一次导航连续；日记与待办等次级内容仍按需加载。
- 大型 DOM、canvas 和视频页面跳过画面副本，仅使用当前页入场，避免额外绘制和空白 canvas。减少动态模式不创建退场画面或位置动画。

## 验证

- TypeScript 和 Vite 正式构建通过。既有较大主包及静态/动态导入混用提示仍存在。
- 八个 UI 回归套件通过；修改后再次核对 mobile-soul、ui-polish、swipes、character-scroll、character-create、mobile-refinement。
- mobile-soul 普通模式 219 项、减少动态模式 211 项；ui-polish 普通模式 104 项、减少动态模式 103 项通过。
- 浏览器实际触摸事件验证侧滑的画面交接位移；核对快速连点、退场副本数量、关闭后无活动 dialog、长表单关闭时保持滚动位置和副本清理。无浏览器异常。
