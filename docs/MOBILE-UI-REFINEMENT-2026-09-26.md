# 手机界面精修 · 2026-09-26

方向：安静的科幻感，内容优先，保留数字生命的紫色与青色气息。

- 消息：缩短标题与介绍区，统一行高、姓名与预览字号；时间靠右，置顶轻量标识，修正群聊列表头像裁切。
- 聊天：柔和环境背景、轻边缘气泡；正文保持 14px，每条连续消息保留头像，限制长文本宽度。
- 世界：首页四个独立入口统一材质与间距，以图标区分色彩；保留星域内的星图与动态效果。
- 角色：关系与群聊入口统一，列表突出头像与名字，保留创建、编辑、删除及星图逻辑。
- 我的与设置：用户卡与设置分组减少装饰、套卡和阴影，深浅主题使用同一套主题变量。
- 左滑：收起时隐藏底层操作按钮，消除圆角处的红色露边；展开与点击收起流程不变。

样式集中于 `src/styles/mobile-refinement.css`，在全局样式之后加载。桌面界面不应用这些手机样式。未修改数据库、记忆、模型请求、角色设定或版本号。

验收：类型检查、Vite 构建；真实浏览器验证深浅主题与 360/390/430px 宽度、连续头像、长文本、左滑；回归角色操作、创建页滚动、群聊布局与关系星图。截图使用隔离测试数据，不修改用户浏览器数据。

尚未生成 APK，未发布官网。手机真机帧率与键盘行为仍需安装包验证。
