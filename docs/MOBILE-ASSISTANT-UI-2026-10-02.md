# 助理界面精修

延续已确定的紫色与青色主题，以及首页助理入口默认收起、点击展开的交互。参考本地 design-md-reference 的 Linear 分析，将助理界面的视觉层次统一为安静的背景、清晰的内容卡片和明确的主要操作。

主要变化：

- 聊天快捷办事统一使用线条图标和 48px 点击区域，收件箱和管理入口采用简洁的按钮排版。
- 工作台概览增加数字层次和分隔线；未聘用入口采用线条头像占位。默认入口保持 84px 内容高度。
- 办事结果采用图标标题、细分隔线和独立操作区；已完成、草稿、待补充、未完成、已撤销有各自的状态表达，保留文字说明。
- 工作台菜单采用图标、标题与用途说明组成的操作行，现有操作与无障碍名称保持可访问。
- 收件箱区分请求原文和结果卡片，分类按钮提供独立数量标记与明确选中状态，空分类增加图标提示。
- 助理管理采用头像、姓名、聘用状态与记录说明组成的资料卡；姓名、性格、形象、历史聘用记录共享统一表单材料。
- 每日整理与办事习惯统一资料选择、输入框、数字概览和主要按钮。朋友圈发布范围在窄屏使用整行下拉框，待办日期和时间在 320px 屏幕分行显示。
- 保留可见焦点和减少动态效果支持，不增加持续背景动画。

代码：`src/styles/secretary-ui.css` 为助理专用样式，`SecretaryIcon.tsx` 为复用 SVG 图标。样式通过助理专用类限定范围，未重写办事、发布、聘用及资料读取逻辑。

验证：

- TypeScript 检查与 Vite 生产构建通过。
- 助理回归 331 项数据检查、92 项界面检查通过，覆盖真实保存、发布、撤销、管理、聘用、工作习惯与原有收起展开流程。
- mobile-soul、ui-polish、swipes、character-ui、character-scroll 五个套件通过。
- Chrome 触屏预览检查浅色/深色、320/390/430px、快捷入口草稿填充、管理与形象选择、收件箱与朋友圈草稿、每日整理及办事习惯；没有横向溢出或运行时错误。
- 截图存于 `.tmp-preview/secretary-polish-20261002/`，其中包含聊天、菜单、管理、形象、收件箱、草稿、每日整理、办事习惯和展开工作台。

本轮为前端界面修改，未打包新的 Android 安装包；真机键盘和帧率未实测。
