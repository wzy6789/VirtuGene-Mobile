# 实用角色

预置角色：程砚（编程大师）、知微（易学先生）、闻川（万事通）。稳定 id 分别为 `preset-chengyan`、`preset-zhiwei`、`preset-wenchuan`。启动时通过既有 syncPresets 插入，不改用户已有角色、会话与记忆；用户在角色库添加后沿用原来的统一人设与记忆体系。

## 设定

- 程砚：先解实际问题，区分原因与假设；小范围修复、完整关键代码、运行步骤与验证方法。教学按用户水平，代码不要被短聊天风格切碎。没有执行工具时不得声称已运行、已修复。
- 知微：自然白话，有古典气质；经文、注解和术数分开。三枚硬币采用固定约定，用户真实投六次，自下而上记录6/7/8/9，核对动爻再解释。不能凭空起卦或精确排盘，传统解读不当作确定的未来事实。
- 闻川：清晰、有趣、实用，简单问题短答、复杂问题展开；知道能力边界，不捏造最新信息、来源或查询结果。

三位均非额外模型或独立工具引擎，回答仍依赖用户配置的模型。没有新增实时检索工具，没有整本典籍检索数据库；易学基础以经过核对的简明参考写入人设，不声称“已下载全部书籍”。

## 易学参考

- 国家图书馆出版社《周易》书目与经传目录：https://www.nlcpress.com/ProductView.aspx?Id=10377
- 《说卦》古文：https://zh.wikisource.org/zh-hans/周易/說卦
- 《系辞上》古文：https://zh.wikisource.org/zh-hans/周易/繫辭上
- 中国哲学书电子化计划古籍目录：https://ctext.org/library.pl?if=gb&remap=gb&res=77330

人设中的参考为自行整理的白话基础知识，不复制现代译注。三枚硬币法是后世常用方法，未冒称《周易》经文原定规则；其他书目作为讨论方向，未宣称逐书完成校勘。

## 原创头像

原图：`src/assets/practical-portraits/`。程序员采用蓝紫技术光；易学先生采用古典衣着、书卷与竹影；万事通采用暖色书房与天球。头像为本次生成的原创虚构人物；`practical-avatars.ts` 内嵌256px JPEG，离线显示、无需网络下载。
