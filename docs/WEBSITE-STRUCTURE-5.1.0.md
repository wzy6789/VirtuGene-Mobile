## 一、围绕一句话重排页面

理念只有一句：**让数字灵魂拥有时间。** 所有内容只证明四件事：
角色有自己的性格和表达方式 / 会记住共同经历 / 关系会因为真实发生的事而变化 / 多个角色生活在持续运行的世界里。

页面顺序（电脑与手机同一套）：

```
导航 → 首屏 → 对话 → 记忆 → 世界 → 界面 → 下载 → 页脚
```

**取消了独立占据一整屏的「理念四条」**，理念内容分别并入三段：

| 原理念条目 | 现在在哪里 |
| --- | --- |
| 角色有自己的性格和表达方式 | 对话段（两条能力 + 一句原则说明） |
| 角色会记住共同经历 | 记忆段（三步演示） |
| 关系会因为真实发生的事而变化 | 记忆段说明（"不是一个进度条"） |
| 多个角色生活在持续运行的世界里 | 世界段说明（"每段剧情都有自己的时间、地点和参与者"） |

导航相应改为：理念 / 对话 / 记忆 / 世界 / 界面 / 下载。手机端只保留 Logo 与「下载」，
其余入口收进右上角菜单，导航条两端对齐。

## 二、四个阶段做了什么

### 第一阶段：必须修复

- **版本升到 v5.1.0**：两处 Android 下载都指向
  `releases/download/v5.1.0/app-release.apk`，页面上不再出现 `v5.0.5`（自动化检查会拦）。
  实测该资产真实存在：HTTP 200，4,041,296 B（约 3.9 MB），versionCode 21，minSdk 24，
  签名与 5.0.4/5.0.5 同一把证书（老用户可覆盖升级）。
- **换行修复**：`.platform-meta` 用 `word-break: keep-all`，「Android 7.0 及以上」的「以上」不会被拆开；
  首屏可信信息同样不拆。
- **替换空白剧情截图**：剧情截图换成「雨夜便利店」——两名角色（古月娜、艾莉）、
  两句动作描写、两轮对白、一个选择、时间与地点、明确的「退出」入口，来自当前 5.1.0 真机界面。
- **下载链接逐个实测**：Android v5.1.0 app-release.apk 与 Windows v2.1.0 exe 均 HTTP 200，且桌面端
  `/releases/latest` 返回 v2.1.0（没有假定两端版本一致）。

### 第二阶段：移动端重排

- 删除独立理念长屏；对话区前移到首屏之后。
- 界面区在手机端改成**单张横向滑动**（宽度 82%，左右露出下一张边缘），不再纵向堆四张大图。
- 记忆演示在手机端改成**分页滑动 + 圆点**，一次只展示一步和一张大图。
- **页面长度**：390×844 从 8366px 降到 **7446px**；430×932 为 7599px。
- 导航栏改为两端对齐，`Logo — 下载 + 菜单`。

### 第三阶段：核心展示

- **记忆三步演示**（这一版最有辨识度的交互）
  - 电脑：左侧三步可点（第一步 你提到一件重要的事 → 第二步 它成为共同记忆 → 第三步 角色在之后自然想起），
    右侧手机画面 300ms 淡入 + 位移一起切；连接线亮到当前步骤。三步内容分别是
    `“周五我要去面试。”` → `周五有一场面试 / 来自你们的一次对话` → `“面试怎么样了？”`。
  - 手机：三步横向分页，左右滑动或点圆点切换。
  - 键盘：方向键 / Home / End 可切换（`role="tab"` 语义）。
- **世界区默认直接展示星图**：中央「我的生活」，周围三段剧情
  （雨夜便利店 / 天台夜谈 / 冰原重逢），节点不规则分布、不互相覆盖、标签 14px、
  连线细而不亮；正在继续的剧情节点有呼吸光效，已暂停的变暗；
  点任意节点，右侧显示剧情 / 地点 / 角色 / 时间 / 最近片段。
  标签从「世界星图 / 剧情现场 / 留下的经历」改成 **星图 / 剧情 / 时间线**（字号加大、按钮变窄）。
- **真实对话按指定剧本重截**（同时表现人味、记忆和话题切换）：
  今天有点累。→ 那就先别逞强。/ 你上次面试前也是这样，嘴上说没事。→ 你居然还记得。→
  我记得的事，比你以为的多。→ 对了，周末想去看海。→ 那就去。/ 别又临出门才找耳机。
  每条 AI 消息都有头像，没有模型名或调试文案，画面里只有 6~7 条消息。

### 第四阶段：精修

- **首屏人物底部**按标准渐变收口
  （`black 0% / black 76% / rgba(0,0,0,.75) 86% / transparent 100%`），
  再叠一层淡紫雾光，裙摆消失在背景里，不再有横向亮边。
- **三种区域氛围**（不再每屏都是同一种紫色星空）：

  | 区域 | 氛围 |
  | --- | --- |
  | 首屏 | 最强紫色星空与人物光效 |
  | 对话 / 记忆 | 更深更安静，环境光降到 50%，粒子减少且变淡 |
  | 世界 | 蓝紫为主 + 少量青色（星云里加了一层青色径向光） |
  | 界面 / 下载 | 干净深色，环境光降到 32%，光晕更弱 |

  粒子密度与亮度随氛围变化（不是只调透明度）；移动端粒子数量约为桌面的一半；
  关闭大面积持续模糊；光效只服务于人物、当前剧情节点与按钮；
  开启「减少动态效果」时不武装动画、不播放呼吸与漂浮。

- **移动端字号标准**：首屏 42px / 章节标题 32px / 正文 16px / 辅助 14px / 最低 13px，
  行高 1.65~1.8，左右边距 20px，按钮最低 48px（下载主按钮 52px）。
- **中文断行**：`text-wrap: pretty` + 关键位置人工换行 + 元信息 `keep-all`；
  自动化检查会逐行测量，出现「单个汉字独占一行」或「『上』单独换行」直接判失败。

### 这一轮靠"真的去看"发现并修掉的问题

1. 横向滑动容器里的 `loading="lazy"` 图片浏览器**根本不会请求**，滑到时会出现空白帧 →
   在世界/记忆/画廊滑动区接近视口时预热（`ScrollerWarmup`），实测所有图片都能解码。
2. 世界区换成星图后，三个面板高度从 421px 到 841px 不等，**切换时页面会跳 420px** →
   桌面端把面板容器固定为同一高度，星图铺满该高度；切换高度差归零。
3. 手机端 `.memory-demo` 是 `display:none`，伪元素的 transform 在无渲染盒时退化为 `none`，
   让「减少动态」的断言失去意义 → 改成直接检查连接线状态与过渡时长。
4. 12px 的说明文字（节点状态、示意图说明、步骤序号等）低于本方案 13px 底线 → 全部提到 13px。
