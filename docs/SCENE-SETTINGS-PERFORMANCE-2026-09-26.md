# 此刻设置展开与收回

发现：原面板使用 grid-template-rows 的 300ms 动画，设置内容在聊天 flex 布局里展开，每帧改变列表可用高度。长内容会挤压甚至几乎隐藏聊天列表；收起内容也留在 DOM 中。

修改：改为锚定此刻入口的独立 portal 浮层，内容独立滚动。开合只使用 transform 与 opacity，关闭动画结束后移除。光晕、纹理与时段背景保留，以径向渐变表达柔和光晕，避免滚动期间的大面积模糊计算。窗口与软键盘可视区域变化时重新定位，不在滚动每一帧触发 React 更新。

关闭支持收起按钮、外部点击与 Escape；键盘焦点限制在面板内并在收回后返回入口。切换会话或卸载会清理关闭计时器。未修改消息时间、会话设置存储或记忆。

验收：类型检查、构建；真实浏览器重复开合三次，检查聊天区尺寸不变、浮层边界、特效层保留、关闭动画、浮层释放及焦点恢复。mobile-refinement 合计 123 项通过。手机硬件的实际帧率仍需真机体验验证。
