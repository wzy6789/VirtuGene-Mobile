# 删除与操作提示 UI 检查

本次全量检索正式源码中的删除、移除、清空、回收站、忘记记忆和操作提示入口，保留已有数据操作规则。

## 统一的提示

- `FeedbackNotice`：18px 圆角、不透明主题底色、细边框，14px 中文正文，成功／信息／失败使用线性 SVG 图标与语义色。关闭和操作按钮至少 44px。
- `FeedbackHost`：全应用共享一个临时提示，新操作替换旧提示；相同文字也产生新的编号与计时。页面跳转后仍能看到操作结果，旧计时器不能关闭新提示。
- 进场 280ms、退场 170ms，仅变化位移与透明度，复用项目临界阻尼曲线。退场中的提示可从当前位置接续新提示；系统和应用减少动效立即生效。
- 普通提示 3.6 秒，失败／长文案 5.6 秒；键盘焦点或鼠标停留时暂停消失。切换账号和进入后台会清理临时提示。
- 提示位于导航上方，窄屏自动换行，宽屏限宽 440px。监听可视视口，使键盘覆盖屏幕时提示上移。
- 行动舱撤销入口仍为持久的页面提示，使用相同视觉组件。读取／操作失败时优先显示失败卡片，撤销数据保留。
