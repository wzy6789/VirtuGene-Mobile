# VirtuGene 5.1.0 Living World 2.0 · Phase 1

本阶段落地世界内核基础；自主行动由 Phase 2 文档单独记录，不改变私聊和群聊的既有数据结构。

## 已完成

- Dexie v19 增加 `worldLocations`、`worldPresences`、`worldAgentStates`、`worldPulses`。
- `World` 增加逻辑时钟、现实锚点和最近脉冲时间。
- 旧世界升级时自动补齐「我的生活」地点和逻辑时钟，迁移幂等。
- 旧剧情按地点投影；进行中的角色写入唯一当前位置；同步不会调用模型，也不会新增世界事件。
- 创建剧情、换地点、召集和离开角色会同步地点与位置状态。
- 世界主页显示世界天数、地点数量和当前在场角色数量。
- 增加待处理世界脉冲 API：只登记真实经过的时间，AI 失败时不编造事件（完整行动链见 `5.1.0-WORLD-PULSE-PHASE2.md`）。

## 约束

- 应用关闭期间不在本地后台运行模型；重新打开时由后续阶段处理 pending pulse。
- 旧事件的 `locationId/worldTime/causeEventIds` 保持可选，保证旧备份和旧迁移数据继续可读。
- 脉冲行动与可见反馈已在 Phase 2 实现；脉冲事件到角色认知与私聊召回的闭环见 Phase 3。

## 验证

- `tsc --noEmit`：通过。
- `vite build`：通过（292 modules transformed）。
- 验收脚本已重新打包；浏览器批量回归因当前环境没有可执行 Chrome 路径未运行，不代表产品断言失败。

Phase 3 已把脉冲事件接入角色可见认知与私聊召回，并加入会话内行动冷却；下一步可在真机反馈后再调整跨会话衰减和因果链。
