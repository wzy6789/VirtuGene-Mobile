# VirtuGene 5.2 世界内容升级

这次升级的目标是让「世界」成为一个会记得、会变化、会自己生活的空间，而不是把私聊窗口换成另一种背景。

## 已落地的核心闭环

### 1. 每一轮都是一个可演出的节拍

世界轮次现在会为环境、动作和对白写入同一个 `beatId`，并记录层级、顺序与镜头提示。正文仍只写入 `worldSceneEntries`，所以旧的私聊、群聊和消息摘要不会被污染。

渲染时继续使用非流式输出，但在本地按节拍依次出现：环境先建立画面，动作让角色“在场”，对白最后落下。不同角色之间会留下呼吸时间，同一角色的动作和台词也不会挤成一条机器式长回复。

### 2. 对话有短期节奏状态

`WorldScene.state.conversation` 保存当前话题、最近话题、已经反复使用的意象、换题标记和连续轮次。它不保存完整正文，只给导演和角色一个轻量的节奏提示：

- 用户明确换话题时，下一轮立即跟随；
- 同一意象连续出现后进入冷却，避免“反复说同一句诗”；
- 连续几轮没有新方向时，角色可以从现场、物件、自己的小目标或另一位角色身上主动开一个小话头；
- 主动话题必须与当前地点和状态有关，不凭空讲设定，也不把用户强行拉回旧问题。

### 3. 地点、时间和氛围真正影响画面

`WorldScene.state.visual` 保存稳定的视觉状态。它由地点、时段和氛围确定性生成，包含主色、辅助色、光色、粒子类型、密度和天气。

世界画布会根据状态切换清晨、白天、黄昏、夜晚的渐变，并显示雨、雪、尘埃、萤火或余烬等轻量环境层。离开地点再回来时，视觉状态和物件状态都保持一致；动画遵守系统的减少动态设置。

### 4. 离开后世界仍会留下可追溯的回声

进入世界首屏后，离线世界脉冲在后台推进，不阻塞首屏加载。只有通过现有地点、在场关系和角色自主状态校验的行动才会写入年表。回来时会显示第一条真实事件的标题作为“世界回声”，不会把远处发生的事情伪装成用户亲眼看见。

### 5. 空响应自动接住，但不暴露内部实现

角色正常生成仍然只调用一次。只有模型返回空正文时，角色层才调用已配置的备用模型；真实调用数随轮次记录，界面不显示“兜底模型”等内部信息。两个模型都没有正文时，仍然保留用户输入并如实进入失败恢复路径，不编造角色台词。

## 数据与隐私边界

- 所有状态按 `userId + worldId + sceneId` 读取，视觉与话题状态不跨用户共享。
- 角色上下文继续沿用知识隔离：不在场、不知情、私密的内容不会因为导演知道而进入角色提示词。
- 关系分面仍只由有原因的世界事件改变，好感度仍只来自 4.x 的 `CharacterState`。
- 世界脉冲只写世界表，不写 `sessions` / `messages`。

## 验收口径

- 连续 15 轮同一话题：不重复同一意象三次以上；用户换题后一轮内跟随。
- 两个角色同时出场：动作、对白按顺序出现，不同时弹出；角色可以彼此回应而不是轮流问用户。
- 切换地点再回来：物件的打开、带走、放下状态保留。
- 世界关闭超过最小间隔后重新打开：首屏不等待脉冲；有真实行动时才出现回声。
- 主模型空响应：备用模型接住且 `llmCalls` 记为 2；正常响应仍为 1。
- `tsc --noEmit` 与 `vite build` 必须通过；现有 World A–E 与历史迁移验收不得回归。
