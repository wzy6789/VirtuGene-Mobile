# 移动端手势统一

- 一级板块：横滑切换相邻板块，不循环。12px 方向锁、横向至少为纵向的 1.4 倍；距离或速度达到阈值才提交。边界仅有小幅阻尼回弹。
- 页面返回：内容区右滑返回，左滑不返回。左右 28px 保留给 Android 系统边缘手势。
- 列表左滑：拥有独立优先权，拖动期间关闭过渡动画，按帧更新；取消恢复原状态，拖动后的合成点击不进入聊天。触碰其他区域收起已展开操作。
- 输入、按钮、链接、文本选择、横向滚动区域、弹窗与列表操作不触发整页切换。
- 页面跟手移动直接操作 DOM，每帧最多一次，不重绘整棵 React 树。动画只使用 transform，170ms 后完成导航。取消、窗口变化、切后台、页面变化、卸载均清理动画帧与计时器。
- 日记、待办、朋友圈、世界二级页增加内容区返回；群聊聊天先退回群列表，再关闭群聊。系统返回先关闭弹窗、此刻设置、消息菜单、图片预览与群聊临时层。原生返回监听在卸载时移除。

真实浏览器手势验收：短滑、斜滑、边缘、多指、取消、边界、控件、横向容器、弹窗、禁用、旧计时器、重复松手、列表跟手与误点击。另回归手机布局、群聊与角色滚动。

浏览器无法模拟 Android 操作系统的边缘手势调度；需要真机确认系统返回与输入法手势。此次未修改角色、记忆、消息数据，未生成 APK。
