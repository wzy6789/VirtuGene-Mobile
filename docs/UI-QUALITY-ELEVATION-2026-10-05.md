# UI 质量跃升方案 · 2026-10-05

定位：6.0.0 已冻结发布，按用户确认，本方案面向 **6.0.1**。目标是让正式 App 的观感追平官网与原型的水准——不是零散修饰，而是一套可验收的视觉代际升级。**不动数据层、不动已冻结的功能范围、不动既有契约。** 实施记录与阶段验收见 [UI-6.0.1-VISUAL-UPGRADE.md](UI-6.0.1-VISUAL-UPGRADE.md)。

## 现状诊断（为什么"高级感不够"）

对照四轮评审的实机截图，当前 UI 的短板集中在五处：

1. **平面感**：卡片全是"1px 边框 + 纯色底"，深色下没有层次、浅色下没有光影，整屏像表格。原型的好看恰恰来自渐变、光晕、深度——正式版把它们简化掉了。
2. **数字没有仪式感**：行动舱最有价值的四个统计数字，现在是普通字号排在格子里；"今日先做 3 件事"是产品的灵魂，视觉上却和普通列表同权重。
3. **图标语言混乱**：`↗` `⌕` `‹` `×` 文字符号、emoji、线条图标三套混用，是"廉价感"最直接的来源。
4. **反馈单薄**：按钮按下、卡片选中、页面切换几乎无过渡；触觉有了，视觉反馈没跟上。
5. **加载与空态是文字**："正在读取你的行动…"一行字，没有骨架屏，加载过程显得慢且粗糙。

## 总原则

- **一币两面**：深色 = 极光（层次靠半透明叠加与光），浅色 = 纸感（层次靠阴影与留白）。不是反色关系，是两套独立调校。
- **球是灵魂**：所有"签名时刻"由小球驱动（见 P3），不堆砌通用动效。
- **改动大但不重做**：令牌先行，组件逐个换皮，每步有截图回归。功能冻结范围不变。
- **预算红线**：CSS 总量 gzip 不超过现有 +15%；全部动效 `prefers-reduced-motion` 有等价降级；不引入新的运行时依赖。

## P0 · 设计令牌 v2（一切的地基，1–2 天）

扩充 `theme-tokens.css`，新增四组令牌：

1. **高度系统**：`--vg-elev-0/1/2/3`，深色用"透明度递增的表面 + 顶部 1px 高光描边"，浅色用"三级阴影 + 半透边框"。所有卡片、弹层、粘性通知只引用高度令牌，不再手写 border+background。
2. **间距与圆角节奏**：4px 基数的间距刻度（4/8/12/16/24/32/48）与圆角刻度（8/12/16/20/28/全圆），全站替换魔法数。
3. **动效曲线**：三条弹簧曲线（标准进出 `cubic-bezier(.2,.8,.2,1)`、回弹、减速）+ 三档时长（120/200/320ms），全部走 `mobile-motion.ts` 的减少动效闸门。
4. **字阶与数字字体**：标题/正文/说明/微型四档字阶锁定行高；统计大数字启用 `tabular-nums` + 字重 600 + 紧凑字距的"展示数字"样式。

验收：令牌表 + 一个对照页（同屏展示旧/新卡片各状态），深浅色截图各一张。

## P1 · 表面与骨架（视觉差异最大的一步，3–4 天）

1. **卡片 v2**：行动舱/待办/收件箱全部换高度令牌；今日重点卡加左侧 3px 主题色能量条（逾期红、今日紫、等待青），一眼可分状态——这是"高级感"性价比最高的一笔。
2. **统计区英雄化**：四个数字从格子改为大字报式一排（数字 32px+），下方一条微型进度气质的分隔；"今日及逾期共 N 件"改为胶囊印章样式。
3. **页头层次**：助理空间页头做折叠式——顶部时头像+名字+小球完整展开，下滑后压缩为单行毛玻璃条（`backdrop-filter`，带降级），小球始终可见。
4. **底部 Tab**：活动项加滑动指示器（共享元素迁移式），图标描边/填充切换，配合已有触觉。
5. **骨架屏**：行动舱、收件箱、消息列表的加载态全部改为骨架屏（呼吸微光，reduced-motion 下静态），替换所有"正在读取…"文字。
6. **空态升级**：保留小球，加一句主文案 + 一行小字 + 一个主按钮的三段式标准件，全站统一。

验收：320/390/430px × 深浅色截图对比；对比度抽测（正文 ≥4.5，大字 ≥3）；CSS 体积核对。

## P2 · 图标与细节语言（2–3 天）

1. **一套图标**：内联 SVG、24px 网格、1.5px 描边、圆角端点，覆盖全部现有语义（约 40 个）；文字符号（↗ ⌕ ‹ ×）与 emoji 图标全部替换。做成一个 `Icon` 组件，按名字引用，和 `SecretaryIcon` 合并。
2. **按钮体系**：主/次/幽灵/危险四级按钮统一高度（48/44/36）、圆角与按下缩放（0.97 + 透明度，120ms）；文字链接式操作（编辑/设为今日重点）升级为幽灵小按钮。
3. **标签与徽章**：状态标签（待开始/等待别人/遇到阻塞/今日重点）统一胶囊件，颜色语义对齐令牌。
4. **弹层统一**：Modal 与底部弹层同圆角、同遮罩透明度、同进入曲线；原生日期控件维持原生（可用性优先），仅统一外层视觉。

## P3 · 签名时刻（记忆点，2–3 天）

只做五个，每个都可截图传播：

1. **完成回响**：完成今日事项时，行内打勾动画 + 页头小球 `success` 表情 + 已有 `resonate('success')` 触觉，三件套绑定为一个标准动作。
2. **今日清空**：今日重点全部完成时，统计区数字依次归零，空态小球入场（共享元素从小球位落下）。
3. **讨论聚焦**："和助理聊这件事"切入对话页签时，上下文横幅从任务卡位置展开（FLIP 动画），小球表情切 `thinking`。
4. **接待动画**：助理空间每次进入，页头小球从消息列表位置接力飞入（已有通道，补齐反向回飞）。
5. **失败姿态**：任何操作失败，小球 `error` + 通知条红色描边脉冲一次（仅一次，不循环）。

红线：签名时刻全部可关闭（减少动效下退化为状态变化，无位移动画）；单个动画 ≤320ms；不打断输入与滚动。

## P4 · 聊天与世界页追平（2–3 天）

1. **聊天气泡 v2**：气泡圆角不对称（自己 18/18/4/18）、长文与短句不同内边距、流式回复的光标改为小球微缩律动；时间分隔线与未读线细化。
2. **输入区**：输入框聚焦时边框微光，发送按钮按下有小球 `happy` 一闪。
3. **世界/角色页**：只换令牌与图标，不做结构改动；关系星图等重渲染组件不动。

## P5 · 质量护栏（贯穿，1 天）

1. **视觉回归集**：把本轮所有新截图纳入 `scripts/verify/` 既有截图回归，新旧对比入库。
2. **对比度与减少动效全量复测**：两套主题 × 三个宽度。
3. **性能闸门**：`ui-performance.css` 既有规则不破；新动效只动 transform/opacity；构建后 CSS/JS 体积入档对比。
4. **复跑全套**：tsc、构建、助理/待办/小球/分包回归全部通过才算完成。

## 排期与次序

| 阶段 | 内容 | 工作量 | 依赖 |

| P0 | 令牌 v2 | 1–2 天 | 无 |
| P1 | 表面与骨架 | 3–4 天 | P0 |
| P2 | 图标与组件细节 | 2–3 天 | P0，可与 P1 后半并行 |
| P3 | 签名时刻 | 2–3 天 | P1 |

合计约 10–15 个工作日。若只做一刀见效的最小集：**P0 + P1 的卡片 v2/统计英雄化/页头折叠 + P3 的完成回响**，约 5 天，观感即可拉开代际差。

## 明确不做

- 不重做信息架构与导航（合并后的三页签保持不变）；
- 不动数据层、契约、验收脚本语义；
- 不引入第三方组件库或动画库（现有自研体系足够）；
- 不在 6.0.0 已发布范围内回贴任何一项（全部归入 6.0.1 开发范围）。
