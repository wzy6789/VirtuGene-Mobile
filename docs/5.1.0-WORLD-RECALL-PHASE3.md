# VirtuGene 5.1.0 Living World · Phase 3 世界记忆闭环

## 目标

让世界脉冲不止停留在世界页。角色在用户离开时亲身参与的自主行动，会在之后的私聊里成为一段可以自然提起的经历，完成“世界发生 → 角色知道 → 角色说得出来”的闭环。

## 已完成

- 脉冲结算写入 `worldEvents` 后，只给该事件的实际参与者写入 `characterKnowledge`（`full + canMention`）。模型不能指定认知对象。
- 私聊新增世界脉冲召回区块。召回同时通过当前用户/世界、事件可见性、角色参与者和认知四道闸门。
- 召回内容明确区分“用户不在时发生”：角色不会把它说成用户亲历，也不会补写记录里没有的细节。
- 同一会话最近已经提过的脉冲事件会暂时冷却，避免连续多轮重复同一件事；消息 `contextTrace.pulseEventIds` 保存真实注入来源。
- 脉冲认知写入与事件、位置、代理状态处于同一个 Dexie 事务；任一写入失败都不会留下半完成的结算。

## 隐私与真实性

1. 查询始终校验世界所属用户，不能跨用户读取世界或认知。
2. 只有 `sourceType=pulse`、`type=interaction` 且角色是参与者的事件才可能召回；旁观者不会因为世界可见而自动获得“亲身经历”。
3. `private` / 未标记可见性的事件不会进入角色上下文；认知缺失或 `canMention=false` 时宁可不提。
4. 召回是本地数据库读取，不新增网络请求或 LLM 调用。
