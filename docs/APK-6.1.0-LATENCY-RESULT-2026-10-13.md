# 6.1.0 已发布APK内置界面速度实测

## 版本及测试边界

实际读取 release/VirtuGene-6.1.0.apk。aapt确认 com.virtugene.app / versionName6.1.0 / versionCode67；SHA256 b2a3eee467cc837726fa4916c22b7ace1828ae776db174be296b08249dfdb888，与发布记录一致。解出assets/public并原样提供给手机尺寸412×915桌面Chrome，运行的是APK内置JS/CSS，不是最新源码重新构建的界面。未修改APK资源、未安装覆盖用户应用、未改版本。

adb devices -l为空，SDK没有可用emulator。因此本次是**APK内代码在桌面浏览器的真实模型实测，非Android安装后真机实测**。本地测试服务器模拟静态资源加载；应用判断为移动预览浏览器，走Web接口，不包含Android WebView、原生IPC、设备CPU、网络与正式网关耗时。

辅助seed只创建隔离IndexedDB测试账号、角色与会话，未调用源码发送服务。实际打开消息列表、点击测试角色、在原界面输入并按Enter，DOM观察第一条流式正文出现，等待原界面停止生成按钮消失；结束读取全部流式气泡。输入前记录performance.now，首条不把推理包或正在输入当正文。

## 后台竞争与质量限制

APK真实界面启动时尝试声线设计、角色独立生活进展；每轮各任务还因代理拒绝而重试，共12次非流式请求被预算闸门拦截。它们没有转发付费模型。原始errors列表保留；complete:true仅指3次规定聊天测量完整，不表示所有后台功能正常，也不表示日常生产所有并发负载已经测量。正式使用时后台请求可能竞争额度、连接或设备资源，但本次不证明它们导致用户实际慢。

首轮回复有“今天天气还行”等未提供来源内容；速度测试通过不代表人物事实可靠或人味达标。三个原稿及上游SSE完整保留。聊天验收只保留本组较稳妥的完整第二轮，不拼句，不以该选择计算时延均值。
