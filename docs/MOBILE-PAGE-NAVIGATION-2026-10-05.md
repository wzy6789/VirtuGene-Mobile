# 手机页面导航调整

## 交互约定

角色资料、基因实验室、设置、助理工作台、编辑器和查看记录等完整功能使用独立的全屏页面。顶部左侧返回，标题居中，内容区域独立滚动；页面横向进入，不使用底部拖动把手、顶部大圆角或向上弹出的抽屉。

删除、注销、退出、结束世界等简短确认使用居中弹窗。消息长按和工具按钮的就地菜单保留。桌面端使用居中窗口。

保留 VirtuGene 深浅主题与紫色主操作。“开始聊天”只显示文字，继续沿用添加或复用角色后进入原有会话的逻辑。

## 实现

- `Modal` 在手机端默认使用页面布局；简短确认显式指定 `presentation="dialog"`。原有调用自动接入，新增页面不再另写底部抽屉。
- `mobile-pages.css` 统一顶部导航、全高滚动、固定操作区、安全区及主题。
- 共用动效改为水平转场，保留中断、退出快照的权限检查、减少动画模式和清理机制。
- 返回按钮、Escape 与原生返回事件遵循相同的导航层级，只返回最上层；父页面仍挂载，保留草稿和滚动位置。
- 聊天“此刻设置”也接入共用页面，时间、地点、气氛仍通过原仓储写入。

## 本地验证

- `character-profile.mjs`：24 项真实 UI / IndexedDB 检查，覆盖按钮无箭头、全屏资料、回到基因库、重复点击、复用会话与场景设置持久化。
- `run-modal-motion.cjs`：41 项，覆盖横向进入、无抽屉边缘与把手、嵌套返回、草稿与滚动保留、居中确认、320/390/430px 大字号、缩短视口、动画中断和隐私快照。
- `run-settings-ui.cjs`：55 项设置操作检查。
- `run-settings-motion.cjs`：触摸、键盘、内部页面返回、滚动恢复、敏感页面、深浅主题和桌面布局通过。
- `run-secretary-motion.cjs`：五个工作台去向、聊天位置保留、快速进退、尺寸变化与减少动画通过。
- `run-action-cabin.cjs`：54 项数据与 20 项 UI 检查，覆盖新建、修改、失败保留输入、完成与撤销和深浅主题。
