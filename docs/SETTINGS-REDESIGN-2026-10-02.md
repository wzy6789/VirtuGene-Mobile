# 全软件设置界面整改方案

阶段：设计方案。原型中的人物、连接、计数和设置值均为示例，不读取或修改应用数据。

## 1. 目标与现状

让用户进入设置后迅速知道：这里可以改什么、现在是什么状态、修改会影响谁。

从当前手机端组件梳理出的主要问题：

| 现有位置 | 问题 | 整改方向 |
| --- | --- | --- |
| SettingsPanel | 一个长弹窗混排密钥、账号、语音、模型、同步、备份、更新和注销；信息密度高 | 设置首页只展示分组入口和当前值，进入详情再操作 |
| MobileMePage | “API Key 管理”和“完整设置”平行，重复路径；“完整”不能帮助用户判断内容 | 设置成为主入口；保留有需要的快捷方式，但跳转同一详情 |
| ChatHeaderMoreMenu | 标题“设置”实际主要是语音；模型消耗混在语音表单里；全局开关与角色方言混排 | 分开“当前角色”和“全局聊天偏好”，显示影响范围 |
| WorldSettingsPage | 长期世界事实管理采用另一套卡片；10px 分组标题和小字操作不容易读 | 世界设定作为规则列表，突出内容、状态和编辑入口 |
| WorldControlSheet | 记忆模式、时间跳过、暂停、结束混在一个长面板 | 长期规则与当前世界操作分开；结束操作单独呈现 |
| MomentsPage | 设置、屏蔽、隐藏、历史可见性使用多套手写弹层；主设置展示很多细项 | 统一页面框架，将提醒、分享节奏、可见范围、发布偏好拆组 |
| DiaryPage / DiarySharing | 隐私锁、提醒、逐条授权分散；用户需自己理解保护与分享的区别 | 汇入日记设置目录；仍保留逐条授权与撤回，明确谁能看 |
| 助理管理 / 办事习惯 | 已有分组和固定操作区，但与普通设置体系尚不统一 | 保留专属业务结构，复用统一的表单、选择器和反馈 |

范围还包括个人资料、改密码、语音识别密钥、模型选择、备份恢复、局域网同步、更新与关于、角色形象/声线等设置型界面。创作、聊天、办事记录等内容页不改成设置列表。

## 2. 信息结构

总设置首页使用七个入口组，首页不铺开完整表单：

1. 个人与账号：头像与名字、密码、账号管理。
2. 外观与阅读：深浅主题、聊天字号及预览。
3. 聊天与语音：消息朗读、语音消息、语速、声音服务、语音输入。
4. AI 连接：连接状态、默认对话模型、服务商密钥、连接问题处理。
5. 内容与隐私：日记设置、朋友圈设置、世界设定；各自跳转同一业务设置页。
6. 数据与设备：备份、恢复、局域网同步。
7. 关于与更新：版本、检查更新、使用说明及现有法律文档。

入口行结构统一为“线性图标 + 清楚的名称 + 当前值或一句用途说明 + 进入箭头”。提供设置搜索：支持“声音/语音”“字体/字号”“密钥/API Key”等常见说法，结果直接进入对应详情，标出所在分组。

### 聊天设置

- 头部展示当前角色头像、名字及“当前角色”标识。
- 当前角色：角色声线/方言、当前会话模型和用量信息。没有声线时显示真实的未生成状态。
- 全局聊天偏好：消息朗读、语音消息、语速、字号。每组明确标记“所有聊天”，入口与总设置共用同一页面和数据。
- 模型信息单独展示；当前会话模型锁定时说明“本会话已固定”，默认模型入口标记“用于新会话/未指定模型的场景”，不制造可以修改旧会话的假象。
- 心情打卡和情绪图谱属于聊天操作，保留在更多菜单中，与设置入口分组。
- 现有 ttsEnabled、aiVoiceMode、ttsSpeed 是全局状态，不在 UI 中伪装成当前角色专属开关。角色 voice 字段才是角色范围。

### 星域 / 世界

使用“世界偏好”的入口目录，明确两个范围：

- **长期世界设定**：规则、地点、人物事实等既有分类；每条显示生效/已暂停状态。编辑进入详情，暂停使用明确控件，删除放入详情的次级操作。新增保留自然语言输入，并给一条示例帮助开始。
- **当前这一段世界**：角色加入方式、时间推进、保存这一刻、写入世界记录、暂时离开、撤销上一轮。加入方式使用带解释的单选卡，而不是三枚长按钮挤在一行。
- “结束这一段世界”单独放置，解释现有结算与只读回看行为；与“暂时离开”呈现不同后果。名称与实际结束范围在接线前确认，不擅自改变结算逻辑。
- 状态来自真实 scene、facts 和 entryMemoryMode；“当前世界”的操作不进入全局开关页。

### 朋友圈、日记、助理

- 朋友圈：提醒、好友分享、可见范围、发布偏好四组。默认分享节奏显示“安静/自然/活跃”及原有时间含义；按好友调整进入列表。屏蔽对方查看与隐藏对方动态分别命名、分别说明。
- 日记：隐私锁、写日记提醒、AI 辅助、已分享给谁。锁定与对外授权分别说明；不恢复已移除的全局“所有角色可看日记”开关。
- 助理：资料与形象、办事习惯、聘用管理沿用现有业务；保留个性特点，但表单与导航遵守统一规则。
- 数据：备份与恢复分别进入任务页，清楚显示读取到的状态和现有合并/覆盖行为；同步提供连接状态和错误反馈，连接参数归入详情。

## 3. 视觉语言

方向：安静、精致、有轻微科技感的手机设置界面。沿用现有品牌紫色与青色，参考本地 design-md-reference 中 Linear 的表面层级、Apple 的移动端简化原则，不照搬字体与配色。

- 浅色：微冷灰底 + 清晰的白色分组面板。深色：深灰紫底 + 高一层的中性面板。背景、分组和输入区域形成三个层级。
- 紫色用于选中状态、主按钮和焦点；青色少量用于连接与成功反馈。删除使用红色，已关闭使用中性灰，同时保留文字状态。
- 页面标题约 22–24px、行标题 15–16px、说明 12–13px，中文行高约 1.5。重要说明不再依赖 10px 小字。
- 手机页面水平边距 16px，组间距 24px，分组面板圆角 18–20px，输入框圆角 12px。普通行约 60px，带说明的行约 72px；触控区域至少 48px。
- 每组共用一个面板与柔和分隔线。图标、箭头、开关保持统一线宽和尺寸。
- 品牌氛围只在标题区域有很轻的色彩。移除大幅“控制台”装饰、满页发光边框和多重卡片嵌套，让设置内容成为视觉中心。
- 原型展示两种主题；正式落地优先复用项目 token，检查最终中文换行与对比度。

## 4. 交互规则

| 类型 | 推荐交互 |
| --- | --- |
| 浏览设置 | 完整页面或统一全高容器，固定返回栏，内容单独滚动 |
| 简单选择 | 短底部面板，带选中标记和一句说明 |
| 立即生效的开关 | 操作后展示当前值；写入失败时回退并给出原因 |
| 多字段表单 | 编辑草稿，底部固定保存按钮；保存后更新摘要，脏表单返回时提供保留/放弃选择 |
| 密钥 | 默认遮蔽，显示/替换分开；不显示虚构的连接正常状态 |
| 危险操作 | 与常用设置隔开，确认页说明真实影响范围和结果 |
| 高级信息 | 进入详情或展开“服务与连接”；主要界面解释用户能感受到的行为 |

文案示例：

- “基因序列标识” → “AI 服务密钥”。
- “基因序列更新” → “软件更新”。
- “AI 语音消息” → “以语音消息回复”，说明“生成语音气泡，点按播放；影响所有聊天”。
- “朗读引擎” → “声音服务”，具体服务商保留在详情中。
- “设置” → 当前明确的“聊天设置 / 日记设置 / 朋友圈设置”。
- 每一项尽量回答“开启后会发生什么”，而不是解释内部调用链。

动效继承上一轮的阻尼过渡：页面进入约 280–360ms，选择与开关约 160–220ms；详情返回恢复列表位置；弹层交接保持遮罩稳定。减少动态效果下移除位移与装饰动画。

## 5. 落地顺序

1. 建立统一设置组件：页面、分组、入口行、开关行、选择详情、固定操作区、状态与错误提示。先改总设置首页与外观详情，确立标准。
2. 改聊天设置与 AI 连接；解决全局与角色范围混淆，迁移旧入口到同一详情。
3. 改星域/世界设定与控制面板；统一框架，保留自然语言和现有世界行为。
4. 改朋友圈、日记、助理、资料、账号、数据与更新等剩余设置型界面。
5. 检查所有旧入口与搜索结果、深浅主题、320–430px、窄窗口与键盘、返回和保存、焦点、减少动态效果，以及数据与账号隔离。

先重构界面和导航，连接现有 store/repo 与操作函数。可能需要新增搜索索引和编辑草稿状态；新增业务配置项应单独定义，不借 UI 改造暗中改变权限、默认值或行为。

## 6. 原型与验收

可点击视觉原型：`docs/prototypes/settings-redesign.html`。展示总设置首页、聊天设置、世界偏好、朋友圈设置，以及字号/语音详情。支持主题切换、首页搜索、单选/开关和详情返回，所有修改仅在原型中演示。

设计验收目标：用户能从名称判断作用；设置行能读到当前值；全局/角色/当前世界的范围清楚；常用项无需经过多级折叠；长表单的保存不会滚出屏幕；所有已存在的设置能力可找到对应位置。

原型检查通过：四个页面的深浅主题、320/390/430px 无横向溢出、搜索别名、字号即时预览、开关与单选、详情返回和减少动态效果。预览截图位于 `.tmp-preview/settings-design-20261002/`。该检查只验证设计原型，未声称已接入真实业务状态。

设计阶段只新增设计文档和原型。随后按用户确认落地到应用，深色作为主要页面方向，实施范围与验证结果见 [落地记录](SETTINGS-IMPLEMENTATION-2026-10-02.md)。
