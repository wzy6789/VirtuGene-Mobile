# 助理与行动页面整合

2026-10-05。用户确认统一空间直接显示自己为助理取的名字，不改名为“生活助理”或“行动舱”。本次是用户在 6.0.0 初始构建后明确授权的功能整合，替代此前两个独立入口；项目、独立风险页与周复盘仍未开放。

## 使用流程

- 消息首页保留一张助理卡，显示实际名字，常显“查看今日 / 继续对话”。详情仍可展开查看统计与管理。没有聘用时显示“聘用助理”，仍可进入今日手动安排事项。
- 统一页面标题和更多菜单使用助理的真实名字，改名实时更新。内部为“今日 / 对话 / 待处理”，底部仍是原四栏，助理页面高亮消息。
- 今日复用真实发生实例、重点排序、逾期与跟进筛选、编辑、完成和撤销。任务的“和助理聊这件事”进入既有对话，显示具体事项及本次日期；可以显式结束讨论。
- 对话第一次访问时加载，之后切页签只隐藏并设为 inert，不卸载发送管线或输入框；保留草稿、会话、滚动与进行中的请求。切换账号卸载整个私有空间。
- 待处理区分“未安排 / 需你补充 / 待确认草稿 / 未办成 / 办事记录”。未安排是 Todo，其他分类是办事请求，数字分别计算；请求办成不等于对应待办已经完成。同一请求有多个结果时允许跨分类出现，不合计为一个混淆的总数。
- 从需补充请求接续只选择原请求并准备输入草稿，不自动发送。朋友圈和每日整理保留原确认、发布、日记解锁与实际回执规则。
- 标题栏小球使用原生按钮，可进入对话；支持目光跟随、键盘操作、手势取消、减少动效与入口接力。任务执行反馈和对话处理状态驱动表情。

## 实例对话与可靠性

`SecretaryTodoContext` 只存账号、Todo id、发生实例 id、原计划日以及模板/实例版本，不复制名称或私密正文。显示和规划时读取当前账号的实时记录。

消息保留所选实例来源，办事请求继承来源，恢复与接续可核验。规划只提供所选实例，执行时重新检查归属、实例身份与双版本；模型的其他目标 id 或标题不能越过当前选择。其他入口修改后旧请求停下，要求重新选择。已成功的请求按稳定 id 重放不重复写入。

通过既有 `todo.update` 增加当前实例的今日重点、工作状态、等待对象、阻塞原因、跟进安排字段；改期写当前实例的实际截止日期，保留重复系列锚点。名称、备注、重复和系列步骤需在原编辑器明确范围。

新工作字段来自用户明确原话，仍执行证据、否定和引述校验；选中事项提供对象上下文，不提供额外操作授权。安排跟进产生 `followup-planned`，不生成 `followup-recorded` 或声称联系过对方。字段未变化不生成事件。

实例修改和回执在事务中提交；撤销复用原实例撤销凭据，核对模板与实例版本，不覆盖后续修改。自己的已成功操作可在核对回执版本后更新讨论来源；其他操作造成版本变化不自动接受。

实例操作的“去查看”仍留在同一助理空间，切到今日并定位对应实例；确认、草稿和失败处理复用原卡片。AI 不可用或助理空缺时，手动待办功能仍然可用。

数据库索引版本维持 32，新增的是可选消息/请求元数据与操作回执字段，不新增一套待办表或迁移已有记录。内部 `actionCabin` 路由和接力 key 保留兼容，但正式页面不再显示该旧名字。

## 验证

- TypeScript `--noEmit`：通过。
- Vite 生产构建：通过。主入口约 487.28 KB / gzip 162.27 KB；包含动态种子初始化的消息首页 JS 约 1.038 MB / gzip 441.45 KB。这些是产物与请求体积，不是启动时间保证。
- 新整合验收：23 项数据 + 15 项界面。包括单实例改期、重点撤销、旧来源冲突、系列保护、否定与引述保护、跟进事实分离、请求重放、名字更新、草稿保留、处理时切页签、回执定位、跨账号清理和无助理/API 手动收集。
- 既有助理：1,228 项数据 + 157 项 UI 通过；原待办/行动组件：54 项数据 + 20 项 UI 通过。
- 正式产物：9 项入口、分包、更新公告与失败恢复检查通过；首页没有提前下载世界、聊天、助理执行器或设置。
- 布局覆盖 320 / 390 / 430px，深浅主题截图在 `.tmp-preview/assistant-hub-dark.png` 与 `assistant-hub-light.png`。
- 模型使用可控替身验证契约，未把它当作真实 API 可用性测试。用户此前明确“不需要真机”，本轮没有增加真机验收门槛。

## 评测收尾：M1 / M2

- 今日重点不再用未排期或未标记为今日重点的未来事项补足前三。已排期的今日、逾期事项继续参与；未来有日期的事项只有用户明确标记为今日重点时才参与。未排期事项保留在待处理的未安排分类。
- 未排期事项不提供直接设为今日重点的按钮；既有未排期重点标记显示为「重点待排期」。今日无待做安排时使用诚实的空态，不把未排期事项描述成已经完成。
- 头部按钮禁止收缩，副标题单行省略，名字保留完整可访问文本和 title。修正窄屏隐藏头像的选择器，使其实际生效；标题字重消费字体令牌。
- 新增 5 项数据、5 项界面检查；助理中枢共 28 数据 + 20 UI、行动舱 54 数据 + 20 UI 全部通过。长名字覆盖 320 / 390 / 430px，验证标题省略、按钮至少 44px、无重叠和横向溢出。
- 类型检查通过；最终生产构建 3.51s，主包 491.61 KB / gzip 163.77 KB。窄屏截图见 `.tmp-preview/assistant-hub-long-name-320.png` 等。
