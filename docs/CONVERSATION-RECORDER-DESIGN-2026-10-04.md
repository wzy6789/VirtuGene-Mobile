# 小星 · 每段普通聊天的对话记录者

2026-10-04。设计方案与可交互原型；尚未迁移正式聊天入口或接入业务数据。原型全部使用示例数据，没有读取真实聊天、写入记忆或调用模型。

## 1. 产品定位

角色头像代表聊天对象，小星承接这段聊天的情绪、回忆与共同故事。每个普通角色单聊都有一个小星入口，沿用同一品牌形象，但展示的数据属于当前用户、当前角色与对应会话。

小星是一位安静的记录者：用户聊天时陪在头部，需要回看时打开记录。它不加入消息序列、不代替角色回答，也不承担生活助理的任务执行功能。原有普通角色与助理头像继续承担身份识别。

“记录”指现有消息、记忆和情绪结果的汇集，打开小球不会另建一份聊天副本、启动录音或自动增加模型调用。

## 2. 默认聊天布局

手机头部从左到右：返回 → 角色头像和名字 → 40px 小星 → 更多。小星点击热区至少 44×44px；头部使用网格与可截断的名字，避免当前居中绝对定位加入口后碰撞。最窄 320px 仍保留返回和更多。

小星固定在头部，消息阅读区和输入框保持连续。默认仅轻微呼吸与眨眼；首次进入可以短暂显示“小星 · 对话记录”，之后不反复教学。无新增记录时没有红点和强提示；一次真实更新后出现短暂的青色状态点，详细更新时间保留在面板中。

打开面板会关闭键盘并保留草稿、消息滚动位置；关闭面板回到原来的聊天位置与触发入口，不能自动聚焦输入框弹起键盘。原型可演示展开、关闭和焦点返回，真机键盘收起与阅读位置恢复需在正式 ChatWindow 接入时验收。

## 3. 展开后的信息架构

面板标题“你们的记录”，头部为小星、角色名和明确的数据范围。小星的主形象约 52px，阅读内容占主要面积。

| 页签 | 用户能看到什么 | 数据范围与来源 |
| --- | --- | --- |
| 概览 | 最新情绪解读、近期记忆、关系状态及共同故事入口 | 当前会话结果 + 明确标注的角色汇总 |
| 情绪 | 现有六维图谱、上次对比、历史解读、更新时间与分析依据 | 当前会话的 EmotionSnapshot |
| 回忆 | 记忆碎片、手动收藏、来源、纠正与删除入口 | 默认本会话；显式切换到这个角色的全部回忆 |
| 故事 | 关系里程碑、共同记忆、分享时刻与相识起点 | 同一用户与角色的历次会话 |

概览可以展示摘要，但必须说明覆盖范围：现有 EmotionSnapshot.summary 是情绪解读摘要，Session.summary 是较早对话的滚动摘要，不能把后者直接命名为“这一次交谈的摘要”。原型“对话摘要”是提案演示；正式首版优先使用已有解读摘要，缺失时显示空态。新增当次摘要的生成逻辑属于后续业务增量，不为打开面板发请求。

情绪页称为“AI 对话解读”，描述这段对话的表达与互动。用户的“我的心情”打卡与日记曲线单独标注用户级范围，不与角色心情、六维坐标合成一个分数。

统计口径明确：“本会话消息数”来自 DB；“相识天数”应查这个角色全部会话的最早有效消息；“角色回忆”仅统计该用户与角色的有效记录。现有 EmotionPanel 从当前会话第一条消息计算的 days 不能直接充当跨会话相识天数。

## 4. 现有功能的归属

| 当前位置 / 功能 | 新位置 | 首版处理 |
| --- | --- | --- |
| 更多菜单里的情绪图谱 | 小星 → 情绪 | 迁移主入口，复用现有分析能力 |
| EmotionPanel 的六维图谱、波动追踪与历史 | 小星 → 情绪 | 复用 EmotionChart，拆分展示层 |
| EmotionPanel 的记忆碎片与随机回忆 | 小星 → 回忆 | 最近记忆优先，随机回忆为次级操作 |
| 关系等阶、进度、自定义等阶名与里程碑 | 概览摘要 + 故事详情 | 沿用角色关系数据 |
| StoryTimeline 共同时间线 | 小星 → 故事 | 改为同一面板内详情，减少弹窗堆叠 |
| MemoryArchiveModal 的原文、纠正、重点与删除 | 小星 → 回忆详情 | 复用原有存储与撤回路径，不复制新 CRUD |
| 用户心情打卡 / 日记曲线 | 情绪页下方“我的心情”；更多保留快捷入口 | 清楚标注这是用户级数据 |
| 单条回复的记忆依据 | 保留消息长按入口 | 定位到那条消息的依据，不合并成整段聊天结论 |
| 语音、阅读字号、模型与聊天偏好 | 更多菜单 | 保留偏好入口 |
| 场景卡与叙事场域 | 聊天原位置 | 继续服务当前对话氛围 |

原有入口迁移后，更多菜单中的旧“情绪图谱”可先作为兼容快捷方式直达新情绪页，避免迁移期间双面板并存；稳定后移除重复入口。

## 5. 小星表情与真实状态

| 实际状态 | 表情 / 反馈 | 规则 |
| --- | --- | --- |
| 没有整理任务 | 待机 | 微动，轻触打开记录 |
| 情绪与记忆处理确实开始 | 思考 | “正在解读对话”，绑定该会话任务 |
| 结果正在落库 | 忙碌 | “正在保存记录”，不提前宣布成功 |
| 完成有效写入 | 短暂完成 | 青色状态点与更新时间，随后回待机 |
| 请求或写入失败 | 遇到困难 | 保留上一份有效结果，提供“本次未更新 / 重试” |
| 关闭动效、后台、视口外或记录面板展开 | 静态当前姿态 | 释放时钟，保持状态仍可读 |

角色正在流式回复不代表小星正在整理；不把角色生成状态转成小星的分析状态。任务进行中点击小球仍可查看面板，但临时轻触表情不能覆盖任务状态。记录更新也不等于“你心情变好了”，不根据推测替用户表现开心。

原型的“演示整理 / 演示重新解读”只是定时切换姿态，没有真实模型任务；忙碌时保持静态对应表情，避免点击的临时开心遮盖演示状态。

现有 settle() 已将情绪、记忆与关系结算合并，复用其成功与失败事件。当前 isAnalyzing 主要用于手动分析，自动结算的 in-flight 集合未暴露可订阅的逐会话状态；接入时需增加以用户、角色、会话为键的只读任务状态，不能直接拿一个全局 busy 值驱动所有聊天的小球。

## 6. 布局与动效

以现有紫青深色主题为主。深蓝底、抬升一层的面板、细边线；强调色用于当前页签、图谱与操作。正文 14–15px，说明不低于 12px，标题约 20px；中文不加夸张字距，字重沿用现有字体降级方案。

手机使用共享 Modal，面板约占视口 84%，顶部圆角消费 --vg-sheet-radius，内容区独立滚动。桌面使用约 360–400px 的侧栏。窄桌面下若主聊天列不足 320px，应切换为覆盖式记录面板，避免压缩聊天气泡。

展开沿用 settleFrames 与共享弹窗动效；页签仅让变化的内容短距离淡入，标题、角色名与页签保持稳定。展开后头部小球暂停，面板头像默认静态。减少动效仍能直接展开、切换和查看记录。

跟手拖拽关闭属于后续交互增强：只从面板把手或内容滚动到顶的明确下拉启动，锁定纵向，保留取消与中途接管；需要扩展共享 Modal 动效层，不能为小星再写一套底部弹窗。本次原型没有实现拖拽关闭或小球飞行共享转场。

## 7. 数据范围与异常体验

- 读取始终校验 userId、characterId 与 sessionId；情绪快照没有单独 userId，需验证其所属会话的用户和角色，而非只按快照 id 读取。
- 换角色、换会话、退出或切换账号，清空旧详情与交互上下文；迟到的分析结果只能更新原会话，不能覆盖当前角色面板。
- 查看原文按真实 sourceMessageIds 和来源版本定位。来源被删时说明“原文已删除”，不得按相似文字替用户找到另一句话。
- 纠正与删除沿用 memoryRepo / ledger 的撤回、墓碑与摘要失效路径，避免旧提取结果重新出现。
- 无会话、无图谱、无记忆分别显示空态，不生成示例数值或填补不存在的关系变化。
- 隐藏小球仅控制入口显示；“暂停自动整理”是独立的后续设置，不能误解为删除聊天记录或撤销已经保存的记忆。现有设置中尚无这一专属开关。
- 消息、回忆与图谱使用延迟加载；关闭面板不订阅整段流式正文，不挂载图谱和时间线。列表统计查 DB，长记录分页加载。
- 真实记录退场快照须校验账号与会话访问权限；记忆原文和编辑详情优先禁用快照。原型允许样本快照，仅因内容全部为固定示例。

## 8. 落地顺序

1. **入口与归属**：新增普通单聊的 RecorderEntry，接入小球；拆分 EmotionPanel 的情绪、回忆、关系展示，统一新的记录容器；保留原头像与聊天功能。
2. **真实反馈**：订阅该会话已有结算结果，补逐会话任务状态与原文定位；打通已有记忆纠正、删除和时间线。
3. **动效精修**：补阅读位置/草稿/键盘验收，再扩展共享 Modal 的跟手关闭；只有验证有帮助后才增加小球共享元素转场。

首版范围是普通角色单聊。助理保留原有头像与工作界面；群聊需要独立设计成员见证与记录范围，不能直接套用某一个角色的单聊账本。

## 9. 原型与验证

原型：docs/prototypes/conversation-recorder.html，可离线打开。左侧两个角色用于验证记录切换；手机预览左上返回按钮用于切换两个示例。页签、回忆范围、原文返回、空记录、主题与减少动效均可操作。

构建与检查：

```powershell
node scripts/verify/build-conversation-recorder.mjs
node scripts/verify/run-conversation-recorder.cjs
```

原型直接复用 SoulOrb、SoulOrbButton、EmotionChart、Modal、主题令牌、气泡样式与项目已有中文字体；本地 design-md-reference 的深色层次原则只作为参考，配色与组件沿用 VirtuGene。

51 项原型检查通过，包括桌面侧栏、820/1024px 覆盖式面板、四个页签、键盘导航、记忆原文、角色切换隔离、空态、320/390/430px、至少 44px 点击区、共享 Modal、关闭后焦点恢复、浅色与系统减少动效、离线交互和零模型请求。截图位于 .tmp-preview/conversation-recorder/。这验证的是设计原型，不代表正式业务数据迁移、消息滚动恢复、真机键盘或 Android 性能已验收。
