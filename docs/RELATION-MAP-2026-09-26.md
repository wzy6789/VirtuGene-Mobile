# 头像关系星图精修

参考王者荣耀从选定人物查看关联人物的组织方式（[关系图入口说明](https://jingyan.baidu.com/article/7f766dafa625fc0001e1d092.html)），采用 VirtuGene 自己的头像、星光和数据，不复制游戏素材。

- 图上只显示头像与连线，没有人物名字、关系等级、点点提示或长说明；辅助阅读标签保留供屏幕阅读器使用。
- 用户与角色头像同尺寸。点头像将其置中，点连线展开实际关系描述和共同经历，详情使用两个头像作为标题。
- 每组最多八位近邻，可翻组访问全部角色，移除原十二人硬截断。
- 周边人物间的真实关系以较淡的线呈现，最多五条，避免一次叠加全部网络。点击相关头像可展开其余直接关系。
- 根据彼此连接调整周边顺序，缩短次要线路；曲线路由检查其他头像与边界。主线明晰，选中线加亮，其余淡化。
- 用户自己头像、图片头像、表情头像都支持；头像无角标和菱形内框。
- 聚焦时头像和线路同时换位，避免位置动画与已变更线路暂时错接；光晕使用小范围渐变和阴影，没有高成本模糊层。
- 读取本账号各世界的关系；三人及以上共同经历关联全部人物对；加载失败明确提供重试。

验收：relation-map 45 项，加角色界面 9 项、手机滚动 8 项。类型检查、生产构建通过。未修改关系数值或人物记忆，未打包发布。

本次针对角色栏的关系星图（RelationNetworkModal）；星域页中的另一个世界关系组件保持原状。
