# 小星动态升级 · 6.0.1

## 参考与取舍

参考 [Rive 分层状态机](https://rive.app/docs/editor/state-machine/layers) 将独立动作叠加的设计，以及 [react-spring](https://github.com/pmndrs/react-spring) 的物理动画思路。目光、身体、状态附件和轻触回应各自驱动，再合成同一角色；这属于本项目的实现取舍，不是直接复制两者的代码或形象。

继续使用原创 SVG、共享 rAF 时钟和解析临界阻尼，不引入 Rive/react-spring 运行时、外部角色素材或数据契约。

## 已实施

- 目光先响应，身体以更低频率跟随，形成轻微侧移和转头；每帧不读取布局，输入事件仍使用当前视口位置及距离衰减。
- 按住时横向展开、纵向压扁；松开或取消后从当前形状恢复。有效点击/键盘激活才触发 320ms 小跳跃和轻微摇头，地面投影同步收缩；滑动与滑出不触发轻触回应。
- 忙碌光点沿原有两段贝塞尔轨道往返，转折点减速且循环连续；用解析采样，不调用 SVG 长度/位置测量。
- 思考气泡轻浮，视线缓慢巡视，轨道亮点轻微呼吸；倾听增加小幅点头与波纹扩缩；困倦标记轻浮，完成星光微动。保持静态表情的轮廓区别。
- 思考、忙碌、失败和完成时，轻触可回应身体动作，但不能用临时笑脸覆盖真实业务状态。
- 新动作沿用系统/应用减少动效、失焦、后台、视口外、animated=false 的暂停机制；静态缩略图不订阅时钟，帧内不更新 React 状态。减少动效直接呈现当前表情。

## 第二轮：呼吸、眨眼与触碰体积感

待机采用错开的个体相位和两组低频起伏，身体轻摆与呼吸不再同拍；忙碌和低落降低漂浮幅度。眨眼改为 65ms 闭合、145ms 张开的平滑曲线，偶尔追加一次轻眨。目光领先身体，高光轻微反向位移，保持中性视线的几何基准。

有效触碰仍在 320ms 内结束，增加起跳/落地压缩与空中伸展，投影宽度、透明度随高度同步变化；没有新增模糊、粒子或循环 CSS 动画。按压移动超过 10px 时即时解除压扁，避免滑动过程中保持按压姿态。暂停时清空目光目标，恢复后不会追逐旧指针位置。思考气泡使用错开的明暗节奏；颜色选择、业务表情保护和六路暂停契约保持。

TypeScript、生产构建（3.83s）、16 项运动数学检查及 80 项浏览器小球回归通过。数学检查新增形变有界性、起落归位与眨眼开合边界；浏览器覆盖目光基准、取消误触、深浅色/窄屏、暂停机制和双球零帧内 React 提交。仍使用共享帧时钟和 SVG ref，不增加帧内 React 更新或运行时依赖；CSS 未增加。正式预览通过 Vite 更新，独立预览已重新生成。浏览器帧间隔仍不代表 Android 真机 GPU 性能。

## 第三轮：分部位运动、注意力与弹性回应

按 `SOUL-ORB-CHARACTER-MOTION-PLAN-2026-10-06.md` 实施核心方案。新增具名通道归属：眼眉ω26、嘴ω20、面部位置ω22、身体ω14、附件ω18，低落/困倦身体ω8。欠阻尼只用于独立的身体回应，ζ=.8；原临界阻尼函数保留兼容，按通道组共享解析系数。SVG绘制移至 `orb-render.ts`，缓存已写属性，稳定嘴/眉等路径不重复写入。

目光采用独立快弹簧（指针ω32、离散目标ω45），身体以ω10跟随。大转睛联动眨眼，冷却700ms；自然连眨概率11%，不靠逐事件重播。目光有总范围约束，指针、未过期宿主目标、待机漫游按优先级仲裁。聊天开始流式回复时看向消息区域，助理完成事项时看向刚操作的任务位置；目标只含方向和视觉身份，1200ms到期，不复制内容，不逐token触发。任务已移除时仅使用按下时捕获的位置，后续滚动/resize立即使其失效。

重要状态增加50ms身体预备和一次性回应：完成/惊讶轻跃与伸展，失败轻摇后静止，总回应≤320ms。表情先反映业务，不等待预备；初次挂载不补播历史状态，新cueId支持重复成功事件。按压释放读取实际压缩量，再由合法click/reaction消费有上限的释放速度；取消、滑出、>10px移动不跳，再次按下回收当前回应。旧sampleOrbTouch明确标为兼容采样器，正式轻触不再叠加它。

状态面板52px小球启用动画，头部44px同时暂停；档案/故事嵌套时面板暂停，返回恢复。颜色配置、业务表情保护、账号/角色/会话隔离及系统/应用减少动效继续有效。减少动效直接给静态最终表情，恢复不补播旧成功/失败。未新增运行时依赖，未重打APK。

46项运动与注意力数学检查、87项小球浏览器检查通过，覆盖帧率独立、异常输入、快速转睛、慢姿态无过冲、2–4%完成伸展、320ms归位、冲量与快速打断、目标优先级和范围。角色小球集成21项通过，助理空间28项数据+26项UI通过，流式聊天56项通过，生产分包9项通过。类型检查和生产构建（3.45s）通过；构建体积为当时工作区整体结果：CSS gzip 75,923B（基线+6.69%），主入口497,132B/gzip166,120B。共享绘制/运动模块独立分包，继续遵守500KB入口与既有启动图预算。

## 第四轮：帧率一致性与落地接管 · 2026-10-07

修复回应末尾逐帧累乘衰减造成的帧率差异。底层弹簧状态与显示包络分离，240–320ms 收尾只按绝对动作时间采样；显示速度包含包络导数，因此收尾中被再次触碰时保留实际位置和动量。50ms 预备边界采用分段精确积分，跨越边界的慢帧不会提前施加整帧冲量。失败摇头改为正弦驱动的解析解，避免不同帧率下摇头幅度与相位漂移。非法时间步不启动或改变动作。

修正远离指针后待机巡视时间被后续赋值覆盖的问题。宿主注意力到期主动移除滚动/视口监听并清除目标，隐藏或 inert 的小球不接收目标；键盘捕获仅接受 Enter/Space，避免输入普通文字时误记任务位置。

77 项数学/注意力检查通过，新增 30/60/120Hz 在预备边界、动作中段、收尾和终点的六个位置/速度通道对照，以及收尾打断连续性。87 项小球浏览器、21 项角色面板、助理 28 项数据 + 27 项 UI、56 项流式聊天、9 项生产分包检查通过。TypeScript 与生产构建通过。工作区整体主入口 497,107B / gzip166,115B；CSS gzip75,923B，基线增长6.69%，本轮未增加 CSS 或运行时依赖。

同目录深浅色聊天/面板录像已重新生成。浏览器验证包含双球零逐帧 React 提交、触碰取消、减少动效和暂停恢复；仍未以浏览器结果替代 Android 真机帧时间测量。本轮未重打 APK。

## 第五轮：按表情编排身体动作 · 2026-10-07

新增 `orb-personality.ts`，十二种表情有独立的身体动作节奏：

| 表情 | 动作表现 |
| --- | --- |
| 待机 / 好奇 | 错相呼吸与轻摆；好奇间歇探身、抬眼 |
| 倾听 | 一次点头加较轻的回应，随后停顿 |
| 思考 | 探视、停留、返回，眼睛有明确注视阶段 |
| 忙碌 | 降低漂浮，短暂收紧身体，轨道继续运作 |
| 开心 / 完成 | 有起跳预备、轻跳、较弱回响，笑容与身体同步 |
| 惊讶 | 较快的直立弹起，转身幅度收敛 |
| 害羞 | 微收身、低头、偏向一侧 |
| 困倦 / 低落 | 慢下沉、缓慢呼吸；困倦带轻微哈欠，低落带叹息 |
| 失败 | 保持克制呼吸，摇头仍只由一次性回应触发 |

动作按时间采样，循环边界位置连续、速度为零；自主手势之间保留停顿。动作轨道通过独立临界阻尼混合，切换表情保留当前身体位置和速度，重新进入状态按新的阶段编排。个体呼吸保留错相，手势只使用短相位偏移。按住或一次性回应期间，自主动作柔和降低；指针与业务注视使自主探视退让。有效轻触增加一次短眨眼，取消操作仍不回应。

完成、惊讶、开心分别使用独立的预备时间、伸展、起跳与转身冲量；轻触释放增强压缩量到冲量的传递，保留上限和320ms归位。身体动作带动面部轻微滞后、顶部高光反向运动和投影横移；思考气泡错位浮动，星光错相明暗。新增自主微表情使用 SVG transform，路径形变仍由既有业务表情/眨眼负责。所有静态缩略图、减少动效和暂停场景保持静态。

稳定姿态增加数值归位阈值，隐藏的思考气泡与星光不再持续更新其属性。浏览器检查明确验证待机时隐藏附件与不变嘴部没有逐帧写入。没有添加粒子、滤镜、计时轮询或运行时依赖；共用原帧时钟，新增动作模块并入既有运动分包。

113 项运动数学与动作编排检查、90 项小球浏览器检查、21 项角色面板检查通过；新增全部表情的幅度有界和循环连续、动作停顿、快速切换身体连续、隐藏附件写入检查。助理28项数据+27项UI、生产分包9项及流式聊天回归通过。TypeScript与生产构建（4.32s）通过。当前工作区主入口497,380B/gzip166,170B，CSSgzip75,923B（基线+6.69%，本轮未增长）。
