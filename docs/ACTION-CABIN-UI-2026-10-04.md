# 行动舱视觉与触控精修 · 2026-10-04

本文记录独立交互原型的今日、项目、收集箱、风险、复盘及关联表单精修，入口为 `docs/prototypes/workbench.html`，演示日期仍为 2026-10-03。后续正式 App 已接入“今日 + 手工收集箱”，使用一个共享待办编辑器与真实数据库；正式实现及验收边界见 [第一阶段接入记录](ACTION-CABIN-IMPLEMENTATION-2026-10-04.md)。下文的五页截图和动画测量仍对应独立原型。

## 视觉与动画

- 延续 VirtuGene 的深色、紫青色主题：舱体顶部弱光、DNA 图标、重点区轨道纹理、独立统计面板。风险使用红色、完成使用青色，装饰不冒充业务状态。
- 使用更沉稳的深色底、柔和紫青色及清楚的文字对比，五页统一阅读面板、操作色与表单样式，保留浅色兼容。
- 页签滑动底座保留原节点，440ms 过渡允许连续切换中重新定向。页面最多五个可见结构分组按 18ms 间隔轻入，减少整页同时运动的生硬感；数字只在实际变化时过渡。完成、撤销及筛选保留未变化的任务行，新内容轻入、剩余内容平移。
- 项目进度通过 scaleX 更新，不逐帧改变宽度。轨道、DNA、勾选与操作提示只播放有限动画，静止页面没有持续动画。
- 弹层首次进入 460ms、内部交接 380ms，使用解析阻尼弹簧采样成单次合成动画。回弹带入释放速度，手势中途可接管当前位置；退出从当前拖拽位置继续向下，不先往上缩回。遮罩从当前透明度继续，退出内容立即失去表单标识、事件数据与对话框语义，190ms 后清理。

## 字体与阅读升级

浏览器实际字形检查确认旧页面的“舱”、部分项目/日期信息会回退到微软雅黑，导致同一行字形、粗细不一致。旧辅助文字只有 9–10px，进一步降低清晰度。

现在直接复用应用已有 `src/styles/ui-fonts.css` 的完整本地 Noto Sans SC 字形分片及 100–900 可变字重，禁止合成粗体。预加载常用字形与行动舱必需的第六分片，不依赖外部字体服务。浏览器确认标题、任务、说明、原因、筛选及数字的实际字形全部来自本地字体。

标题 23px / 550，任务正文 14px / 500，任务说明 11.5px、正文说明 13px，筛选与表单标签约 12px；320px 下任务正文仍为 13.5px。重点任务的项目与截止信息拆开排版，必要时只省略项目名，截止时间保持可见。按钮文字按下时轻移一个像素，避免缩放整个文字层；图标按钮保留轻微缩放。

深色阅读及语义文字在最高阅读层的对比度均达到 4.5:1。中文使用自然字距，数字统一使用等宽数字。这里只验证字形来源、尺寸与颜色对比，主观视觉仍通过实际截图核对。

## 触控与性能

下拉手势只在弹层把手的扩展触区启用。判断初始方向后锁定，下拉跟手，短拖回弹，较长距离或有效释放速度关闭；超过正常区域逐渐增加阻力。回弹期间再次按住，从当前显示位置接管。正文与任务列表保留浏览器滚动，不拦截阅读手势。

按钮按下有反馈；移出触区反馈撤回，移出后松手取消，滑回可以确认。键盘、Esc、点击遮罩关闭、焦点约束和关闭后恢复保持可用。任务被移除时优先把焦点交给同一区域的下一操作，不引发滚动跳跃。

之前 render(false) 会重建整块正文及全部页签；现在按稳定身份更新 DOM，筛选不重建重点区、任务更新不替换无关行，批量勾选保留原行和滚动位置。位置测量按批次完成，动画使用 transform/opacity；手势期间只有需要更新时才申请一个 RAF，不开常驻帧循环。页面隐藏或开启减少动态效果时取消未完成动画及退出留影；减少动画不禁用直接手势。

## 验证

复跑命令（运行器均自建临时服务器与隔离浏览器数据）：

```powershell
node scripts/verify/workbench-design.mjs
node scripts/verify/workbench-motion.mjs
```

最新验证：192 项业务与布局检查、70 项字体与动效检查通过，共 262 项。覆盖真实字形来源、禁止合成粗体、文字尺寸与深色对比度、已加载字体离线使用、Chrome 触摸事件、连续操作、键盘、减少动态效果，以及 320/390/430px 深浅色五页与桌面。截图分别输出到 `.tmp-preview/workbench-design/` 和 `.tmp-preview/workbench-motion/`。初轮 167 + 59 项为历史验收统计。

Chrome 4 倍 CPU 降速下连续切换筛选 40 次，首轮测量的同步更新（含样式/布局读取）中位 4.7ms、P95 6.9ms、最大 7.2ms；未变化的重点面板持续复用。这是当前开发机的浏览器测量，不包括完整绘制、GPU 或 Android 真机耗时，不作为真机帧率承诺。

本轮字体与弹簧升级后的同场景测量：中位 5.0ms、P95 7.4ms、最大 8.6ms，未变化的内容持续复用，操作结束后没有残留的持续动画。数据属于独立原型，不是正式应用整体性能测试。

实现主要位于 `workbench-motion.js`、`workbench-motion.css`，原来的 `workbench.js` 与 `workbench-power.js` 仅接入稳定更新、弹层生命周期及焦点恢复。保留独立示例存储键、备份格式及已有保存失败回滚行为。
