# 具体生活自述的来源风险与流式边界

本轮继续以自然、生动、性格鲜明且可信的角色聊天为目标。用户更新后的收尾标准允许综合判断，但当前仍有明显的事实偏差，尚不足以认定效果非常好。

## 已实现

新增 `chat-self-report-risk.ts`，识别有限的一组第一人称、重复发生的具体实体行为，如“我一般会盯着锁屏”“我也经常停留在解锁界面”“我通常看电影时吃苹果片”。这是来源风险提示，不是自动事实裁判。

普通偏好、比喻、否定、引用、问题、假设和明确创作／扮演保持放行。实体行为词采用较窄的对象组合，避免将“吃亏”“站在你这边”“跑题”按身体经历拦截。“我平时看电影喜欢推理片”仍作为偏好处理。

设定正文与显式提供的角色生活资料可降低这项风险；声音样本、引用、用户或第三方资料、负面指令不作为自述支持。资料必须包含重复发生的线索，一次经历和喜欢某事不等于已经有此习惯。匹配只检查四字动作对象及频次，并非全文语义证明；没有风险提示绝不代表新增细节可信。

检查接入私聊、主动消息及群聊的共享质量入口。私聊只传本轮完整进入提示词的角色生命轨迹条目，不将旧 assistant 自述或用户记忆作为个人习惯证据。主动消息使用已提供的角色生活线索。群聊依照该角色的设定检查，不把混合的公开／私人记忆笼统作为角色个人经历证据。

存储的生活轨迹可能来自历史提取，不能据“单独存储”保证来源事实本身正确。这一检查不承担生活记录真实性审核、细节一致性或跨来源归属的完整语义判断。非中文、未覆盖动作、其他自传表述仍可能漏检。

未上屏稿件沿用既有的一次质量重试，不增加常规第二个模型评审。主动消息两稿仍有风险则不发，群聊沿用每角色一次重试预算与兜底检查；私聊保留既有最佳稿选择机制，所以并非“两稿有风险一定不会显示”。

**已经流式显示的内容不静默替换。** 新检查记录这类风险而非假称已修复。新增 `self-report-risk` 统计枚举，确保问题不会在聚合时丢失或被当作改善。统计不存正文、人设或密钥。

## 真实测试

### 全新六轮：林霜 everyday R6

使用当前真实私聊发送、独立 IndexedDB 与默认生成路径，无回放。六轮均正常结束，一轮一次调用，无质量重试。此组未出现目标习惯句，不能证明检查阻止了它。

仍出现明确问题：

- “那说明……本来也不着急”把忘记意图解释成事情不着急。
- “从招牌跳到忘拿手机”再次把拿起手机后忘了要做什么误读成忘拿手机。
- “慢慢吃是催你别噎着”从名字推断店铺用意。
- “算你脑子转得快嘴没跟上”替用户做心理解释。

推理故事的偏好和技术比喻可辨认，但这些偏差仍影响自然可信程度，不给予完整人味通过结论。

### 已保存错误稿回放：真实流式路径

从林霜 R5 取前两轮真实提供方原稿，重新通过当前私聊发送和数据库。回放不算新的模型回答，不产生付费调用。

第二轮原稿包含“我一般会盯着锁屏等它主动交代，当然它不会”。正文已按原路径显示，因此没有触发隐蔽重试。第一个报告 `complete=false` 表示未观察到所期待的重试，不是会话发送失败。它没有证明模型改好。

修复新风险枚举的统计登记后，用 R2 报告再次回放。实际质量面板数据中，`self-report-risk=1`、`streamedUnresolved=1`、新增提供方调用为零。这证明统计接线有效，同时明确证明当前流式路径仍会显示这一风险。

### 显式诊断：延后显示，验证未上屏重试

测试工具加入 `LIVE_DEFER_DELIVERY`，仅用于这份诊断，删除发送参数的 `onDelta`。正常真实样本和产品生产路径都保留原有流式呈现。

同一错误稿触发一次真正的模型重试，结果为：

> 这算什么，脑子把任务挂起还没给返回值。
>
> 说明你拿手机那一下，纯属条件反射，目标早丢了。

新的稿件没有再声称自己的锁屏习惯，但“纯属条件反射”仍是没有用户依据的原因解释。`complete=true` 只证明此诊断触发了一个完整新调用，不能代表回复真实性、人味或正常流式效果达标。

## 下一步与发布状态

新增检查关闭了一个原先完全不可见的局部来源风险，并揭示了“逻辑重试可用”与“流式用户实际不会经历重试”的差异。下一步继续处理无来源的原因解释与不准确回顾，并在保持自然语气和流式体验的前提下改善内容可靠性，不能靠给全部回复追加审查调用或删除文字伪装完成。

本轮没有重新打包或发布，官网仍提供此前的 6.0.3；目标保持进行中。
