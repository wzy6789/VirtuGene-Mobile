# 角色记忆维护约定

维护目标：同一角色在私聊、群聊、星域、朋友圈与主动问候中，保有自己已经知道的经历。记得一件事不代表每轮都必须重讲它。

## 共同入口

`src/lib/character-memory.ts` 的 `buildCharacterMemoryContext` 负责来源核验、知情权限、检索、排名、冷却、去重、篇幅与溯源。调用方提供用户、角色、当前话题、最近交流、现场与听众；调用方不再单独筛选长期资料。

不同入口共用 `chat/group/world/moment/todo/diary` 来源。`mode` 表明调用场景，不建立另一份记忆库，也不改变角色归属。个人约定、人物共同事件、自己的生活与会话摘要在共同入口里归入对应来源。

原始表保留各自的正文和来源关系，统一的是角色取用规则，不复制整份私密正文到一个新库。记忆台账与使用记录负责证据及溯源，原资料和当前权限仍是事实依据。

## 身份与权限

- 归属以 `userId + characterId` 为准，不按名字合并不同角色。
- 当前世界是现场信息，不是个人记忆检索的边界；角色自己的知情记录跨用户拥有的世界延续。
- 私聊只使用当前角色的资料；多人共享提示词只使用每位听众均有权知道的交集。
- 星域和群聊的每位 Actor 可以在独立请求里读取自己的经历。公开输出之前核验披露边界，不把 A 的个人资料传给 B 或公共导演。
- 群聊按消息产生时的见证快照判断，不因后来加入就继承旧事。
- 动态、日记与待办继续使用实际浏览、当前分享、认知授权等各自闸门；查旧事不等于获得新权限。
- 删除、改写、撤回与备份恢复须保留版本和墓碑处理。摘要不得绕过来源版本校验。
- “从此刻参与”只限制本场入场前正文；只有用户明确选择失忆玩法，才关闭过往召回。

## 现场与长期资料

页面可以附带当前会话正文、当前场景状态、人设和关系状态。这些是现场或即时状态。更早的摘要、个人事实、约定和跨入口经历必须经过共同入口。

实时回复只渲染服务已选中并打包的 `references/text/sections`，不把 `catalog` 再塞一遍。目录用于授权档案查看。当前内容被预算完整保留后才记录为已注入，历史来源仍保留正确的渠道和原文标识。

重复内容的冷却从最近交流计算，不能通过清空资料、永久禁词或固定话题实现。用户提起旧事时仍应可按权限找回。

## 星域约定

不自动生成或注入物件背景，不预设物件主题与悬念。物件须由用户主动提起；角色或模型先说出的东西不代替用户选择。历史物件数据保留兼容读取，不作为当前背景。

`src/lib/world/world-time.ts` 处理用户场景时间。时间标签是用户设定，现实时间仅为记录提供存储时间戳；旧记录日期不代表现在。相对跳跃从场景锚点推进，新片段延续用户时间，撤销恢复完整时间状态。虚构纪年无法数值化时保留原文，不补现实日期。

## 必要验证

调整记忆读取后至少验证 `memory-unified`、`memory-attention`、`memory-final`、`memory-continuity` 和 `character-memory`；涉及星域调用、权限、时间与重试时增加 `worldA/worldB/worldE/worldF`。`memory-unified` 含真实私聊组件发送检查。模型边界使用替身，不消耗用户真实服务。

2026-09-30 改动和结果见 [MEMORY-ATTENTION-2026-09-30.md](MEMORY-ATTENTION-2026-09-30.md)。

## 私人助理记忆

助理使用 `src/lib/secretary/memory.ts` 作为同一账号助理工作区的共同取用入口，沿用 `memories`、来源修订、墓碑与备份同步。保存用户原话、偏好，按需检索自己的旧私聊和真实办事进展；改名、换会话及聘用后延续用户资料。助理不会接入角色的群聊、星域及继承候选，办事记忆不构成新的执行授权。

明确记住、纠正、忘记以及不让记的指令必须同时处理结构化事实与旧原话检索，避免删除了事实却从旧交流重建。助理记忆改动增加 `secretary-memory` 和原有助理检查，细节见 [ASSISTANT-MEMORY-2026-10-02.md](ASSISTANT-MEMORY-2026-10-02.md)。

长期事实先过滤当前话题；冷却及预算未选中的事实不能再从原消息重复注入。任务回执与实际记录均核验版本，生成期间改写、撤回、新完成日期实例或日记重锁时阻止过期答复。召回优化及76项专项检查见 [ASSISTANT-MEMORY-OPTIMIZATION-2026-10-03.md](ASSISTANT-MEMORY-OPTIMIZATION-2026-10-03.md)。

工作记忆继续支持常见问法与同会话短句接续，索引覆盖完整原话并优先检索稀有主题词。部分提炼的原话只移除已提炼片段，保留其他工作信息；表达偏好持续应用，话题冷却不等于忘掉用户要求。长消息提供相关片段，近期聊天也核验版本。明确工作概览可召回跨会话实际进度，角色代发仅提供原始办事回执状态。107项记忆专项及实现范围见 [ASSISTANT-MEMORY-SERVICE-2026-10-03.md](ASSISTANT-MEMORY-SERVICE-2026-10-03.md)。
