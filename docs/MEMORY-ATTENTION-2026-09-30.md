# 星域物件、统一记忆与用户时间修正（2026-09-30）

用户要求：不预设物件作为背景或主题；记忆统一并随角色延续；星域遵循用户设定的时间。

## 已修正的原因

字条并非只来自模型临时发挥。`world-object-repo.ts` 原先会为场景自动生成三件物品，普通地点包含“留在桌面的字条”，其他地点包含湿纸页或票根。场景创建、进入、移动与探索都会调用这套默认物件生成。物件随后不断进入导演和角色的现场上下文，旧摘要、目标和经历又会强化同一内容。

此前不同入口虽已调用统一记忆服务，仍在页面额外读取、重新筛选和拼接部分长期资料。星域额外读取早前私聊摘要、按目录再次渲染记忆；私聊另查默认世界的经历、日记、待办等；群聊另带待办；主动问候另挑一个固定跟进问题。这些旁路使召回结果随入口改变，并可能重复注入。

旧舞台生成还注入现实时间；用户跳时间时又把原话重写为根据手机时钟推算的粗略时段。新片段未继承用户时间，数字时刻的视觉光线也未识别。

## 物件背景

- 删除默认物件模板与场景自动生成调用，兼容接口不再写物件。
- 探索面板只保留人物、地点与前往动作，移除背景物件与物件操作入口。
- 导演、角色与旁白不读取或注入物件清单；旧存档里的物件也不作为背景。
- 共用规则明确禁止预设物件背景、主题、任务或悬念。物件内容须由用户主动提起；“继续”“随便聊”“看看周围”不能代替选择。
- 用户主动提起的内容仍可回应，不删除历史正文或旧物件记录。
- 最近正文中的重复内容由共同冷却规则处理。冷却随窗口过期，不永久删除记忆；用户重新提起可按权限召回。

## 统一记忆

`buildCharacterMemoryContext` 是私聊、群聊、星域 Actor、旧舞台、朋友圈评论与主动问候的共同取用入口。各入口查同一组来源，区别由角色身份、听众权限、现场正文和篇幅决定。

私聊移除额外长期资料读取与二次排序，仅格式化服务已选中的引用。星域实时 Actor 直接使用服务的已打包文本，不再额外拼早前摘要或目录资料；目录用于授权档案查看。个人约定、人物共同事件、可提起的世界事件及经来源核验的旧会话摘要也进入共同服务。已知事件跨用户拥有的世界检索，目录同步按全部听众的知情交集取用。

角色以 `userId + characterId` 识别。换聊天入口、地点或世界不改变这个人的记忆归属。“从此刻参与”只限制入场前的本场正文，保留自己的过往；明确选择失忆模式时才关闭过往召回。角色自己的私聊和生活进入各自 Actor 请求，不给其他角色或公共导演；公开台词继续经过披露检查。删除、改写、撤回与来源版本检查仍然生效。

## 用户时间

- 共用星域时间说明：用户场景时间优先于现实日期、手机时间与旧记忆日期。
- 旧舞台移除现实时间注入。导演、Actor、旁白、意图解析和自主编排均遵循场景时间。
- 保存用户的日期、时刻、时段与虚构纪年，无法数值化的设定也保留原文。
- 新场景初始化冻结的时间锚点；相对跳跃从场景当前时间计算。精确日期、中文几点/半点/分钟、三天后和两小时后有本地处理。
- 新片段继承上一段时间与锚点；撤销恢复时间标签、偏移与锚点。
- 光线识别精确时刻，时间变化立即更新视觉状态。
