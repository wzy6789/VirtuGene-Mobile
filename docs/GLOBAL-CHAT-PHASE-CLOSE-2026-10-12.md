# 全局聊天优化阶段收尾与暂停 · 2026-10-12

按用户明确指令停止新增优化方向，只收尾正在处理的私聊发送前记忆核对与必要回归；不追加付费调用、不升版本、不构建产品、不打包或发布。此为阶段暂停，不是完整目标达标。

## 已完成的工程项

- 保留原角色卡与生活记录，保存工作区基线及审计证据；共用上下文预算计入分隔符，身份/关系关键段保持完整。
- 普通角色与预设使用一致的关系来源规则，互动数值不再自动推导亲密关系；角色性格标签不自动制造过去的熟悉关系。独立设定仍保留。
- 摘要依据当前原消息及准确版本，孤立/过时摘要不再代替事实；关键词相关性优先于无关固定记忆。
- 记忆读取区分无匹配、不可用、拒绝和可引用候选。当前已适配的聊天、群聊、主动、动态与世界入口使用相同的读取状态基础，不能据此宣称所有入口已完成发送前保护。
- 世界范围限制、同时间戳历史分页兼容索引、并发/切会话上翻保护已落地。历史仍线性扫描；桌面合成规模证据不是 Android 验收。
- 读取中删除/撤权会退出候选，完整来源快照覆盖聊天/日记/待办及世界/动态依赖；返回前整批重新核对可见性、知情资格和世界归属。
- **本次收尾**：私聊每次模型发送与重试前，只读核对统一召回的来源。发生改变时本地剔除旧引用并重编译相关记忆区块，更新回复来源说明及用于检查的回忆习惯证据；不额外生成、不要求重新说完整问题。有效且未改变的记忆保留。

## 本次失败与修正

类型检查首次因 Object.hasOwn 超出现有 TS 库目标失败，已改用现有目标兼容的 hasOwnProperty；未调整项目编译目标。

首次出站用例失败，随后定位为测试时序错误：第三次 validate 在回复落库时才执行，已经晚于模型请求；错误用例不能证明“发送前编辑仍泄漏”。已改为第二次 validate（当前生产循环发送点）修改记录，并实际检查最终模型请求和真实来源变化。原失败与诊断日志保留，不改写。

重编译时重新构造来源追踪对象，不能用 Object.assign 保留旧对象中已消失的来源字段。补测保留/编辑/删除三种实际发送流程，检查回复落库及追踪与出站正文一致。

## 模型用量与真实样本边界

本次收尾及近几批来源保护新增真实模型调用 **0**，token **0**，没有新增聊天原稿，不更新最佳聊天。测试传输为替身，不是模型人味评分。

已记录的四份开发样本分别为 memory-live、relation-live、source-live、retrieval-live：已知 token 21543、9587、至少2554、2056；这四份证据合计已知下限35740，source-live另两次后台用量未知，不是整个长期任务的完整账单。关系样本有首答空输出、编旧话和未知被否定的问题；来源契约样本仍有负向回忆；最新读取状态样本只有单轮开发观察。不能据此报告全局人味达标或封存样本胜率。

## 尚未验证 / 未完成

- 完整固定样本、封存角色与场景、25–40轮长聊、三会话连续性及预设评分门槛，没有完整达标证据。
- 群聊、世界、主动、动态、语音等各自产生的其它提示/媒体/现场记录，尚未全部接入最终发出请求前的核对；本次只保证已验收的统一召回私聊路径。
- 当前会话 history、摘要、动态操作区块、媒体与身份在请求前改变的全部边界，仍需专项验证；不能将本次统一召回核对扩大解释为全部提示内容已保护。
- 已经发出的内容不能回溯撤销；异步账本在先前组装阶段记为 injected 的使用记录、之后的来源变化与撤回仍需审查。本次回复 contextTrace 与实际出站正文的对应已补测，但不是完整账本真实性验收。
- 模型请求内部的异步准备窗口、来源知情资格历史版本、读取/网络交界处的并发原子性仍未证明。
- Android 设备上的性能、实际提醒、语音听感/音频路由和手机体验未完整验收；桌面样本与模拟传输不能代替这些门槛。
