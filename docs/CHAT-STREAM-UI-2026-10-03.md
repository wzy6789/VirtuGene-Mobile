# 普通私聊流式气泡适配

本轮围绕已有的普通私聊流式接口调整展示层，保留请求、取消、会话隔离、流式缓冲和最终持久化流程。

## 展示与衔接

- 光标放在正文末尾，使用主题青色；只在最后一段显示。零宽度占位不会额外挤出一行，结束或停止时移除。
- 每个新分段只进行一次 300ms 渐显与 6px 轻移，使用柔和减速曲线；逐片段更新复用原 DOM。正文容器不重复播放入场动画，气泡宽高直接跟随排版。
- 流式段落使用正常换行，避免每次追加内容重新平衡前面的行。
- 预览分段独立包含外边距，与虚拟列表正式行一致，消除保存后的段间距偏移。记录已显示的流式消息 ID，正式行跳过入场与扫光。
- 待生成气泡关闭复制、朗读和长按菜单，正式消息恢复原操作。等待状态提供读屏提示，逐片段正文不触发重复播报。
- 流式语音消息继续以原字号显示正文，语音准备/播放放在正文下方。预留控件高度，音频就绪时保持布局稳定；播放按钮热区至少 48px。传统语音气泡保留原有转文字方式。
- 保留原有长回复跟随、阅读历史不抢滚动、回到最新及停止/断流状态。

## 流畅度加强

- 普通聊天等待状态和首字复用同一个气泡、头像与布局锚点。气泡最小宽度 66px，单个首字不会让等待气泡突然收缩。首段文字进行一次 220ms 渐显，不随追加片段重新启动。
- 发送/停止保持同一个按钮 DOM，仅对两层图标进行透明度、轻移与缩放过渡，热区不变。标题下方只有变化的状态文字进行过渡。
- 流式回复新增一两行时，60px 以内的底部距离按实际帧时间阻尼收尾，最长 160ms；大段到达、切换会话、聚焦输入框和键盘变化仍直接调整。每帧直接写滚动位置，不产生 React 提交，触摸/滚轮/键盘介入即取消。
- 入场动画使用 backwards 填充，完成后恢复 transform:none，避免长气泡持续保留变换层。主题青色用于光标与生成中的轻边界提示。
- 系统或应用减少动态效果会移除文字、图标、等待点动画，并让滚动直接到位。
- “回到最新”使用最长 420ms 的柔和减速，持续追踪虚拟列表的实际底部。触摸、滚轮、Escape 和导航键可中途取消；生成结束或旧 effect 清理不会误取消新的返回动作。键盘触发时焦点转到聊天记录，便于立即接管滚动。
- 返回按钮保留布局锚点并平滑淡出，隐藏状态立即设为 inert、aria-hidden 和 tabIndex=-1，避免淡出期间误触或键盘跳入。
- 停止和断流提示增加安静的主题色图标与 220ms 轻入场；正文与气泡继续保留。
