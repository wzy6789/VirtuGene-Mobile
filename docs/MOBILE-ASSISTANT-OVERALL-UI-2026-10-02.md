# 助理整体交互与布局优化

本轮延续助理专用的紫色、青色和中性卡片材料，重点调整信息和操作的位置。

- 聊天页直接展示记日记、写朋友圈和加待办，今天安排、查记录、改待办和每日整理归入可展开的更多办事。采用四列布局，窄屏不必横向滑动找入口。展开支持平滑反向过渡、键盘、inert 和减少动态效果；展开本身不发送请求。
- 工作台菜单将办事收件箱和每日整理放在并列入口卡片中，管理、能力和习惯保持次级操作行。
- 管理、每日整理、办事习惯和聘用使用稳定的长表单弹窗。主要按钮放在滚动内容外的底部操作区；错误与保存提示也在操作区内显示。长表单滚动时无需再翻到底部寻找保存。
- 管理资料按基本资料、性格偏好和形象划分表单区块。办事习惯按记录与表达、回应与安排分组，320px 时改为单列输入。
- 收件箱分类在内容滚动时保持可见，请求按日期增加分组标记，读取过程中提供静态骨架。保留真实请求、结果和分类的既有逻辑。
- 表单原生日期选择器、单选和复选控件跟随深浅主题，改善深色界面的图标和控件对比度。
- 首页助理入口仍保持与普通会话相近的 84px 内容高度，点击后才展开。

实现入口：`SecretaryQuickActions.tsx`。`Modal.tsx` 增加可选 footer，未传 footer 的弹窗保留原有结构和行为；固定操作区仅在本轮助理表单中使用。

验证：

- TypeScript 与 Vite 生产构建通过。
- 助理回归 331 项数据检查、94 项界面检查通过。补充检查了展开快捷项不发送请求、长表单滚动时保存按钮位置稳定。旧能力目录断言同步到现有的 14 项能力，包含已添加的待办步骤。
- mobile-soul、ui-polish、swipes、character-ui、character-create、character-scroll 六组回归通过。
- Chrome 实际触屏预览检查浅色/深色、320/390/430px、560px 窗口高度、快速反向展开、底部操作可见性、表单与操作区边界、弹窗焦点循环、收件箱分类固定和减少动态效果。没有横向溢出或运行时错误。
