# 角色记忆最终检查与修复（2026-09-26）

## 验收标准

记忆归角色和当前账号所有，而不是归某一种界面所有。同一角色可以在私聊、群聊、星域与朋友圈评论中检索自己的已知内容；换角色、换账号、未亲历或未获授权，不得扩大知情范围。多人场合继续要求本轮全部听众通过权限校验。

## 本轮修复

1. **切换世界丢失其他世界经历**：统一服务不再把个人历史限制在当前 worldId/sceneId。对本账号全部世界逐条核验角色见证、认知、可见性后检索；世界设定仍按所在世界读取。
2. **追问必须说“还记得”才能回查**：普通问题（去哪、哪里、给谁等）也会检索较早私聊、群聊、星域正文和看过的动态。候选范围扩大不代表开放权限；普通追问不能读取未看过的动态，朋友圈历史时间窗不变。
3. **进行中星域被新结束的星域挤掉**：先筛选 active/paused，再限制最近场景数量；历史正文按问题检索，取消检索前截断最近正文及固定历史场景数造成的漏召回。
4. **刚回答过的记忆下一轮被排除**：取消私聊用之前六条回复的溯源排除本轮资料。只排除本轮其他区块已完整注入的相同来源。
5. **授权日记绑定当前世界**：统一服务同时检查当前逐条授权和该角色已有的 full/canMention 认知，不依赖当前世界；撤回后下一轮立即失去访问。多人取交集。
6. **未完成待办在跨模式追问中遗漏**：允许召回授权且与问题相关的未完成事项，明确标为未完成。无日期事项不在无关问题中默认注入。
7. **日记及星域摘要重复占上下文**：私聊与星域渲染按本轮已注入来源去重，统一打包同时按来源 id 和文本去重，钉住的记忆优先。
8. **旧点赞被不相关的新帖挤掉**：互动记忆附带所属帖子的主题，参与相关性排序，保留用户设置的可见性与历史时间窗。

所有改变均在读取、检索和上下文组装路径；未清空用户聊天记录，未修改历史正文，未生成新 APK 或发布官网。

## 实际边界

通过证明的是已覆盖数据及权限条件下的上下文互通，不是保证模型每次都正确引用全部记忆。有限上下文仍按相关性与预算选取；被删除或此前从未保存的原文不能恢复；不同角色 id 不会因为同名自动共享。大型长期数据库的原文检索性能还需真机长期数据验证。
