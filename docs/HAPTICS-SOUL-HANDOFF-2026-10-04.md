# 触感反馈与头像／图片接力实施记录

日期：2026-10-04。依据 `ui-next-haptics-shared-element.md` 的审阅修订稿实施。应用代码、浏览器行为及 Android 构建已验证；真实设备的力度和帧时间仍待实测。

## 已实施的体验

设置的“外观与阅读 → 动态效果”增加持久化的“触感反馈”，默认开启，独立于减少动效。统一封装位于 `src/lib/haptics.ts`，原生使用 `@capacitor/haptics@8.0.2`，Web 在支持时使用振动，否则安静降级。

| 触点 | 实际反馈时机 |
| --- | --- |
| 设置开关、底部导航 | 有效切换时轻反馈；关闭触感本身不震动。 |
| 横滑 Tab | 实际提交切换后确认；导航点击与滑动入口分别处理，避免双重反馈。 |
| 会话行左滑 | 预计落点首次跨过阈值时反馈；同一次手势反复跨阈值不重复。 |
| 消息长按菜单 | 菜单可用并激活时确认；生成中的消息不开放菜单。 |
| 字号尺 | 拖动中安静，正常松手且字号改变时反馈；键盘边界不反馈。 |
| 普通聊天发送 | 当前用户消息成功保存后确认，模型请求开始前触发；自动代发与重试不走此确认入口。 |
| 录音 | 实际开始录音时确认；独立取消录音操作给警示，同一次按住录音后滑出取消不补第二次反馈。 |
| 手账锁 | 实际校验后的成功或失败结果；账号、输入或组件变化会使过时结果失效。 |
| 删除角色、注销账号 | 用户确认执行时警示；隐藏会话和待办软删除不混用强警示。 |
| 关系里程碑 | 同一事件对象只庆祝一次，后台或回复静默期间跳过，不补发。 |

封装使用单调时间的 60ms 全局节流，只即时接纳，不排队。选择反馈执行 `selectionStart → selectionChanged → selectionEnd`；途中关闭偏好或切换账号会阻止过时振动，但仍释放生命周期。原生与 Web 分支互斥，插件异常不会阻塞交互。

回复服务取得独立静默令牌，在 `finally` 释放；并发请求各自释放，账号变化清除旧令牌。静默覆盖整次角色回复服务调用，包含模型输出及其收尾；输出 token、完成提示和自动补发都不触发确认。

## 接力与流畅度

`src/lib/soul-handoff.ts` 注册真实元素，按角色或媒体 ID 匹配，只保留一个不接收输入的视觉副本。没有克隆整个聊天或新增逐帧 React 状态。采样复用 `mobile-motion.ts` 的临界阻尼进度，现有页面和弹窗曲线不变。

| 路径 | 当前实现 |
| --- | --- |
| 会话列表 → 聊天页头 | 原头像飞向紧凑的 32px 页头头像；异步选择完成后才进入。 |
| 聊天 → 会话／角色列表 | 恢复原来的滚动、搜索和角色筛选后计算落点，不为动画滚动列表。 |
| 角色资料 → 聊天 | 使用资料弹窗当前可见头像；副本位于弹窗之上，资料关闭或卸载后的迟到操作不再导航。 |
| 动态图片 → 图片预览 | 使用媒体 ID；外层展开裁切区域、内层补偿缩放，保持图片比例，落点按真实 contain 图片区域计算。 |

头像主要通过 transform 飞行，小面积圆角同时过渡；圆角属于有限重绘，不能宣称整条动画完全不重绘。表情头像额外匹配目标字号，避免恢复真实页头时突然变大或变小。

新触摸、窗口失焦、视口变化、账号变化、减少动效、目标卸载和无关导航均释放副本、标记、动画、定时器和监听。未加载、源不在视口或目标无效时直接恢复；等待目标有 300ms 上限，导航不等待动画。图片翻页或新预览手势也立即交还控制。

会话选择增加代次检查及 reset 失效机制，避免迟到的旧选择覆盖新会话；分享日记也核对最终角色和账号。

## 验证与交付

浏览器使用 Chrome、真实 React 组件与 IndexedDB；模型传输、Native Haptics API 和 Web 振动由测试替身记录。没有将替身调用认定为设备触感验收。

| 验证 | 结果 |
| --- | --- |
| `run-haptics-handoff.cjs` | 55 项：真实开关、字号、左滑、PIN、会话和资料入口、正反向接力、图片比例、输入接管、动态取消、原生 API 生命周期、选择竞争及 reset。 |
| `chat-stream-ui.mjs` | 56 项：含真实消息保存确认、流式期间静默与完成后的令牌释放。 |
| `run-settings-ui.cjs` / `run-ui-audit.cjs` | 55 / 88 项通过；深浅色和窄屏兼容。 |
| `run-touch-fluidity.cjs` / `run-page-motion.cjs` / `run-modal-motion.cjs` | 31 / 29 / 27 项通过。 |
| `run-settings-motion.cjs` | 所有场景组通过，包括实际触摸滚动、快速返回、敏感页、减少动效与桌面兼容。 |
| `design-tokens.mjs` | 367 项通过。 |
| TypeScript / renderer 生产构建 | 通过。 |
| Android | `cap sync android`、Manifest 合并、`:app:assembleDebug` 通过。 |

新增专项复跑：

```powershell
node scripts/verify/run-haptics-handoff.cjs
node scripts/verify/chat-stream-ui.mjs
```

先构建 renderer，专项运行器会读取本次生产 CSS；自身启动临时服务器，截图保存在 `.tmp-preview/haptics-handoff-20261004/`。设置相关运行器仍依照验证 README 构建 fixture 并启动验证服务器。

Android 已生成 `android/app/build/outputs/apk/debug/app-debug.apk`，包含 HapticsPlugin 注册与合并后的普通权限 `android.permission.VIBRATE`。新增原生插件需要更新安装包，单独热更新 renderer 无法注册插件。未安装到用户手机，也未替用户发布。

待设备实测：不同机型的力度、系统关闭触感时的行为、快速连续操作，以及普通 Android 上接力与流式聊天并行时的帧时间。本次浏览器验证和 APK 构建通过不代表这些设备指标已通过。
