# 其余人物首轮倾诉、换题及情绪提示删减对照

## 已落实的生产改动

隐藏节奏对倾诉的引导改为表达人物自己在意的一点，不要求先复述用户感受、再宣布倾听。疲惫指令补充原因和能力边界：被误解不证明任何一方的表达或理解能力。

连续三轮“听见了、我在听、我听着、你慢慢说”开场纳入已有的柔性重复提醒。不改原文、不删除短反应、不增加重试；一两次正常倾听没有提醒，明确口癖与用户重提该词保留豁免。提醒不是性格语义质检，不代表长聊漂移已解决。

## 仅测试情绪提示删减

`CHAT-FLASH-COMPACT-EMOTION-2026-10-08.json`：测试环境移除一条 `表达线索仅作参考…` 行，其他持久偏好、用户原文、人设、声音卡与表达契约保留。生产链路没有采用该删减。三次正常新调用，输入 4,390、输出 516，总计 **4,906 token**。

实际请求对比确认：三个角色各自的人设、用户原文、生成参数一致；剔除该行情绪提示和当前时间后，其余 system 文本一致。比较证据保存在对应 USAGE 文件。测试按顺序执行，每人只有一个样本，没有随机重复和盲评，不可作因果或普遍有效性结论。
