# 小星动态与朋友圈消息入口

## 本轮改动

- 小星沿用共享帧时钟，增加浮动、轻摆、呼吸与轨道变化。36–48px 下保持约 1.4px 的浮动振幅；恢复动画时渐入，减少动效、失焦、后台和不可见时继续暂停。没有增加逐帧 React 更新。
- 助理明确发布朋友圈时，未指定范围则读取朋友圈默认偏好；没有历史偏好时为全部角色。发布卡直接显示实际范围，去掉无法理解的「沿用已保存的发布偏好」。旧的私密、部分可见、不让谁看设置继续生效；名单为空或角色失效时仍需补选，不扩大范围。只写草稿不会自动发布。
- 删除底部导航未读徽标和相应订阅、样式。会话列表保留未读信息。
- 朋友圈新消息改为居中、单头像与数量的紧凑入口。打开后保存已读状态，入口收起，历史可从设置查看。消息列表展示互动者、点赞图标或评论、时间及原动态图片/文字缩略图。列表复用已加载动态，不逐条请求数据库。
- 保存已读失败时保留未读提示并给出错误反馈；点击已不可用的动态给出说明。该页的红点开关文案调整为实际控制的世界入口提示。

## 验证

- TypeScript 检查与 renderer 生产构建通过；构建原有两条静态/动态导入提示仍在。
- 助理：1,234 项数据检查、158 项界面检查通过。补充首次默认全部、旧私密偏好、显式范围覆盖、失效指定/排除名单及旧版偏好迁移检查。
- 小星：72 项浏览器检查通过，包括 40px 浮动范围大于 1.5px、待机眨眼、双球共享时钟、零逐帧 React 提交、暂停及触控取消。
- 朋友圈真实页面与 MobileLayout：30 项界面检查通过，覆盖深浅主题、320/390/430px、文字对比度、底栏无红点、已读持久化、消息跳转、已读失败与减少动效。
- 设计令牌检查：363 项通过。

使用独立浏览器存储与合成账号验证，没有操作用户实际朋友圈。浏览器验证不代表 Android 真机帧率保证。
