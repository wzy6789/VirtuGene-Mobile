# 助理接入后的过渡动画

本轮调整手机助理入口、快捷办事、任务状态和工作台弹窗的连续性。

- 工作台转入管理、收件箱、每日整理、办事习惯和能力目录时，沿用当前遮罩亮度，旧面板在新面板下方淡出；新面板从接近原面板的位置自然落定。交接约 300ms，旧面板淡出 160ms。独立打开约 360ms，独立关闭 180ms，长表单增加轻微的 14px 入场位移。
- 旧面板只是不可交互的视觉快照，设置 inert、aria-hidden 并移除 dialog 语义。快速反向切换最多保留一帧旧面板，窗口变化、页面隐藏或减少动态效果时清理动画。嵌套弹窗保留独立层级，不把父弹窗当作替换对象。
- 首页助理默认仍与普通会话一样紧凑。入口和更多办事的高度变化统一到 360ms，文字、图标采用轻微位移和稍后淡入；切换状态只更新状态标签，不重新播放整张历史消息卡的入场。
- 聊天容器变化不再无条件滚到底。阅读旧记录时展开或收起工具保留滚动位置；停在底部时继续跟随最新消息。发送、新消息和输入框编辑时的键盘调整保留原有跟随行为。切换会话重新绑定滚动容器的观察器。
- 助理结果卡、管理、收件箱和每日整理组件直接随聊天组件加载，避免首次打开时 Suspense 空白打断交接。代价是这些模块进入主包；当前构建主包 gzip 约 550KB，较调整前约增加 27KB，既有大包提示仍存在。
- 为聊天标题、快捷办事和各助理弹窗设置不同的组件 key，消除同一助理 ID 在兄弟组件中重复引发的警告和更新异常。

验证结果：

- TypeScript 和 Vite 生产构建通过。
- 助理完整回归：374 项数据检查、101 项界面检查通过。
- ui-polish 104、mobile-refinement 151、mobile-soul 219、swipes 31、group-layout 17 项检查通过；长表单位置断言改为在入场完成后测量。
- 新增 `scripts/verify/run-secretary-motion.cjs`，使用真实聊天组件和 80 条历史记录检查浅色/深色的历史阅读位置、底部跟随、重新挂载会话、五个工作台目的地的遮罩交接、快速反向切换、320px 窗口变化和减少动态效果。检查连续切换后仍只有一个聊天容器、一组办事按钮，并检查运行时及控制台错误。
- 运行方式：构建应用后执行 `node scripts/verify/build-secretary.mjs`，启动验证服务器 `scripts/verify/serve.cjs`（17899），再执行 `node scripts/verify/run-secretary-motion.cjs`。
