## 1. 一句话

世界页多了一个「关系网络」：**现在是什么关系**（等阶 + 真实共同经历计数），
以及**为什么会变成这样**（关系变化史里的真实原因）。数字一律不出现。

```
世界 → 关系网络
 ├─ 你和他们（每个角色）
 │    现在：关系等阶（来自 4.x 好感度，唯一来源）+ 共同经历/未做完的真实条数
 │    为什么：关系变化史里真实发生过的原因（含 4.x 等阶升级，实时写入）
 └─ 他们之间（角色 ↔ 角色）
      世界层独有：4.x 从来没有"角色之间的关系"
      有分面 ⇒ 用人话讲（很信任对方 / 有些摩擦 …），没有记录 ⇒ 如实说还没有
```

## 2. 「可解释」是怎么落地的（本阶段唯一的新写入）

2b-0 已经做到：**4.x 等阶升级 → 一条 `relationship` 世界事件**（标题就是「关系进入「熟悉」阶段」）。
本阶段在同一个位置补上第二件事：**把"为什么"写进关系变化史**（`relationshipEvents`）。

```ts
// world-writer.ts（type === 'relationship' 时）
await relationshipRepo.applyEvent({
  a: userRef(userId), b: characterRef(characterId),
  facets: {},                       // ← 只记录原因，**不改任何数值**
  reason: lifeEvent.title,          // ← 「关系进入「熟悉」阶段」
  sourceEventId: event.id,          // ← 与那条世界事件互相可追溯
  idempotencyKey: lifeEvent.id,     // ← 幂等：重复同步不写第二条
});
```

**为什么 `facets: {}`**：好感度等数值的唯一来源仍然是 4.x 的 `CharacterState`
（这就是尚未裁定的 **R7**）。如果这里也去写 `relationshipStates.affinity`，
就会出现两套数值、迟早互相打架。所以本阶段**只记录"为什么"，一个数字都不写**，
验收里有一条专门的 **R7 不变量**断言（世界层好感度快照前后完全不变）。

**噪音控制**：只有真正的**关系变化**（等阶升级）才写关系史；普通互动照旧不写
（与 2b-0 对世界事件的口径完全一致）。

## 6. 过程中的两个发现（都是测试自己的问题，如实说明）

1. **夹具写错了**：我先把 `CharacterState.affinity` 改成 19，但那一行当时**还不存在**——
   Dexie 对不存在的键执行 `update` 是 no-op，于是等阶根本没升级，A 组前 5 条断言全红。
   现在先 `stateRepo.getOrCreate()` 再置 19，并加了一条 **⓪ 夹具成立** 断言
   （先证明夹具真的处于临界状态，再断言产品行为——否则测试可能在什么都没验证的情况下变绿或变红）。
2. **我的期望值写错了两次**：信任 80 属于"高"档（我却按"中"档写期望）；角色对的显示顺序按
   SubjectRef 排序（实际是「月见 和 星遥」，我写成了「星遥 和 月见」）。
   两处都是**断言错误、产品正确**，已按实际语义改正（第二处改成两种顺序都接受，避免把内部排序当成产品契约）。

## 7. 已知限制

| # | 项 | 说明 |
|---|---|---|
| L1 | **分面（信任/依赖/摩擦/熟悉）目前几乎总是空的** | 4.x 只计算好感度，不产出这五个分面；它们要等世界舞台/场景结算按事件写入才会长出来。所以"他们之间"现在大多显示"还没有记录到他们之间的具体变化"——**这是如实状态，不是没做完** |
| L2 | 用户 ↔ 角色只显示等阶，不显示分面数字 | 等阶来自 4.x 好感度（唯一来源）；分面有记录时才显示人话标签 |
| L3 | 关系史只记"为什么"，不记"变了多少" | 这是 R7 的自我保护（不写数值）。若你希望记录"这次变化让信任 +8"，需要先裁定 R7：把分面数值也纳入唯一来源 |
| L4 | 角色 ↔ 角色目前只有迁移回填 + 测试写入 | 生产上还没有事件去改角色之间的关系（世界舞台阶段才会有）；迁移来的 `sharedStoryEvent` 会显示为一条原因 |
| L5 | 关系页不提供编辑入口 | 不提供手工改关系（避免"用户直接改数值"破坏可解释性）；将来若有需要，建议做成"事件"而不是直接改状态 |
| L6 | **R7 仍未裁定** | 本阶段证明了"不写数值"也能可解释；但要在 Phase 4 之前定下唯一来源。建议方案：`relationshipStates.affinity` 改为**读取时从 `CharacterState` 取**（或干脆不存该字段），世界层只保留 4.x 没有的那四个分面 |
| L7 | baseline 之后 8 个阶段仍未提交 git | 建议尽快落一次提交 |
