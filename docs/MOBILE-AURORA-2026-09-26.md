# 手机界面：有温度的数字生命

本轮未改版本、未打包、未发布，未修改聊天记录、角色设定或记忆权限。

## 实现

- 新增 mobile-aurora.css，沿用原主题变量：消息紫青、日记淡紫、待办青绿、朋友圈暖金、星域蓝紫；统一按钮触摸面积、阅读间距和卡片圆角。
- 消息列表强化置顶层次，搜索光感延续到角色搜索；字标光轨收短。
- 私聊保留14px正文和非流式逻辑，消息轻量入场，背景跟随此刻选定的时段；不改消息时间。
- 此刻浮层增加头部拖动：下拉距离或速度达到阈值关闭，小幅拖动松手回弹，取消指针恢复位置。DOM位移不触发每帧React更新，不改变聊天布局。按钮不触发拖动。
- 星域顶栏与退出控件、对白/动作/旁白、创建与详情入口精修；保留已有星图布局、流式输出、按需历史加载及新内容滚动机制。
- 朋友圈封面暖光、头像行对齐、正文/评论/点赞区精修；日记纸面和待办三视图精修。
- 页面后台暂停装饰动画；减少动态设置禁用移动和转场。未添加持续动画模糊或全屏粒子系统；沿用既有星图效果。
