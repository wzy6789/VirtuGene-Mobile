# 助理界面精修 · 2026-10-02

助理相关窗口沿用设置页的深色材质体系，主要改善信息层级、手机阅读和操作可达性。参考 design-md-reference 的 Linear 深色层级与 Apple 移动控件简化原则，保留项目的紫色主题与助理形象。

## 实际调整

- 工作台、收件箱、每日整理、记忆与能力目录统一背景、卡片、边框和强调色。新增共用的 `SecretarySurfaceIntro`，说明当前窗口的用途；请求数、记忆数和能力数均来自实际数据。
- 工作台把收件箱和每日整理作为主要入口，管理、能力、习惯和记忆作为解释清楚的次要入口。日记、朋友圈和待办的去向固定在底部，滚动菜单仍可使用。
- 收件箱四个分类在同一行呈现，计数与分类文字分开；分类栏滚动时保持可见。原请求和办事结果分层展示，去掉外层重复容器。草稿、待补充、失败与完成保留各自真实状态和颜色。
- 结果卡片提高正文和按钮的字号，操作区与结果正文用细边框分开；没有操作的卡片不留空白操作栏。
- 每日整理的输出选项变为明确的选择卡片。习惯设置按记录、回应和提醒分组，输入文字为 16px。管理与长表单的主要操作固定在底部。
- 首页助理仍默认与普通对话条目等高。新增在职状态点和待处理标记；实际计数变化只过渡数字，保持标签与布局稳定。展开动作继续使用此前可反向接管的高度动画。
- 表单事件先读取当前输入值，再交给状态更新，避免异步更新时再次读取变化后的 DOM 值。
