隐私说明

LAST UPDATED / 2026.09.09

VirtuGene 是一个用于数字角色创作、私人记录和长期记忆整理的本地优先应用。本说明解释应用当前如何处理数据。

数据保存在何处

角色资料、聊天记录、记忆条目、情绪状态、手帐内容和本地登录资料默认保存在你的设备中。VirtuGene 当前不提供账号云同步，也不运行用于保存这些内容的自有服务器。

你使用自己的 AI 服务时

只有在你主动配置并发起对话时，应用才会将当前输入、必要的角色设定、相关记忆和近期对话发送给你选择的 AI 服务提供商，以生成回复。你的 API Key 使用设备本地加密存储；VirtuGene 不接收、不托管该密钥。

应用权限

  • 网络：仅用于你主动发起的 AI 请求、检查应用更新或访问你选择的在线服务。
  • 通知：仅在你授权后发送本地提醒。
  • 麦克风：仅在你主动使用语音输入时调用。
  • 照片或文件：仅在你主动选择图片或导出内容时访问。

你的控制权

你可以在应用内删除聊天、角色、手帐和本地资料，也可以在系统设置中撤销权限。卸载应用或清除应用数据会删除设备上的本地内容；请在操作前自行备份需要保留的信息。

本官网

本网站为 GitHub Pages 托管的静态介绍页，不提供注册、支付或信息提交表单。网站更新和问题反馈可通过项目页面处理。
