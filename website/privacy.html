隐私说明

更新于 2026 年 11 月 27 日

逢星（VirtuGene）用于 AI 角色互动、记忆整理与生活记录。本页分别说明官网浏览和应用使用中的数据处理方式；具体功能以你使用的版本及服务配置为准。

浏览本官网

逢星之境的正式域名由阿里云 ECS 托管，项目网站也提供 GitHub Pages 镜像。浏览页面不会调用模型、启用麦克风，或读取你在应用中保存的聊天、角色和日记。

打开网页时，浏览器会向网站服务器请求页面、图片等文件，并传递 IP 地址、请求路径及浏览器相关信息。托管与网络服务可能按其配置处理访问日志。打开外部链接后，相关数据处理适用目标服务的说明。

应用中的本地资料

角色、聊天记录、记忆、日记、事项与偏好设置等资料主要保存在你使用应用的设备中。使用在线模型、语音、网关、备份或同步能力时，相关内容会根据具体功能和你的配置在设备之外处理。

你主动导出、备份或分享资料时，所选内容会保存到指定位置，或发送到你选择的服务。请留意导出文件的存放位置及接收方。

模型服务与网关

自行配置模型服务和 API Key 时，应用会向你选定的服务发送本次生成所需的输入、角色设定、相关历史对话、记忆或其他已选资料；使用图片能力时，也可能发送你选择的图片。

使用已配置且可用的网关时，请求会先经过网关，再由网关调用模型服务。网关若提供账户功能，还会处理登录所需的账户信息及访问凭证。具体可用能力、额度和数据处理方式取决于该服务的实际配置。

模型服务或网关对请求内容的使用、保存与删除，适用其自身说明。启用服务前，请核对服务地址、隐私政策和费用；妥善保管 API Key 与访问凭证。

语音与设备权限

应用中的语音输入和通话需要相应的识别、合成服务及设备权限。根据所选识别方式，音频或识别文字可能发送给对应服务；生成语音时，待朗读文字会发送给语音合成服务。

  • 麦克风：用于你主动使用的语音输入或通话，是否授权由系统提示和你的选择决定。
  • 通知：用于你启用并授权的提醒。
  • 图片与文件：用于选择附件、导入资料或导出备份，具体访问范围以系统选择器或权限提示为准。

你可以在系统设置中撤销权限。模型与语音服务的费用和内容处理规则由相应服务提供方确定。

管理、备份与删除

你可以通过应用已有的资料管理、备份和导出入口管理内容。删除角色、聊天或其他资料前，请确认影响范围；卸载应用或清除应用数据可能使设备上的资料无法恢复，建议先备份需要保留的内容。

本地删除与第三方服务的数据删除分别处理。对于模型服务、网关、同步服务或已分享的副本，请通过对应服务的管理入口或联系渠道处理。

说明更新与问题反馈

本页会随实际功能及数据处理方式更新。使用新增在线能力前，请阅读该功能的说明与授权提示。

如需反馈问题，可以前往项目问题页面。该页面公开可见，请勿附上 API Key、访问凭证、完整私人对话或身份证明等敏感资料。
