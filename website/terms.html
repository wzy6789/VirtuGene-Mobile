使用条款

更新于 2026 年 11 月 27 日

逢星（VirtuGene）是用于 AI 角色互动、记忆整理与生活记录的应用。本页说明产品的使用边界；功能、服务与可用性以你使用的版本及实际配置为准。

AI 内容与判断

角色回复和其他生成内容由人工智能产生，可能包含错误、虚构或不恰当表达。人物表现和记忆内容也可能受到模型能力、上下文与配置的影响，重要事实请自行核对。

AI 生成内容不能替代医疗、法律、心理、财务等专业意见。涉及健康、人身安全或其他重要决定时，请结合现实情况，并在需要时寻求合格专业人士的帮助。

服务配置与费用

在线 AI 能力需要可用的模型连接。你可以按版本支持情况配置自己的模型服务和 API Key，或使用已配置且可用的网关。语音识别与语音合成可能需要另行配置。

使用第三方模型、网关或语音服务时，请先了解对应服务的价格、额度、数据处理方式和使用限制。相关费用依服务提供方或你所选服务方案确定，官网展示不代表提供免费或无限量的模型调用。

服务地址、凭证、网络或服务商状态异常时，相关能力可能暂时无法使用。请使用你有权访问的服务与凭证，并妥善保管 API Key 和账户信息。

你的内容与资料

请确保输入、导入、创建或分享的内容具有相应使用权限，尊重他人的隐私、著作权及其他合法权益，遵守适用法律法规。请勿使用产品生成或传播违法、有害或侵权内容。

在提交图片、对话或其他资料给在线服务前，请确认相应内容可以发送给该服务。具体数据流向和管理方式可查看隐私说明及所选服务的政策。

备份与删除

应用以本地资料管理为主。请自行保管设备及备份文件，并在更换设备、清除数据或卸载应用前备份需要保留的内容。

删除操作的影响以相应功能提示为准。设备中的资料、网关账户、同步服务及已分享副本分别管理；需要删除第三方服务中的内容时，请使用该服务提供的入口。

官网与展示内容

逢星之境的正式域名由阿里云 ECS 托管，项目网站也提供 GitHub Pages 镜像。浏览官网不会调用模型、开启麦克风或读取应用中的私人资料；官网中的界面、示例与录屏用于说明产品功能。

不同平台、版本与配置下的功能和界面可能不同。示例对话、人物表现或录屏效果不构成每次使用都会获得相同结果的承诺；可用功能请以实际版本及相关说明为准。

更新与反馈

产品功能和第三方连接可能随版本更新或服务变化而调整。使用更新后的功能时，请留意相关操作提示、服务要求与数据说明。

你可以通过项目问题页面反馈使用问题。提交前请移除密钥、访问凭证及私人内容。
