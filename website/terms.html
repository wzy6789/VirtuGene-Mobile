使用条款

LAST UPDATED / 2026.09.09

VirtuGene 是关于长期记忆、数字角色和私人记录的个人创作项目。使用产品代表你理解并接受以下规则。

AI 生成内容

角色回复由人工智能生成，可能出现错误、虚构或不恰当内容。它不能替代医疗、法律、心理、财务等专业意见；请结合现实情况自行判断并在需要时咨询合格专业人士。

你的内容与账号

你应确保输入和创建的内容符合法律法规，不侵犯他人的隐私、著作权和其他合法权益。请勿利用产品生成或传播违法、有害或侵权内容。当前版本的资料默认保存在你的设备中，请自行妥善保管设备、密码和 API Key。

第三方 AI 服务

如果你自行配置第三方 AI 服务，相关请求还会受该服务提供商的条款与隐私政策约束。请确认你有权使用所填入的 API Key，并理解对应服务的价格与使用限制。

测试阶段

当前产品仍处于公开测试阶段，功能可能调整或暂停。正式公开发布前，将根据最终功能和应用分发平台要求补充版本说明、支持渠道与必要的合规信息。
