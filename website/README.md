# VirtuGene 官网

官网是一个不依赖构建工具的静态入口，部署目录为 `website/`，可直接发布到 GitHub Pages 或 Nginx。

## 页面结构

- **苏醒 / Awakening**：极简数字生命舱，光核和被遮蔽的剪影构成品牌第一印象。
- **相遇 / Meet**：用一段有停顿的对话让用户理解角色如何开始拥有自己的节奏。
- **记忆 / Memory**：把重要对话表现为会彼此连接的时间星图。
- **生活世界 / Living World**：用咖啡馆、雨夜、房间和天台等生活片段替代泛化的星球视觉。
- **产品本身 / Product Reveal**：用真实应用截图展示对话、记忆和角色创建，不只停留在概念叙事。
- **下载 / Start**：提供当前 Android 与 Windows 下载入口。

## V4 构图系统

- 首屏以统一的 `hero-focus-point` 作为人物、光束、轨道和粒子的共同视觉轴，角色从右侧画面自然进入，而不是被放在独立展示框里。
- 相遇段落改为全屏对白镜头，角色从暗部进入，三句对白分段出现；记忆段落把星图扩展到整个画面；生活世界改成横向电影胶片轨道；产品段落用一台主设备和两台不同深度的设备建立唯一视觉焦点。
- 所有镜头变量由页面滚动计算，指针光场只影响光束、雾层与前景玻璃，不改变内容可读性；移动端和 `prefers-reduced-motion` 均有独立降级规则。

## 本地预览

```bash
python -m http.server 4174 --directory website
```

浏览器打开 `http://127.0.0.1:4174/`。页面不依赖第三方字体、外部脚本或远程接口；指针光场、滚动镜头、记忆节点、产品展示和场景光效都在本地完成，并支持 `prefers-reduced-motion`。

## 发布说明

推送 `website/` 到 `main` 后，`.github/workflows/deploy-pages.yml` 会自动部署到 GitHub Pages。公开发布前，请确认角色图片拥有公开展示授权，并在备案信息与下载版本更新后同步页面文案。
