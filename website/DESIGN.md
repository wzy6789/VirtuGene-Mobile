# 逢星之境官网设计依据

2026-11-27 版。官网介绍逢星（VirtuGene）的数字角色陪伴、共同记忆和日常记录，面向首次了解产品的人。首屏的实物感来自一件紫水晶质感的折叠玻璃雕塑，轮廓呼应现有 V 标志。真实产品画面从第二章开始出现。

## 官网研究与取舍

| 参考 | 官方资料中能确认的特点 | 在逢星中的运用 |
| --- | --- | --- |
| [Linear](https://linear.app/) 与 [Linear 品牌指南](https://linear.app/brand) | 首页按工作流程组织真实界面。品牌指南强调标志四周留白，字标偏好接近白色的 Mercury White 和深灰 Nordic Gray | 首屏只设一个主视觉。珠白承担大面积底色，皇家紫专用于主要操作与关键章节。把截图放回相应功能的说明旁 |
| [Stripe Press](https://stripe.press/) | 书封、书脊和书本材质承担视觉识别，图书是首页的展示对象 | 把逢星既有 V 形态转为可感知材质的玻璃造型，保留自然滚动，以一幅优化的 WebP 承载首屏视觉 |
| [Apple Vision Pro](https://www.apple.com/apple-vision-pro/) | 官方产品页将产品特写与不同使用情境分章组织 | 聊天、记忆、日常分别有独立构图与主叙述。段落之间用材质和明暗转换建立节奏 |
| [Kindroid](https://kindroid.ai/) 与 [Replika](https://replika.com/) | 前者从文字和通话等具体相处方式切入，后者用对话例子讲记忆 | 相处方式可切换。共同记忆使用现有手动示例里的热茶原句，旁边提供实际记忆管理界面 |
| [Day One](https://dayoneapp.com/) | 按记录、回顾、导出等具体行为组织功能段落，同时说明用户数据控制 | 日常章节分别放大一项待办与故事入口，把资料管理和模型数据去向放进独立说明 |
| [Radix Colors 色阶用法](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) | 用途区分页面底色、组件表面、边界、交互与正文 | 同一紫色色相家族分配给纸面、底板、主操作和正文，文字阅读依靠明度差 |

以上是对官方内容和公开品牌资料的归纳。以下色值、字号和构图为逢星的设计决策。

## 色彩与排版

| 角色 | 色值 | 页面使用 |
| --- | --- | --- |
| 珠白 | `#FCFAFC` | 记忆章节、界面图集、隐私与使用说明正文 |
| 淡丁香 | `#EEE8F2` | 日常与世界的双界面背景 |
| 墨紫 | `#24152C` | 标题，在珠白上的对比度为 16.59∶1 |
| 灰紫 | `#574B5E` | 正文，在珠白上的对比度为 7.86∶1 |
| 皇家紫 | `#482055` | 主按钮，白字对比度为 13.02∶1 |
| 深梅紫 | `#28152E` | 体验章节与页脚，配浅字 `#E0D1E4` 为 11.65∶1 |

大标题用本地托管的 Noto Serif SC 字形子集，保留中文宋体笔画的粗细变化。正文用设备无衬线字体。已有 V 标识和 Allura 花体字继续组成品牌署名。桌面首屏标题随宽度在 58 至 94 CSS 像素间调整，手机首屏改为先读标题、再看造型。

## 页面与实现

- 首屏为全幅珠白摄影棚和巨幅紫玻璃，主入口连接产品体验，次入口启动无声录屏。手机使用单独导出的轻量构图。
- 深梅紫的相处章节保留聊天、通话和故事切换。聊天和星域使用真实组件截图，通话以真实操作区局部说明功能。示例资料来自既有展示夹具。
- 记忆章节把截图中手动录入的热茶条目排进书页，链接打开真实界面。生活助理和世界首页放大实际界面局部，点击可还原全图。
- 展示型照片与产品证据采用独立素材。能交互的控制使用原生 HTML 按钮、链接和对话框。官网使用普通滚动，顶部无发光进度线或滚动触发的背景刷新。界面缩略图保留轻微悬停位移，并尊重系统和站内动态偏好。
- 体验区的三个标签保持在同一位置。舞台为三种界面预留共同的空间，切换只改变当前说明与画面。图集按完整屏幕比例展示，图注直接说明画面里的操作。
- 7.0.0 标注为 Android 体验展示，官网不提供安装包。演示主动播放，不采集音频或调用模型，第三方 AI 与语音配置的说明随实际应用使用场景呈现。
