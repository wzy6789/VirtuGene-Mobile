# VirtuGene 官网设计规范

> 让数字灵魂拥有时间。以古月娜与紫蓝色生命光效建立记忆点，让真实产品界面解释性格、记忆、关系与世界。文字安静可读，下载入口清楚，手机上也能完整地看见内容。

本规范仅适用于 `website/` 官网。依据当前代码整理，设计方法参考
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
的 Linear、Apple、Stripe 分析；不复制这些品牌的字体、配色或专有素材。

## 色彩与表面

基础变量定义在 [styles.css](./styles.css)，产品展示表面定义在
[living-light.css](./living-light.css)。

| 用途 | Token / 数值 | 应用 |
| --- | --- | --- |
| 背景 | `--bg-0: #070810` | 深色画布 |
| 次级背景 | `--bg-1: #0c0d19` | 环境底色 |
| 深层表面 | `--bg-2: #131421` | 文档背景层次 |
| 产品表面 | `--surface-display: #10111d` | 截图容器、下载卡片 |
| 抬升表面 | `--surface-raised: #181827` | 版本标签、交互状态 |
| 主文字 | `--ink: #efeaf9` | 标题和重点内容 |
| 次文字 | `--muted: #b7b0ce` | 正文与说明 |
| 辅助文字 | `--faint: #a19ab5` | 标注、页脚 |
| 品牌紫 | `--violet-brand: #6c5ce7` | 品牌基色 |
| 操作紫 | `#7864db` / hover `#8b77ea` | 主要下载按钮 |
| 柔紫 | `--violet-soft: #a99bff` | 标题强调、当前状态 |
| 生命蓝 | `--life-blue: #9be8ff` | 人物光丝与状态点 |
| 生命青 | `--cyan: #00cec9` | 少量语义点缀 |

氛围色与操作色职责分开。人物、世界节点保留光效；产品卡片靠表面色差、细边框和轻阴影获得层次。
不为每张卡片增加大面积霓虹光晕。各章节的环境光随滚动弱化。

## 排版

使用 `--font` 中的系统中文字体栈，不依赖远程字体。中文标题采用较自然的字距，不照搬英文负字距。

| 角色 | 桌面 | 手机 |
| --- | --- | --- |
| 首屏标题 | `clamp(44px, 5.2vw, 72px)`，600，行高 1.25 | `clamp(38px, 8.9vw, 52px)` |
| 章节标题 | `clamp(30px, 3.25vw, 46px)`，600，行高 1.3 | 32px；≤420px 时 30px |
| 正文 | 17px，行高约 1.8 | 16px，行高 1.75–1.8 |
| 小正文 | 15px | 15px |
| 说明与章节编号 | ≥13px | ≥13px |

标题只强调一个重点。正文限制阅读宽度，版本号、平台要求和下载信息避免拆成孤字。

## 结构与布局

页面顺序：[index.html](./index.html) 的首屏 → 对话 → 记忆 → 世界 → 界面 → 下载。
每段回答一个问题，理念融入内容，章节编号承担导航感。

- 内容容器最大 1280px，桌面左右内边距为 `clamp(20px, 4.6vw, 64px)`。
- 结构留白主要使用 16 / 20 / 24 / 32 / 40 / 64px；章节间距为 72–104px，手机为 64px。
- 手机布局断点为 860px：导航收进菜单，主内容单列，人物保持完整比例。
- 600–860px 的平板首屏采用双列；记忆与画廊缩小单张占宽，保持可读的手机截图尺寸。
- 对话截图桌面最大 320px，手机最大 300px；原始截图通过图片查看器展示。
- 世界的三个桌面面板固定 620px 高，切换不改变区域高度。
- 界面区桌面四张等宽截图；手机横向分页。八张补充截图使用原生横向滚动，按钮和方向键增强浏览。
- 截图保持原始比例。首屏人物可以渐隐，产品截图不以裁切隐藏内容。

## 组件与交互

- 保留圆角胶囊式下载按钮；普通按钮最小 48px 高，首屏主要操作 52px，紧凑导航按钮至少 44px。
- 展示卡圆角 `--radius-lg: 22px`，下载卡圆角 `--radius: 18px`，版本标签 6px。
- 每段有明确的主操作，次操作使用安静的描边或文字样式。
- 所有按钮保留 hover、按下和可见焦点反馈；画廊到达边界时禁用对应方向按钮。
- 记忆演示、世界切换、图片查看器与菜单的键盘行为见 [main.js](./main.js)。
- 动画共用现有 Ticker；继续遵循性能分级、离屏暂停、标签页隐藏暂停和减少动态设置。
- JavaScript 失效时标题、正文、下载链接和截图仍可读；横向内容仍可以原生滚动。

## 文案与事实

优先讲相处中的具体体验。截图注明演示内容，不把历史截图称为最新版本，不将官网星图描述为在线试玩。
下载卡按平台分别标注版本与系统要求。模型服务的 API Key 与可能的计费说明应在下载前可见。

## 修改后的检查

检查 390 / 430 / 768 / 1440px 等视口及手机横屏：无页面横向溢出、无文字裁切、截图比例正确、点击目标足够大。
实际操作记忆步骤、世界标签、节点、画廊、图片查看器和手机菜单。
检查减少动态模式及关闭 JavaScript 的页面。渲染结果与代码共同作为验收依据。
