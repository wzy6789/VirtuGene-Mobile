# 逢星之境官网设计依据

2026-11-27 版。官网介绍逢星（VirtuGene）的数字角色陪伴、共同记忆和日常记录，面向首次了解产品的人。首屏的实物感来自一件紫水晶质感的折叠玻璃雕塑，轮廓呼应现有 V 标志。互动场景从第二章开始，Android 原图可在页末按需查看。

## 官网研究与取舍

| 参考 | 官方资料中能确认的特点 | 在逢星中的运用 |
| --- | --- | --- |
| [Linear](https://linear.app/) 与 [Linear 品牌指南](https://linear.app/brand) | 首页按工作流程组织真实界面。品牌指南强调标志四周留白，字标偏好接近白色的 Mercury White 和深灰 Nordic Gray | 首屏只设一个主视觉。珠白承担大面积底色，皇家紫专用于主要操作与关键章节。把可操作的示例放在相应功能说明旁 |
| [Stripe Press](https://stripe.press/) | 书封、书脊和书本材质承担视觉识别，图书是首页的展示对象 | 把逢星既有 V 形态转为可感知材质的玻璃造型，保留自然滚动，以一幅优化的 WebP 承载首屏视觉 |
| [Apple Vision Pro](https://www.apple.com/apple-vision-pro/) | 官方产品页将产品特写与不同使用情境分章组织 | 聊天、记忆、日常分别有独立构图与主叙述。段落之间用材质和明暗转换建立节奏 |
| [Kindroid](https://kindroid.ai/) 与 [Replika](https://replika.com/) | 前者从文字和通话等具体相处方式切入，后者用对话例子讲记忆 | 相处方式可切换。用同一段雨夜热茶对话贯穿聊天示例和记忆原话 |
| [Day One](https://dayoneapp.com/) | 按记录、回顾、导出等具体行为组织功能段落，同时说明用户数据控制 | 日常章节分别给出可勾选的待办和可展开的世界入口，把资料管理和模型数据去向放进独立说明 |
| [Radix Colors 色阶用法](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) | 用途区分页面底色、组件表面、边界、交互与正文 | 同一紫色色相家族分配给纸面、底板、主操作和正文，文字阅读依靠明度差 |

以上是对官方内容和公开品牌资料的归纳。以下色值、字号和构图为逢星的设计决策。

## 色彩与排版

| 角色 | 色值 | 页面使用 |
| --- | --- | --- |
| 珠白 | `#FCFAFC` | 记忆章节、界面图集、隐私与使用说明正文 |
| 淡丁香 | `#EEE8F2` | 日常与世界的双界面背景 |
| 墨紫 | `#24152C` | 标题，在珠白上的对比度为 16.59∶1 |
| 灰紫 | `#574B5E` | 正文，在珠白上的对比度为 7.86∶1 |
| 皇家紫 | `#482055` | 主按钮，白字对比度为 13.02∶1 |
| 深梅紫 | `#28152E` | 体验章节与页脚，配浅字 `#E0D1E4` 为 11.65∶1 |

大标题用本地托管的 Noto Serif SC 字形子集，保留中文宋体笔画的粗细变化。正文用设备无衬线字体。已有 V 标识和 Allura 花体字继续组成品牌署名。桌面首屏标题随宽度在 58 至 94 CSS 像素间调整，手机首屏使用专门为竖幅生成的夜色玻璃图，标题在上，互动入口靠近拇指。

## 页面与实现

- 首屏为全幅珠白摄影棚和巨幅紫玻璃，主入口进入互动演示，次入口通向共同记忆。手机单独使用夜色竖幅封面与珠白按钮。
- 雨夜场景里，聊天是一封玻璃信笺，通话用声纹与可展开的字幕表现，故事可以翻到下一段。示例均事先写好，访客自己掌控节奏。
- “外面下雨了，我去泡杯热茶”是从聊天走向记忆的线索。左页的条目可展开原话，书页保留简短摘要。日常区并排放置珠白的待办纸页与深梅紫书封式世界目录，前者可勾选事项，后者可打开日记、朋友圈、待办和星域各自的示例。
- 展示型照片与产品证据采用独立素材。能交互的控制使用原生 HTML 按钮、链接和对话框。官网使用普通滚动，顶部无发光进度线或滚动触发的背景刷新。界面缩略图保留轻微悬停位移，并尊重系统和站内动态偏好。
- 体验区的三个标签保持在同一位置。舞台为三种界面预留共同的空间，切换只改变当前说明与画面。图集按完整屏幕比例展示，图注直接说明画面里的操作。
- 首页、图集与常见问题只介绍产品平台和功能。四张 Android 原图存放在可选的“界面参考”内。场景采用网页排版、文字及预制纹理，操作只作用于当前页面。


## 手机版的编排

同一个网址和同一组原生交互控件承载两种排版。手机以深紫竖幅封面开场，进入“一封雨夜来信”后先选聊天、通话或故事，功能说明在信笺下方。较宽的触摸横屏让文字与画面并排。操作中的演示、勾选及展开状态随窗口转向保留。

记忆区采用暖奶白引文纸与小幅布面日记本物件。纸面待办可以直接勾选，深紫世界目录按行展开。界面参考和访问说明在页末按需阅读。官网公开文案介绍平台和使用方式，不宣称具体发布版次。
