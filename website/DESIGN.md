# VirtuGene 官网设计规范

> 让数字灵魂拥有时间。7.0 版以真实界面解释相处的方式，保留古月娜、紫蓝色环境光、粒子、玻璃与生命光丝。

仅适用于 `website/`。设计方法沿用 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的 Linear 层次、Apple 产品展示与留白原则；不复制其品牌配色、字体或专有素材。

## 内容与顺序

首屏品牌与聊天产品同屏；随后为三种相处方式、可管理的记忆、生活助理与世界、四张可放大的新版画廊、公开下载与必要准备。每段只承担一个阅读重点，避免把全部功能列成同构卡片。

7.0.0 目前是本地体验展示，不能写成已公开发行。当前官网公开安装包独立标识 Android 6.1.0、Windows 2.1.0，不根据展示版本自动更新下载版本。更新需用户明确授权及真实资产核对。

## 排版与容器

- 系统中文无衬线为正文。品牌使用应用现有本地 `VG Signature`/Allura 子集，保留许可证；不依赖远程字体。
- 首屏大字桌面约 64px，手机 32–46px；章节标题桌面约 44px，手机 30px。正文 16–18px，次正文 14–15px，说明原则上 13px。
- 主容器最大 1320px，侧距 20–72px，章节间距 72–112px。标题不靠缩小文字或截断换取空间。
- 首屏两列，650px 以下上下排列。人物与独立真实手机截图构成同一视觉；手机不能侵入文字与按钮。
- 体验区为一组竖向选择与一张实际手机界面，宽屏展示边框有层次的整体容器。650px 以下单列，未选项收起辅助描述，保留明确标题。
- 记忆与日常章节采用交替的编辑式布局；手机统一文字在前、图片在后。画廊桌面四列，860px 以下两列，不用横向隐藏重要内容。
- 手机截图完整保留 390:844 的比例，圆角 14–28px。主要展示宽 260–300px；画廊缩略图可点击放大。

## 操作与动效

- 所有 UI 不使用箭头、斜箭头、尖括号或 chevron 装饰及尾标。上一张、下一张、返回、关闭都用明确文字。常见问题以加号/减号表示展开。
- 主操作至少 44px 触控高度，基础按钮 50px；焦点用清楚的淡紫轮廓。
- 体验选择是 `tablist/tab/tabpanel`，支持方向键、Home、End；画廊/菜单/原图查看/视频弹窗支持 Escape 与焦点恢复。
- 原有全局动效共用 Ticker，保留性能分级、离屏与后台暂停。减少动态时保留完整静态构图，不自动播放视频、不自动切换体验。
- 视频 `preload=none`，需要主动打开和播放。关闭或后台时暂停；网站不请求麦克风、摄像头或模型。
- 无 JavaScript 保持介绍、首张实际截图、画廊及下载可读；图片失败时保留有意义的替代文本。

## 事实与说明

七张图片均为当前实际组件的合成资料截图，语音是无声界面展示。不要用虚构示例来声称真实人味、模型效果、音质或时延已经达标。必要的 API Key、服务计费与上下文外发说明靠近下载；具体准备问题折叠展开。

检查 320 / 390 / 650 / 768 / 1024 / 1440px 下的中文断行、阅读宽度、图片比例、触控、焦点、菜单、录屏暂停及文案。保留同条件修改前后截图；禁止回滚覆盖并行应用代码来制造对比。官网检查不能写成 Android 真机或实际语音验收。
